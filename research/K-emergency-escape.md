# K. 알라미 비상 탈출 동작 조사 (TSK-175)

> 11-24 [리서치 1]. 법률 자문이 아닌 조사예요. 알라미 공식 도움말(zendesk)은 자동 읽기를 막아서(403) 원문을 직접 못 읽었어요. 알라미 공식 블로그(딜라이트룸)와, 도움말을 옮겨 적은 다른 회사 글로 확인했어요. 신뢰도는 표마다 적었어요.

## 결론

1. **알라미의 비상 탈출은 '언제든 보이는 탈출구 + 쓸수록 귀찮아지는 벌칙'이에요.** 몇 분 뒤나 몇 번 실패 뒤에 나타나는 방식이 아니에요. 미션 화면 오른쪽 위에 늘 있고, 정해진 미션(사진, 바코드처럼 대상이 없으면 못 하는 미션)에서만 쓸 수 있어요.
2. **끄는 방법은 두 번 바뀌었어요.** 예전(안드로이드): 움직이는 버튼을 100번 누르기, 쓸 때마다 100번씩 늘고 30일 뒤 처음으로. 지금(26.22.0 이후, 2026-11 기준): 10번 누르기 + 다짐 글 쓰기, 쓸 때마다 다짐 문장이 늘고 매달 1일에 처음으로.
3. **알라미가 직접 밝힌 고민은 '너무 어려우면 진짜 급한 사람이 화나고, 너무 쉬우면 침대에서 탈출구로 끄고 다시 잔다'예요.** 처음 1,000번에서 500번, 100번으로 낮췄다가 악용 불만이 나와 '쓸 때마다 두 배'를 넣었어요.
4. **유료, 무료 차이와 끄는 설정은 확인되지 않았어요.** 공식 도움말 제목상 사용자가 켜고 끌 수 없고 횟수도 못 바꿔요. 유료 전용이라는 근거는 못 찾았어요(무료로 보이지만 확정 아님).
5. **우리 추천: 이름은 '탈출'이 아니라 '오늘은 못 해요' 쪽, 동작은 '언제든 보이되 끄면 다시 잠들기 방지는 그대로'예요.** 우리 미션(M1~M4)은 사진, 바코드처럼 물건이 필요 없어서, 알라미와 쓰임이 달라요. 우리는 '몸이 아프거나 옆 사람이 자서 흔들기를 못 할 때, 실험실 기능이 너무 어려울 때, 센서 고장' 같은 경우가 대부분이에요.

## 1. 알라미에서 언제 보이고 어떻게 끄는지 (화면 순서)

### 1-1. 지금 방식 (26.22.0 이후)

| 순서 | 화면 | 하는 일 |
|---|---|---|
| 1 | 알람 울림 → 미션 화면 | 정해진 미션(아래 표)이 시작돼요 |
| 2 | 미션 화면 오른쪽 위 | '비상 탈출(Emergency Escape)' 메뉴가 늘 보여요. 몇 분 뒤나 실패 횟수 조건은 확인된 것이 없어요 |
| 3 | 탈출 화면 | 10번 누르기 |
| 4 | 다짐 글 화면 | 다짐 문장을 따라 써요. 쓸 때마다 문장 수가 늘어요 |
| 5 | 알람 꺼짐 | 다짐 횟수는 매달 1일에 처음으로 돌아가요 |

쓸 수 있는 미션: 물건 찾기, 단어 말하기, QR/바코드, 사진, 스쿼트, 수학 6~7단계. 흔들기, 타이핑, 걷기는 빠져요.

신뢰도: 중간. 알라미 도움말 글 제목과 검색 요약, 그리고 도움말을 옮겨 적은 WakeUpBroo 글(2026-11-08, "Alarmy's help center as of November 2026" 기준이라고 밝힘)로 확인했어요. 다짐 문장 예시는 못 찾았어요.

### 1-2. 예전 방식 (안드로이드 도움말, 블로그)

| 시기 | 끄는 방법 | 출처 |
|---|---|---|
| 처음 출시 | 1,000번 누르기 | 딜라이트룸 블로그(2025-02-10) |
| 1차 | 무작위로 켜지는 칸을 500번 누르기 | 같은 블로그 |
| 2차 | 100번, 칸 9개 | 같은 블로그 |
| 3차 | 100번, 5x5 칸(25개), 한 번 쓰면 다음은 200번 | 같은 블로그, 안드로이드 도움말 |
| 도움말 기준 | 사진, 바코드 미션에서만. 움직이는 버튼 100번, 쓸 때마다 +100, 첫 사용 30일 뒤 처음으로 | 안드로이드 도움말(검색 요약) |

이름: 한국어 블로그는 '비상 해제 모드', 영어 블로그는 'Emergency Cancellation Mode', 지금 iOS 도움말은 'Emergency Escape'예요. 앱 안 한국어 이름이 '비상 탈출'인지는 원문을 못 봐서 확정하지 못했어요.

### 1-3. 끈 뒤 흐름

- 탈출 뒤에 기상 확인(Wake Up Check)이나 다시 잠들기 방지가 그대로 도는지는 **확인된 자료가 없어요.**
- 알라미 기상 확인은 유료 기능이에요(우리 A 문서 5절). 그래서 무료 사용자는 탈출 = 바로 끝일 가능성이 커요(추정).

## 2. 유료, 무료 차이와 설정 위치

| 항목 | 확인 결과 |
|---|---|
| 유료 전용인가 | 근거 못 찾음. 유료 기능 목록(걷기, 스쿼트, 여러 미션, 기상 확인, 소리 키우기)에 들어 있지 않아요. 다만 스쿼트 미션 자체가 유료라, 스쿼트에서의 탈출은 유료 사용자만 만나요 |
| 사용자가 끌 수 있나 | 없음. 도움말 제목 "Can I turn off or modify Emergency mode?"의 검색 요약: 켜고 끌 수 없고, 누르는 횟수도 못 바꾼다. 요청은 검토 중이라고 함 |
| 설정 위치 | 설정 메뉴에 없음. 미션 화면 안에만 있음 |

## 3. 사용자 반응

| 반응 | 내용 | 출처 |
|---|---|---|
| 좋음, 꼭 필요 | 여행 중이라 등록한 물건이 없을 때 쓸 길이 필요하다. 미션이 물건을 못 알아봐서 결국 비상 버튼으로 껐다 | 딜라이트룸 블로그, 앱스토어 리뷰(검색 요약) |
| 너무 어려움 | "이미 깼는데 이 귀찮은 걸 해야 하냐"는 불만 (진짜 급한 사용자) | 딜라이트룸 블로그 |
| 악용 | 쉬워지자 핵심 사용자 일부가 "너무 쉬워서 계속 악용하게 된다"고 불만. 침대에서 탈출구로 끄고 다시 잠 | 딜라이트룸 블로그 |
| 탈출구가 없을 때 | "안 꺼져서 앱을 지워야만 멈췄다" (우리 A 문서 불만 3위) | research/A-competitors.md 83행 |
| 우회 | 자동화 앱(Automate)으로 비상 메뉴를 무력화하는 흐름을 공유한 글이 있음(오래된 안드로이드 기준) | LlamaLab 커뮤니티 |

알라미가 낸 숫자: 이 기능 사용 비율은 공개된 것이 없어요. 같은 글에서 '핵심 사용자 1%'의 불만을 무겁게 봤다고 써요.

**정리:** 사람들은 탈출구가 '있는 것'은 원해요. 다툼은 '얼마나 귀찮게 하느냐'예요. 알라미는 숫자를 네 번 바꿨고, 결국 '처음엔 쉽게, 자주 쓰면 점점 어렵게'로 왔어요.

## 4. 다른 앱 비교

| 앱 | 탈출구 | 언제 보이나 | 벌칙(귀찮게 하기) | 끈 뒤 |
|---|---|---|---|---|
| 알라미 | 비상 탈출 | 늘 (정해진 미션만) | 10번 누르기 + 다짐 글, 쓸수록 길어짐, 매달 초기화 | 확인 안 됨 |
| Sleep as Android | 전용 탈출구 없음. QR, NFC 미션만 '대신 어려운 양 세기 미션' 길이 있음(끌 수 있음). 집에서 2.5~5km 떨어지면 코드 요구 건너뜀 | 코드 미션에서 늘 | 더 어려운 다른 미션 | 기상 확인 그대로 돎. 안 누르면 다시 울림. '내기' 기능: 꼼수 쓰면 건 돈을 잃음 |
| I Can't Wake Up! | 전용 탈출구 없음. 미션 없이 쓸 수 있는 스누즈 횟수를 미리 정함 | 해당 없음 | 없음 | 깨어 있나 시험(Awake Test) 실패하면 다시 울림 |
| AlarmPop (iOS, 경쟁사 홍보 글) | 모든 미션에 비상 탈출 | 늘 | 연속 기록(streak)이 끊김 | 남은 알람 취소 |
| AMdroid | 확인된 탈출구 없음 | 해당 없음 | 해당 없음 | 알람 뒤 확인 기능 있음 |

신뢰도: Sleep as Android는 공식 문서, 나머지는 스토어 설명과 회사 홍보 글이에요.

**배울 점**
1. 알라미: 쓸수록 어려워지기 + 주기 초기화 → 급할 때 한 번은 쉽고, 습관이 되면 막혀요.
2. Sleep as Android: 탈출이 아니라 '다른 미션으로 바꾸기' + 끈 뒤 확인은 그대로 → 탈출해도 다시 자기 어려워요.
3. AlarmPop: 벌칙을 '시간'이 아니라 '기록'으로 줘요 → 우리 W1 연속 기록과 잘 맞아요.

## 5. 우리에게 맞는 방향 (TSK-176 [기획 5] 참고용)

### 5-1. 우리 상황이 알라미와 다른 점

| | 알라미 | 우리 |
|---|---|---|
| 못 하는 이유 | 물건이 없음(여행), 인식 실패 | 몸이 아픔, 옆 사람이 자서 흔들 수 없음, 문제가 안 풀림, 센서 고장, 실험실 기능이 너무 어려움 |
| 쓰는 미션 | 사진, 바코드 등 일부 | M1~M4 모두와 실험실 확실히 잠깨기 |
| 끈 뒤 | 확인 안 됨 | 다시 잠들기 방지(결정 145)가 이미 있음 |

### 5-2. 동작 추천안 (정하는 건 [기획 5])

| 항목 | 추천 | 이유 |
|---|---|---|
| 언제 보이나 | 미션 화면에 늘 작게 | 알라미, AlarmPop 모두 늘 보임. 몇 분 뒤에만 보이면 진짜 급할 때 그 시간 동안 소리가 계속 나요 |
| 끄는 법 | 짧은 동작 하나(예: 10초 길게 누르기, W3와 같은 동작) | 잠결에도 할 수 있고, 새 동작을 또 배우지 않아도 돼요 |
| 벌칙 | 쓸수록 길어지기(10초 → 20초 → 30초), 한 달마다 처음으로 | 알라미가 네 번 바꿔서 도착한 답이에요 |
| 끈 뒤 | 다시 잠들기 방지와 '정말 깼어요?'는 그대로 돎 | 탈출해도 다시 잘 수 없게. Sleep as Android 방식 |
| 기록 | W1에 '오늘은 미션 없이 깼어요'처럼 따로 표시, 연속 기록은 이어 가되 표시만 다르게 | 기록을 끊으면 벌칙이 너무 세요. 메모리 규칙상 W1은 연속 기록을 단순하게 보여 줘요 |
| 설정 | 처음엔 켜져 있음. 끄고 싶은 사람(더 독하게)만 앱 전체 설정에서 끔 | 알라미는 못 끄게 해서 '바꿔 달라' 요청을 받는 중이에요 |
| 유료 | 무료 | 결정 147, 148과 맞고, '안 꺼져서 지웠다' 불만을 막는 안전장치라 돈을 받을 이유가 약해요 |
| 손님 문구 | 'D0 화면 단순하게' 규칙에 맞게 글자 하나, 아이콘 하나 정도 | 메모리 '울림 화면은 단순하게' |

### 5-3. 이름 후보 방향

'비상 탈출', '비상 해제'는 알라미 이름이라 쓰지 않아요. 방향은 셋이에요.

| 방향 | 예 | 느낌 | 추천 |
|---|---|---|---|
| A. 사정 말하기 | '오늘은 못 해요', '지금은 어려워요' | 부드럽고 솔직함. 벌칙과 잘 어울림 | **1순위** |
| B. 다른 길 | '다른 방법으로 끄기', '미션 건너뛰기' | 뜻이 바로 보임. 다만 '건너뛰기'는 쉬워 보여서 악용을 부를 수 있음 | 2순위 |
| C. 브랜드 말투 | '봐주세요', '오늘만 봐줘요' | 도전자 브랜드 말투(J 문서)와 맞고 웃김. 진짜 급한 사람에겐 가벼워 보일 수 있음 | 3순위 |

추천: A 방향의 '오늘은 못 해요'. 이미 있는 '이번만 쉬기'(알람 카드)와 말투가 비슷해서 앱 안에서 어색하지 않아요. 다만 '이번만 쉬기'와 헷갈리지 않게 [기획 5]가 함께 봐야 해요.

- 지금 방식에서 늘 보이는지, 몇 분이나 몇 번 실패 뒤에만 보이는지(자료상 '늘'로 보이지만 원문 확인 못 함)
- 탈출 뒤 기상 확인이 도는지
- 유료 전용 여부

확인하려면 폰에 알라미를 깔아 직접 보는 방법이 있어요. 폰 설치는 사용자 지시가 있을 때만 해요.
