# D. 디자인 무드 리서치 (Pinterest)

- 작성일: 2026-11-15
- 방법: 앱 안 브라우저로 Pinterest 검색 결과를 열어 핀 제목과 핀의 대표색(Pinterest가 이미지마다 붙여 둔 평균 배경색)을 모았어요.
- 로그인 없이 검색 결과가 열려서 대체 수단(Dribbble/Behance 웹검색)은 쓰지 않았어요.
- 모든 링크는 **참고용**이에요. 화면, 일러스트, 문구를 그대로 가져오지 않아요.

---

## 1) 결론 요약

| 항목 | 내용 |
|---|---|
| 큰 흐름 | 알람 앱은 **아주 어두운 바탕 + 큰 시간 숫자 + 포인트 색 하나** 조합이 가장 많아요. 아침 루틴 앱은 반대로 **크림·베이지 바탕의 차분한 라이트 모드**가 많아요. |
| 미션 화면 | 게임처럼 노는 느낌(Alarm Game App, Fun Alarm app UI)과, 스트릭(연속 기록) 보상으로 동기를 주는 쪽(AlarmMax: Streak)이 두 갈래예요. |
| 인증 카드 | 인스타 스토리 템플릿은 **뉴트럴 베이지·브라운 + 큰 세리프/산세리프 제목 + 체크리스트** 형태가 압도적이에요. 국내 '기상 인증'은 모니모처럼 **흰 바탕 + 시간 강조 + 귀여운 캐릭터**가 많아요. |
| 추천 무드 | **A안 "새벽에서 아침으로"** (다크 기본 + 해 뜨는 오렌지 포인트). 알람 울리는 새벽엔 눈이 덜 부시고, 미션 성공 순간에 밝은 아침색으로 넘어가는 이야기가 앱 콘셉트와 딱 맞아요. 인증 카드도 이 전환을 그대로 보여줄 수 있어요. |

## 3) 무드 3안

> 폰트는 모두 무료 상업 사용 가능한 OFL(SIL Open Font License) 계열이에요. 아이콘은 Lucide로 통일해요.

### A안. 새벽에서 아침으로 (추천)

- **키워드**: 새벽 남색, 해 뜨는 순간, 따뜻한 전환, 단단함
- **이야기**: 알람이 울리는 화면은 어두운 남색, 미션을 깨면 화면이 해 뜨듯 오렌지/크림으로 밝아져요.

| 역할 | 라이트 | 다크 |
|---|---|---|
| 바탕 | #FBF6EE (크림) | #0E1424 (새벽 남색) |
| 카드/면 | #FFFFFF | #182036 |
| 글자 | #1B1F2A | #F2EEE6 |
| 포인트 (해) | #FF7A3D | #FF8A4C |
| 보조 (하늘) | #FFC979 | #6B7BB8 |
| 성공 | #3BA776 | #4CC38A |

- **타이포**: 본문 `Pretendard`. 큰 시계 숫자는 `Space Grotesk`(굵은 무게, 고정폭 숫자 설정)나 `Outfit`. 숫자가 둥글고 또렷해서 잠결에도 잘 읽혀요.
- **일러스트/모션**: 수평선 위로 해가 올라오는 단순한 그라데이션 면. 미션 성공 때 바탕이 남색에서 오렌지로 0.6~0.8초 동안 번지는 전환. 일러스트는 면 위주, 선 최소화.
- **어울리는 레퍼런스**: Awake App(https://www.pinterest.com/pin/925137948464813266/), Calendar Widget Dark(https://www.pinterest.com/pin/1012817403716092939/), Orange and Black Story(https://www.pinterest.com/pin/979955200186005977/), Lumy(https://www.pinterest.com/pin/590675307422260207/)

### B안. 장난스러운 기상 게임

- **키워드**: 게임, 쨍함, 귀여움, 경쟁과 보상
- **이야기**: 미션을 게임 스테이지처럼 보여주고, 스트릭과 배지로 보상해요. 10~20대에게 강하게 먹히는 방향이에요.

| 역할 | 라이트 | 다크 |
|---|---|---|
| 바탕 | #FFF8E1 | #15131C |
| 카드/면 | #FFFFFF | #221F2D |
| 글자 | #1A1A1A | #FAFAFA |
| 포인트 (노랑) | #FFD21F | #FFD84A |
| 보조 (라벤더) | #A9A1FF | #8F86FF |

- **타이포**: 본문 `SUIT`(둥근 기운이 있어 친근함). 큰 숫자는 `Unbounded`나 `Bricolage Grotesque` 굵은 무게로 통통하게.
- **일러스트/모션**: 굵은 외곽선 캐릭터(예: 졸린 동물 마스코트), 탭할 때 튕기는 스프링 모션, 성공 때 색종이 효과. 모션이 많아 배터리와 새벽 눈부심은 따로 챙겨야 해요.
- **어울리는 레퍼런스**: Alarm Game App(https://www.pinterest.com/pin/606086062399413093/), Create Alarm 노랑(https://www.pinterest.com/pin/69735494226509358/), Fun Alarm app UI(https://www.pinterest.com/pin/943222715685944346/), Clucky(https://www.pinterest.com/pin/722827808990427375/)

### C안. 조용한 미니멀 시계

- **키워드**: 트루 블랙, 숫자 중심, 절제, 기계적
- **이야기**: 화면 대부분을 비우고 시간 숫자 하나로 승부해요. 어른스럽고 집중력 있는 인상이에요.

| 역할 | 라이트 | 다크 |
|---|---|---|
| 바탕 | #F4F4F2 | #000000 |
| 카드/면 | #FFFFFF | #121212 |
| 글자 | #111111 | #EDEDED |
| 보조 글자 | #7A7A7A | #8A8A8A |
| 포인트 (빨강 점) | #E5322D | #FF453A |

- **타이포**: 본문 `Wanted Sans`(정돈된 고딕). 큰 숫자는 `JetBrains Mono`나 `Space Mono`처럼 고정폭, 혹은 도트 느낌을 원하면 `Doto`(OFL) 검토.
- **일러스트/모션**: 일러스트 없음. 숫자가 바뀔 때 한 칸씩 넘어가는 플립/롤링 모션 정도만. OLED(화면 자체가 빛나는 디스플레이)에서 배터리 절약에 유리해요.
- **어울리는 레퍼런스**: Nothing OS Concept(https://www.pinterest.com/pin/400398223141727074/), True Black E-Ink Widgets(https://www.pinterest.com/pin/1135047912371205075/), BLACK ALARM(https://www.pinterest.com/pin/437060338844432789/), blue dot pale(https://www.pinterest.com/pin/371828512984018454/)

## 4) 인증 카드 방향

레퍼런스에서 본 공통 문법:
- 스토리 템플릿은 9:16 세로, **큰 제목 + 짧은 목록 + 여백**이 기본이에요.
- '증거' 느낌은 **시간 숫자를 크게** 보여줄 때 가장 강해요 (iPhone Camera Morning Alarm 템플릿, 모니모 기상 인증).
- 국내 기상 인증은 흰 바탕과 캐릭터, 해외 템플릿은 뉴트럴 베이지 톤이 많아요.

morning-up 카드 제안 (A안 기준):

| 요소 | 제안 |
|---|---|
| 크기 | 1080×1920 (스토리), 1080×1350 (피드) 두 가지 |
| 맨 위 | 날짜, 요일 (작게) |
| 가운데 | 일어난 시각을 아주 크게 (예: 06:42). 큰 숫자 폰트 그대로 사용 |
| 그 아래 | 깬 미션 이름 + 걸린 시간, 연속 기상 n일째 |
| 바탕 | 일어난 시각에 따라 그라데이션이 달라짐 (이를수록 남색 많고, 늦을수록 오렌지 많음). 매일 카드 색이 조금씩 달라 모으는 재미가 생겨요. |
| 맨 아래 | 작은 앱 로고 + 앱 이름. 스토리 위쪽/아래쪽 안전 영역(약 250px)은 비워 둠 |
| 선택 | 셀카나 창밖 사진을 넣는 사진형 버전 (상쾌한 기상, morning essential 참고) |

주의: 손님이 보는 카드 문구에는 가운뎃점(·)과 긴 줄표(—)를 쓰지 않아요.
