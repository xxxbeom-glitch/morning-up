# F. 미션 썸네일 레퍼런스 (게임 아이콘, 패키지)

조사일: 2026-11-16 / 출처: Pinterest 50장 / 피그마: `04 디자인 레퍼런스 보드` 페이지, 잠들기 탭 보드 오른쪽 프레임 `미션 썸네일 레퍼런스 (게임 아이콘, 패키지)`(`248:1148`)

## 배경

- 미션 고르기(S1)에서 미션마다 게임 앱 아이콘이나 게임 패키지 같은 썸네일을 넣으려고 해요. 그림은 챗지피티 같은 이미지 생성 도구로 사용자가 직접 만들어요.
- 원하는 톤: 아케이드풍, 또는 친근하고 말랑한 느낌.
- 앱 UI 아이콘은 Lucide만 쓰지만, 이 썸네일은 일러스트라 예외예요.
- 카드 셋째 줄은 참고할 점(모양, 색, 질감, 캐릭터), 넷째 줄은 우리 미션에 쓸 곳이에요. 남의 캐릭터, 로고, 게임 이름은 따라 그리지 않아요.

## 짧은 결론

- **추천: "말랑 3D 젤리 아이콘"** (묶음 1을 기본으로, 묶음 2의 점토 질감과 낮은 채도를 섞기). 게임 앱 아이콘처럼 보이면서 앱의 밝은 아침 분위기와도 맞고, 이미지 생성 도구가 가장 안정적으로 잘 그리는 스타일이에요.
- 미션 4개는 **같은 틀, 같은 조명, 같은 카메라**로 만들고 **주인공 물체와 바탕색만** 바꿔요. 그래야 한 세트로 보여요.
- 아케이드 느낌을 더 원하면 대안으로 **묶음 5의 파스텔 오락기 틀**(웃는 오락기, 분홍 오락기)을 공통 틀로 쓰고 화면 안에 미션 그림을 넣는 방법이 있어요.

## 미션별 방향

미션 이름은 `docs/mission-ideas.md`의 4개 기준이에요(단어비, 암산, 흔들흔들, 바른말 고르기).

| 미션 | 주인공 물체 | 바탕색 제안 | 참고 카드 |
|---|---|---|---|
| 단어비 (떨어지는 단어) | 웃는 젤리 글자 블록 2~3개가 비처럼 떨어지고 작은 빗방울 | 하늘 파랑 (#5FB2E3 근처) | 웃는 젤리 큐브, 떨어지는 블록, 하늘에서 블록, 벽 뚫는 새 |
| 암산 (수학 문제) | 더하기, 곱하기 같은 기호 젤리 블록, 또는 숫자 판을 든 작은 로봇 | 살구 주황 (#F28A3C를 연하게) | 3D 사칙연산, 수학 로봇, 네온 길찾기 |
| 흔들흔들 (흔들기) | 흔들리는 말랑 생물이나 공이 든 통, 양옆에 흔들림 선 | 민트 (#00C281을 연하게) | 팝잇 공 굴리기, 점토 몬스터들, 픽셀 조이스틱 |
| 바른말 고르기 (4지선다 맞춤법) | 젤리 O와 X, 또는 카드 네 장 중 하나에 반짝임 | 라일락 분홍 | 젤리 OX, 보송한 OX 판, Kaoki 카드 상자 |

- 썸네일 안에 글자(한글, 영어)는 넣지 않아요. 생성 도구가 글자를 자주 틀리게 그리고, 미션 이름은 화면에서 썸네일 아래에 따로 써요. 단어비의 글자 블록도 '가', 'A' 같은 한 글자만 두거나 무늬로 대신해요.

## 한 세트로 보이게 하는 공통 규칙

| 항목 | 규칙 |
|---|---|
| 비율 | 정사각 1:1, 1024x1024로 만들기 |
| 틀 | 둥근 사각(앱 아이콘 모양), 모서리는 한 변의 약 22%. 틀까지 그림에 넣거나, 그림은 틀 없이 만들고 앱에서 같은 모서리로 잘라요 (잘라 쓰는 쪽 추천: 모서리가 4개 모두 똑같아져요) |
| 바탕 | 미션마다 한 색, 위가 조금 밝은 부드러운 그라데이션. 무늬, 풍경 없음 |
| 주인공 | 물체 하나(많아도 같은 물체 3개), 가운데, 틀 안의 약 70% 크기 |
| 카메라 | 정면에서 살짝 위, 같은 거리 |
| 조명 | 왼쪽 위에서 오는 부드러운 빛 하나, 위쪽 광택 띠, 아래 짧고 흐린 그림자 |
| 질감 | 말랑한 무광 젤리(살짝 점토 느낌). 유리, 금속, 반짝이 가루 없음 |
| 색 | 채도는 중간. 바탕과 주인공은 같은 색 계열에 밝기만 다르게, 포인트 색 하나 |
| 얼굴 | 넣는다면 모든 미션에 같은 눈(검은 점 두 개)과 볼터치. 넣지 않으면 모두 빼기 |
| 글자 | 넣지 않기. 단어비만 예외로 ㄱㄴㄷ, abc 낱자를 그림처럼 넣어요(11-16 사용자 결정) |
| 만드는 법 | 아래 뼈대 프롬프트는 그대로 두고 `[주인공]`과 `[바탕색]`만 바꿔요. 첫 그림이 마음에 들면 그 그림을 같이 올리고 "이 그림과 같은 스타일로"라고 붙이면 세트가 더 잘 맞아요 |
