# L. 자발적 후원 창구 법과 스토어 정책 조사 (TSK-183)

> 11-24 [리서치 1]. **법률 자문, 세무 자문이 아닌 조사예요.** 공식 문서 확인 날짜는 모두 2026-11-24예요. 실제로 열기 전에 세무사에게 한 번 확인받기를 권해요(특히 3절).
> 사업자 정보(상호, 등록번호, 주소)는 넣지 않았어요. '개인 사업자 일반과세자, 정보통신업(앱 개발)'처럼 종류만 적었어요.

## 결론

| 질문 | 답 | 확실한 정도 |
|---|---|---|
| 앱 안에 '후원' 버튼을 두려면? | **구글 인앱 결제 상품('응원하기')으로 파는 것이 가장 안전해요** | 높음 |
| 앱 안에 계좌번호를 적거나 토스, 후원 사이트 링크를 걸면? | **구글 정책 위반 위험이 커요.** '구글 결제 말고 다른 결제로 이끌기'를 막는 규칙에 걸려요 | 높음 |
| 대가 없는 순수 후원(계좌)이면 기부금품법은? | 1년에 1천만 원을 넘기면 등록이 필요한데, 개인 앱 운영비 같은 '사익' 목적은 **등록 자체가 안 되는 목적**이라 위법이 될 수 있어요. 1천만 원 아래는 등록 의무가 없어요 | 중간 (행안부도 '사례마다 다르다') |
| '응원하기' 상품으로 팔면? | 대가가 있는 '판매'라 기부금품에서 빠진다고 보는 것이 일반적이에요. 평범한 앱 매출이에요 | 중간 (문언 해석, 공식 해석 못 찾음) |
| 세금은? | 일반 매출이에요. **부가세 10%(가격의 1/11)와 종합소득세** 대상이에요 | 높음 |
| 사업자 통장이어야 하나? | **지금은 의무 아님.** 사업용 계좌 신고는 '복식부기 의무자'만 해야 하고, 정보통신업은 직전 연도 수입 1억5천만 원 이상부터예요. 첫해는 해당 없어요. 다만 구분해 두면 장부 쓰기가 편해요 | 높음 |
| 통신판매업 신고는? | **해석이 갈려요.** 첫해는 '직전 연도 거래 50회 미만' 면제에 들 가능성이 높지만, 판매가 50회를 넘으면 다음 해에는 신고 대상이 될 수 있어요 | 낮음~중간 |

**추천 하나: 구글 인앱 결제 '응원하기' 1회 구매 상품(1,000원, 3,000원, 5,000원 정도)을 설정 화면 안쪽에 두고, 산 사람에게 작은 감사 표시(예: 홈에 작은 배지나 감사 문구)를 줘요.** 계좌와 외부 링크는 앱 안에 두지 않아요.

이유:
1. 구글 정책에 맞는 유일하게 확실한 길이에요.
2. 작은 감사 표시가 있으면 '대가 있는 판매'가 분명해져서 기부금품법 걱정이 줄어요.
3. 결정 148(광고 없음), '당장 유료화 안 함'과도 부딪히지 않아요. 기능은 하나도 잠그지 않아요.
4. 구글 수수료 15%(한국은 2026-12-31부터 체계가 바뀔 예정)와 부가세를 빼면 1,000원에 약 770원이 남아요.

## 1. 구글 플레이 정책

### 1-1. 후원, 팁은 구글 결제를 써야 하나

| 경우 | 정책 | 출처 |
|---|---|---|
| 앱 안에서 디지털 상품, 기능, 서비스를 파는 것 | 구글 결제(Play Billing) 필수 | 결제 정책 [9858738](https://support.google.com/googleplay/android-developer/answer/9858738?hl=ko) |
| 세금 면제 기부(비영리 단체 기부) | 구글 결제를 쓰면 안 됨(예외) | 같은 문서 3절 "tax exempt donations" |
| 사용자가 크리에이터에게 주는 팁 | **100%가 크리에이터에게 가고 + 디지털 대가(스티커, 배지, 이모지)가 없으면** 개인 간 송금으로 보고 구글 결제 필요 없음. 둘 중 하나라도 어긋나면 구글 결제 필수 | 결제 정책 FAQ [10281818](https://support.google.com/googleplay/android-developer/answer/10281818) |

**우리에게 맞춰 읽으면:** 이 FAQ는 플랫폼 앱 안에서 '다른 사용자(크리에이터)'에게 주는 팁을 위한 규칙이에요. 앱 개발자 자신이 받는 후원에 그대로 들어맞는지는 문서에 없어요. 실제로 2019~2021년에 앱 안 후원 링크 때문에 오픈소스 앱이 내려간 사례가 여러 번 보고됐어요([HN 2019](https://news.ycombinator.com/item?id=21268389), [HN 2021](https://news.ycombinator.com/item?id=26761594), 2차 자료). 그래서 '응원하기'처럼 **구글 결제 상품으로 파는 것이 안전한 쪽**이에요.

### 1-2. 앱 안에 계좌번호, 외부 링크를 둘 수 있나

| 항목 | 정책 | 출처 |
|---|---|---|
| 앱 안에서 다른 결제 수단으로 이끌기 | 금지. 스토어 설명, 앱 안 홍보, 웹뷰, 버튼, 링크, 안내 문구 모두 해당 | [9858738](https://support.google.com/googleplay/android-developer/answer/9858738?hl=ko) 4절 |
| 다른 결제로 이어지는 웹페이지에 링크 | 금지에 포함 | FAQ [10281818](https://support.google.com/googleplay/android-developer/answer/10281818) |
| 앱 밖(메일 등)에서 다른 결제 안내 | 가능 | 같은 FAQ |
| 한국: 웹 결제로 가는 링크(아웃링크) | 대체 결제 프로그램에 등록하면 가능. 앱 안 웹뷰로 열고 UX 지침을 지켜야 함 | [11222040](https://support.google.com/googleplay/android-developer/answer/11222040?hl=ko) |

**정리:** 앱 안 '후원 계좌 안내'나 '토스로 후원하기' 링크는 위반 위험이 커요. 앱 전용 한 장 사이트(11-24 확정)에 후원 안내를 두고, 앱에서 그 사이트로 바로 가는 링크를 두지 않는 방식은 정책상 가능해 보여요. 다만 앱 안 '사이트 열기' 버튼에서 몇 번 눌러 후원 페이지로 이어지면 FAQ가 말하는 '결국 다른 결제로 이어지는 페이지'가 될 수 있어요.

| 항목 | 지금 | 출처 |
|---|---|---|

| 한국 대체 결제(개발자 제공 결제) | 구글 결제와 함께 제공하면 그 결제분은 수수료 4%p 낮춤(15% → 11%). 프로그램 등록, PCI DSS(카드 보안 기준), 24시간 안 거래 보고 필요 | [11222040](https://support.google.com/googleplay/android-developer/answer/11222040?hl=ko), [13821247](https://support.google.com/googleplay/android-developer/answer/13821247?hl=ko) |

## 2. 국내법

### 2-1. 기부금품법

지금 이름은 「기부금품의 모집ㆍ사용 및 기부문화 활성화에 관한 법률」(2024-07-31 시행)이에요. [국가법령정보센터](https://www.law.go.kr/법령/기부금품의모집ㆍ사용및기부문화활성화에관한법률)

| 내용 | 근거 |
|---|---|
| 기부금품 = **반대급부(대가) 없이** 받는 돈이나 물건 | 제2조 1호 (법제처 해석 18-0693에 인용된 문구) |
| 1천만 원 이상 모집하려면 등록 | 제4조 1항 |
| 등록할 수 있는 목적은 공익 사업으로 정해져 있음. **사익만을 위한 모집은 등록 대상이 아님** | 제4조 2항 |
| 사익 목적으로 등록 없이 1년에 1천만 원 이상 모집 = 적법하지 않음 | [법제처 해석 18-0693 (2019-03-13)](https://moleg.go.kr/lawinfo/nwLwAnInfo.mo?mid=a10106020000&pageIndex=&cs_seq=413940&rowIdx=90). 법제처 해석은 법적 구속력 없음 |
| 등록 없이 모집하면 3년 이하 징역 또는 3천만 원 이하 벌금 | 제16조 1항 1호 (2019년 문구, 현행 같은지 원문 확인 필요) |

**개인 후원 계좌에 대한 행안부 입장(보도):** "사례마다 요건을 따져야 해서 일반화하기 어렵다." 화면에 '자발적 구독료'처럼 계좌만 적고 시청자가 스스로 보내면 적극적 모집이 아닌 자발적 기부로 볼 수 있다는 설명, 대가(시청료, 서비스 대가)로 보면 법 적용에서 빠진다는 설명이 함께 보도됐어요. 국세청은 개인 계좌 후원금을 '증여'로 본다고 했어요. ([뉴시스 2025-01](https://www.newsis.com/view/NISX20250120_0003039371), [더나은미래](https://futurechosun.com/archives/54561), [서울변회 회보](http://m.news.seoulbar.or.kr/news/articleView.html?idxno=3549), 모두 2차 자료)

### 2-2. '응원하기' 상품 판매로 할 때 차이

| | 무상 후원(계좌) | '응원하기' 상품 판매 |
|---|---|---|
| 기부금품법 | 대가가 없으면 기부금품. 1천만 원 넘으면 위법 위험 | 대가(감사 표시 상품)가 있는 판매라 해당 안 된다고 보는 것이 일반적 |
| 세금 | 사업 관련이면 사업소득, 아니면 증여로 볼 수 있어 애매 | 그냥 매출. 부가세, 소득세 |
| 소비자 보호(환불) | 해당 없음 | 전자상거래법 청약철회 규칙 적용. 디지털 상품은 미리 '구매 즉시 제공, 철회 제한'을 표시해야 제한 가능. 환불은 구글 환불 정책도 따름 |
| 이름 쓰기 | '후원', '기부' | 상품 이름에 '기부'를 쓰지 않는 것이 좋아요. '응원하기', '커피 한 잔 사 주기'처럼 |

### 2-3. 통신판매업 신고

| 내용 | 출처 |
|---|---|
| 전자상거래로 파는 사업자는 통신판매업 신고 대상(전자상거래법 제12조) | [전자상거래법](https://www.law.go.kr/법령/전자상거래등에서의소비자보호에관한법률) |
| 면제: ① 직전 연도 거래 50회 미만, ② 부가세법상 간이과세자 (공정위 고시 제2022-4호) | [공정위 행정예고](https://www.ftc.go.kr/www/selectBbsNttView.do?pageUnit=10&pageIndex=24&searchCnd=all&key=193&bordCd=105&nttSn=10853), [머니투데이 2020](https://news.mt.co.kr/mtview.php?no=2020052109363838313) |
| 앱 마켓에서 앱이나 인앱 상품을 파는 개발자가 대상인지 | **공식 해석을 못 찾았어요.** 구글 정책상 한국 개발자가 부가세 책임을 지는 '판매자'라서 대상이라고 보는 쪽이 많지만, 마켓이 판매를 맡는다고 보는 해석도 있어요 |

우리 경우: 일반과세자라 ②는 안 돼요. 첫해는 직전 연도 거래가 0이라 ①에 들 가능성이 높아요. 판매가 연 50회를 넘으면 다음 해에는 신고하는 것이 안전해요. 신고는 정부24에서 하고, 면허세(지역마다 다름)가 들어요.

| 결제 처리 | 결제는 Google Play가 처리해요. 카드 번호 같은 결제 정보는 저희가 받지 않아요 |
| 저희가 볼 수 있는 것 | Play Console 주문 관리에서 주문 번호, 상품, 금액, 날짜 등을 볼 수 있어요(구매자 정보가 어디까지 보이는지는 콘솔에서 실제 확인 필요) |
| 폰 안 저장 | 감사 표시를 보여 주려고 구매했다는 사실만 폰 안에 저장해요. 지우면 구글 구매 기록으로 다시 불러와요 |
| 보관 | 전자상거래법상 대금 결제와 공급 기록은 5년 보관. 다만 기록 원본은 구글이 가지고 있고, 저희가 따로 모으지 않으면 '구글 기록을 따름'으로 적어요 |
| 환불, 문의 메일 | 환불 문의로 받은 메일 주소는 기존 '의견 보내기' 메일과 같이 처리 |

계좌 방식이면 입금자 이름과 계좌 정보를 저희가 직접 받게 돼서 처리방침과 보관 의무가 늘어요. 이것도 계좌 방식을 추천하지 않는 이유예요.

## 5. 방식별 비교

| | A. 인앱 '응원하기' 상품 | B. 앱 안 계좌 안내 | C. 앱 밖 링크(한 장 사이트에 후원 안내) |
|---|---|---|---|
| 구글 정책 | 맞음 | **위반 위험 큼** | 앱 안에서 이어지지 않으면 가능 |
| 기부금품법 | 판매라 걱정 적음 | 대가 없으면 해당, 1천만 원 넘으면 위법 위험 | B와 같음 |
| 세금 | 부가세 10% + 소득세, 구글 정산 자료로 신고 쉬움 | 매출인지 증여인지 애매, 직접 기록 | B와 같음 |
| 수수료 | 15%(12-31 뒤 바뀜) | 없음 | 없음(토스 등 쓰면 그쪽 수수료) |
| 개인정보 | 구글이 처리, 우리가 받는 것 적음 | 입금자 이름, 계좌 직접 받음 | B와 같음 |
| 사용자 편의 | 버튼 한 번 | 계좌 복사, 은행 앱 이동 | 사이트를 따로 찾아가야 함 |
| 들어올 돈 | 적지만 꾸준할 수 있음 | 앱 안에서 못 알리니 거의 없음 | 거의 없음 |
| 추천 | **추천** | 하지 않음 | A와 같이 두는 정도(선택) |

## 6. 열기 전에 할 일 (추천안대로 갈 때)

1. Play Console 결제 프로필에 사업자 등록 번호 넣기(수수료 부가세 10% 막기).
2. 상품 설명에 '기능은 바뀌지 않아요, 개발을 응원하는 상품이에요'와 환불 안내를 적기.
3. 통신판매업 신고 여부를 세무사나 정부24 상담으로 한 번 확인.
4. 개인정보처리방침에 4절 항목 더하기.
5. 2026-12-31 한국 수수료 개편 뒤 숫자 다시 보기.
