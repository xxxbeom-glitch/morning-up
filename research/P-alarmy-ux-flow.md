# P. 알라미 UX 흐름 대조표 (TSK-221, 결정 178)

- 조사: [리서치 5], 2026-11-26. 알라미 26.43.0(Z플립5). 바탕은 M 문서(11-25 무료 범위, 캡처 `docs/exports/tsk-193/`)이고, 유료 구독 뒤 새로 본 것은 ★로 표시해요.
- 기준(결정 178): **흐름**(언제, 어떤 순서, 어떤 형식으로)은 알라미를 따르고, **모양과 문구**는 우리 것이에요. 이 문서는 알라미 문구를 옮기지 않고 흐름만 적어요.
- 상태: **끝(11-26 11:30).** 1, 2절은 M 문서, 3, 4절 ★는 11-26 폰 확인(Z플립5, 프로 구독 상태). 1절 7, 8행(알라미 홈 배너, 밤 점검)은 권한을 일부러 끄는 시험이 필요해 이번엔 안 봤어요.

## 1. 권한 안내: 언제, 어떤 순서, 어떤 형식

| 순서 | 때 | 권한 | 알라미 형식 | 거절하면 | 우리 지금 |
|---|---|---|---|---|---|
| 1 | 첫 알람 만들기 1단계(시각 고른 뒤 '다음') | 알림 | 화면 안 카드(왜 필요한지 한 줄 + 두 버튼) → 시스템 창 | 그대로 다음 단계 | O2-1(온보딩, 한 화면에 권한 하나) |
| 2 | 첫 알람 4단계를 다 마친 직후 | 배터리 최적화 제외, 다른 앱 위에 표시 | 전체 화면 목록 한 장(권한마다 '설정하기'), X로 닫기 | 말없이 다음(결제 화면) | O2-3, O2-4 따로 한 장씩 |
| 3 | 미션을 고를 때(카메라 미션, 말하기 미션) | 카메라, 마이크 | 미션 설정 시트 안 '권한 허용하기' 버튼 | 미션을 못 고름 | 해당 없음(카메라, 마이크 미션 없음) |
| 4 | 수면 측정을 처음 켤 때 | 마이크 | 소개 4단계의 3단계가 권한 카드 → 시스템 창 | 말없이 탭으로 돌아감 | 해당 없음 |
| 5 | 전원 끄기 방지를 켤 때 | 다른 앱 위, 접근성 | 기능 페이지 안 권한 2줄 목록 | 기능이 안 켜짐 | P6 동의 바텀 모달(결정 101) |
| 6 | 언제든(사용자가 찾아갈 때) | 필수 권한 전체, 방해 금지 허용, 배터리 | 설정 > '알람 울림 최적화' 체크리스트 3줄 | - | T2 권한 한 화면(결정 130) |
| 7 | 권한이 꺼져 있을 때 홈에서 | - | (M 문서에서 못 봄, 폰 확인) | - | H2-1~H2-5 홈 경고 배너 |
| 8 | 권한이 꺼진 채 알람이 다가올 때 | - | (폰 확인) | - | N1 밤 9시 내일 알람 점검 알림, PL2 나중용 시트 |

- 흐름 요약: 알라미는 **필요한 순간에 한 번** 묻고(알림은 시각 고른 직후, 카메라는 카메라 미션 고를 때), 거절해도 막지 않고 넘어가요. 놓친 권한은 **설정의 체크리스트 한 곳**에 모아요.
- 우리는 온보딩에서 필수 넷을 한 장씩 차례로 묻고, 홈 배너와 밤 알림으로 계속 알려요. 목적은 같고 우리가 더 자주 알려요.

## 2. 바텀시트와 팝업을 쓰는 상황

| 형식 | 알라미가 쓰는 때 | 우리 같은 자리 |
|---|---|---|
| 바텀시트(값 고르기) | 볼륨과 부드럽게 깨우기, 부드럽게 깨우기 시간, 미션 목록과 미션 설정, 퀵 알람, 소리 직접 추가, 알람 자동 해제 시간 | S6 볼륨 시트, S1 미션 시트, T1-1, T1-2(설정 열기 규칙: 토글+시트) |
| 바텀시트(제안, 한 번) | 미션 끝 '다음엔 더 어렵게?', 다시 잠들기 방지 설명, 이탈 할인 | 없음 |
| 가운데 팝업(확인) | 저장 안 하고 나가기, 앱 종료, 앱 삭제 방지 켜기, 평가 묻기 | S0-1 저장 안 하고 나가기 |
| 팝업 없음(바로 + 되돌리기 띠) | 알람 삭제('실행취소' 띠), 한 번만 건너뛰기(확인 없이 바로) | H7 삭제 스낵바(결정 160), 이번만 쉬기(H8) |
| 작은 메뉴(점 세 개) | 홈 정렬, 꺼진 알람 삭제, 카드 더보기(삭제, 미리보기, 1회 건너뛰기, 복제) | H3 더보기 |
| 화면 안 알약 | 토글 끄면 '한 번만 건너뛰기' | H8-1 '이번만 쉬기' |
| 전체 화면 | 권한 목록, 결제, 미션 목록 페이지, 다시 잠들기 방지 분 고르기 페이지 | O2, T2 |

- 규칙으로 보면: **값을 고르면 시트, 되돌릴 수 있는 행동은 확인 없이 바로 + 띠, 잃는 게 있으면(저장 안 함, 앱 나감) 가운데 팝업**이에요.
- ★ 유료로 열린 시트와 팝업(다시 잠들기 방지 동작, 미션 여러 개, 알람 전 수정 방지): 폰 확인.

## 3. 푸시 알림 목록
자세한 표는 `research/O-notifications.md` 2, 3절(TSK-216)이에요. 흐름만 줄이면:
- 알라미는 **전체 화면이 앞에 있을 때(울림, 미루기, 확인)만** 못 지우는 알림 하나를 같이 띄워요. 기다림, 놓침, 자동 해제는 알리지 않아요.
- 늘 보이는 '다음 알람' 알림은 선택(처음엔 꺼짐)이에요.
- 날씨, 취침, 리포트, 소식, 캠페인 알림은 통로만 있고 알람 흐름과 따로예요.

## 4. 설정 메뉴 위치와 구성
- 위치: 하단 탭 5개 중 맨 오른쪽 '설정'. 알람 하나의 설정은 알람 편집 화면 안에 있어요.
- 구성(M 문서 1-16): 프로필(로그인) → 프로 → 전원 끄기 방지 → 앱 삭제 방지 → 알람 울림 최적화 → 알람 고급설정(알람, 미션, 알람 회피 방지 묶음) → 테마 → 사운드 출력 → 앱 알림 설정 → 시스템 설정 → 공지, 자주 묻는 질문, 의견 보내기, 정보.
- 묶는 방식: **알람 하나에만 걸리는 것**(미션, 소리, 미루기, 다시 잠들기 방지)은 편집 화면, **모든 알람에 걸리는 것**(자동 해제, 미션 중 음소거, 수정 방지, 대기 알람 알림)은 설정 > 알람 고급설정.
- ★ 유료로 본 것(11-26, 캡처 `docs/exports/tsk-216/`):
  - 다시 잠들기 방지(편집 화면 줄 → 분 고르기 페이지, 139): 끄고 N분(1, 3, 5, 7, 10) 뒤 **전체 화면 + 알림**이 함께 떠요. 화면은 90초 카운트다운과 큰 버튼 하나뿐이에요(141). 답이 없으면 알람이 다시 울리고(142), 끄면 N분 뒤 또 물어요(되풀이). 버튼을 누르면 끝나고 '아침' 탭으로 가요(143). 몇 번 물을지 정하는 칸은 없어요.
  - 알람 전 수정 방지(설정 > 알람 고급설정 > 알람 회피 방지, 144): 시트 하나에서 '사용안함, 5분, 10분, 30분, 60분, 180분, 600분' 중 고르는 것이 전부예요. 울리기 그 시간 전부터 알람을 못 바꾸게 하는 규칙이에요. 이번엔 켜 보지 않았어요(막히는 모양은 못 봄).
  - 광고 없는 홈: 아래 광고 띠가 사라지고, 맨 위 이벤트 배너(아이돌, 웹툰 알람 홍보)는 그대로 있어요.
  - 못 본 것: 미션 2~5번째 칸, 걷기, 스쿼트 미션(시간과 센서 때문에 이번엔 안 함).
