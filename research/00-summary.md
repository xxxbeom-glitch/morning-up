## 1. 한 줄 결론

> **"광고 없는 해제 화면 + 재밌는 미션 + 알람이 반드시 울리는 안정성"** 세 가지로 승부해요. 경쟁 앱 7개가 전부 광고가 있고, 리뷰 불만 1위가 "알람 끄는 화면의 광고, 결제 유도"예요.

| 무엇을 알았나 | 근거 | 우리 결정에 주는 뜻 |
|---|---|---|
| 경쟁 앱 7개 모두 광고 있음 | A 2번 표 | "알람, 미션 화면 광고 없음"만으로도 차별점 |
| 알라미 유료: 미션 묶기(최대 3개), 기상 확인, 다시 잠들기 방지, 몸 쓰는 미션 | A 1번 | 이 중 묶기, 기상 확인은 무료로 풀기 (기획과 같음) |
| 불만 3위 "알람이 안 꺼짐, 비상 탈출 없음" | A 4번 | 비상 해제와 미션 미리 해보기를 기본 기능으로 |
| 알람이 안 울리는 원인 1위는 제조사 절전 기능 (삼성, 샤오미 최악 등급) | B 4번 | 온보딩 권한 단계 + 홈 "상태 점검 카드" 필수 |
| 코드 재사용은 Apache 2.0만 (AOSP DeskClock, Chronos 등) | B 2번 | GPL 앱(Fossify Clock 등)은 보기만 |
| 화면 공통 패턴: 시간 숫자가 주인공, 요일 칩 7개, 울림 화면 버튼 2개, 권한은 이유 먼저, 해제 뒤 연속 기록 | C 1번 | 기본 화면은 표준을 따르고, 울림부터 해제까지에 힘을 줌 |
| 무드 추천: "새벽에서 아침으로" (남색 → 해 뜨는 오렌지) | D 3번 | 미션 성공 순간의 색 전환을 앱의 상징 장면으로 |

## 3. IA (정보 구조)

```
첫 실행
└ 온보딩 (5화면 안쪽)
   ├ 1. 앱 소개 (한 화면)
   ├ 2. 첫 알람 시간 정하기
   ├ 3. 미션 하나 골라 미리 해보기
   ├ 4. 권한: 알림 → 전체 화면 알람 → (필요 시) 정확한 알람
   └ 5. 절전 해제 안내 (삼성, 샤오미는 전용 안내)

홈 = 알람 목록  ─ 하단 탭: [알람] [기록] [설정]
├ 상태 점검 카드 (설정 빠진 게 있을 때만)
├ 다음 알람까지 남은 시간
├ 알람 카드 (시간, 반복, 미션 아이콘, 켜기/끄기)
│   └ 알람 편집
│       ├ 시간 선택
│       ├ 반복 요일 (7칸 칩 + 매일/평일/주말)
│       ├ 미션 묶음 (추가, 순서 바꾸기, 난이도) → 미션 미리 해보기
│       ├ 소리, 진동, 점점 커지는 소리
│       ├ 스누즈 (횟수, 간격)
│       └ 깨어 있나요 확인 (켜기, 몇 분 뒤)
└ + 새 알람

기록
├ 연속 기상 일수, 이번 주 7칸
├ 지난 기록 (일어난 시각, 깬 미션, 걸린 시간)
└ 인증 카드 만들기 → 공유

설정
├ 알람 안정성 (권한 상태, 절전 해제 안내)
├ 기본 미션, 난이도
├ 화면 (테마)
└ 앱 정보, 오픈소스 고지

알람 울림 (시스템이 띄움, 홈과 따로)
└ 울림 → 미션 → 해제 완료 → (몇 분 뒤) 깨어 있나요 확인
```

## 5. 핵심 사용 흐름: 울림 → 미션 → 해제

```
[알람 시각] 잠금 화면 위로 울림 화면
   │  큰 시간, 알람 이름, 오늘 미션 미리보기
   ├─ 작게: 스누즈 (남은 횟수 표시) ──→ n분 뒤 다시 울림
   └─ 크게: 미션 시작
          │  미션 중에는 소리를 줄였다가, 손을 놓으면 다시 키움
          ▼
     미션 1 → (묶음이면) 미션 2 → 미션 3
          │  실패하면 새 문제로 다시
          │  15분 넘게 못 끄면 비상 해제 길이 열림
          ▼
     해제 완료 (기상 확인)
          │  남색 바탕이 해 뜨듯 오렌지로 번짐
          │  "n일 연속", 이번 주 7칸, 버튼 하나
          │  (선택) 인증 카드 만들기
          ▼
     몇 분 뒤 "깨어 있나요?" 알림
          ├─ 시간 안에 누름 → 끝
          └─ 안 누름 → 알람 다시 울림 → 미션부터 다시
```

안정성 장치 (사용자 눈에 안 보이지만 흐름의 일부)
- 폰을 다시 켜면 알람 자동 재예약, 미션 중 앱이 꺼지면 다시 울림.
- 전원 끄기 방지는 넣지 않아요 (구글플레이 접근성 권한 정책 위험, mission-ideas 7번).

## 6. MVP 미션 추천 (4개 + 기능 2개)

사용자 아이디어(mission-ideas.md)를 기준으로, B 조사의 "만들기 쉽고 실패 적은 미션" 기준을 맞춰 봤어요.

| # | 미션 | 추천 | 이유 |
|---|---|---|---|
| 1 | 움직이는 문장 타이핑 | ✅ MVP | 알라미 따라쓰기와 체감이 확실히 다르고, 홍보 영상에서 바로 보여요. 기본 입력만 써서 만들기 쉬워요. 한글은 다 친 뒤 비교. |
| 2 | 헷갈리는 4지선다 (사과/샤과/서과) | ✅ MVP | 오답을 자동으로 만들 수 있어 문제 데이터 부담이 작아요. 3문제 연속 정답이라 찍어서 통과 확률 약 1.6%. |
| 3 | 두더지잡기 | ✅ MVP | 게임 느낌 담당. 장르는 자유롭게 쓸 수 있고, 캐릭터, 그림, 효과음만 직접 만들면 돼요. 누르는 영역은 넉넉하게. |
| 4 | 흔들기 | ✅ MVP (추가 추천) | 기획에서 이미 "사용 가능"으로 정했고, 기본 센서만 써서 가장 쉬워요. 화면을 보기 힘든 사람용 쉬운 미션이자, 다른 미션이 안 될 때 대체 미션 역할도 해요. |
| 기능 | 미션 묶기 | ✅ MVP | 알라미 유료 기능. 처음부터 "알람 1개 = 미션 목록" 구조로. |
| 기능 | 깨어 있나요 확인 (다시 잠들기 방지) | ✅ MVP | 알라미 유료 기능. 일반 알림과 예약 알람만 써서 정책 문제 없음. 이름은 알라미 표현과 다르게 지어요. |
| - | 수학 문제 | 보류 | 모든 경쟁 앱에 있어 차별점이 약해요. 4지선다가 같은 "머리 깨우기" 역할을 해요. |
| - | 바코드/QR | 2차 | 효과는 좋다는 리뷰가 많지만 카메라 권한, 등록 과정이 필요해요. |
| - | 기억 퀴즈 (어려운 주관식의 수정판) | 2차 | 문제 데이터를 수백 개 만들어야 해요. |
| ❌ | 전원 끄기 방지 | 빼기 | 구글플레이 정책 위험 |

모든 미션에 공통으로: 난이도 3단계, 미리 해보기, 비상 해제, 미션 중 소리 줄이기.

## 7. 디자인 방향성

### 원칙 (C 조사)
1. 시간 숫자가 늘 1순위. 너무 가늘지 않게 (새벽 저시력).
2. 울림 화면은 결정 하나만: 주 버튼 "미션 시작", 스누즈는 작고 멀리.
3. 비상 해제는 작게라도 늘 보이게.
4. 권한은 한 화면에 하나, 이유 먼저, 필수/선택 표시.
5. 기상 확인은 10초 안에 끝.
6. 온보딩은 첫 알람까지 5화면 안쪽.
7. 반복 요일은 한글 7칸 칩 + 매일/평일/주말.
8. 알라미 화면과 나란히 놓고 닮은 곳이 없는지 검토.

### 무드 3안 (D 조사)

| 안 | 키워드 | 대표 색 (다크 기준) | 숫자 폰트 | 장점 | 약점 |
|---|---|---|---|---|---|
| **A 새벽에서 아침으로 (추천)** | 새벽 남색, 해 뜨는 순간, 따뜻한 전환 | 바탕 #0E1424, 포인트 #FF8A4C, 보조 #6B7BB8, 라이트 바탕 #FBF6EE | Space Grotesk 또는 Outfit | 미션 성공 순간의 색 전환이 앱 이야기와 인증 카드로 바로 이어짐. 새벽 눈부심 적음 | 그라데이션 품질 관리 필요 |
| B 장난스러운 기상 게임 | 게임, 쨍함, 캐릭터 | 바탕 #15131C, 포인트 #FFD84A, 보조 #8F86FF | Unbounded, Bricolage Grotesque | 10~20대에게 강함, 공유 욕구 높음 | 게임형 경쟁 앱이 많아 차별 약함, 일러스트와 모션 부담 큼 |
| C 조용한 미니멀 시계 | 트루 블랙, 숫자 중심 | 바탕 #000000, 포인트 #FF453A | JetBrains Mono, Space Mono, Doto | 만들기 쉽고 배터리에 유리 | 인증 카드 공유 욕구 낮음, "재밌는 미션"과 결이 다름 |

- 본문 폰트 후보: Pretendard (A), SUIT (B), Wanted Sans (C). 모두 무료 상업 사용 가능.
- 아이콘: Lucide로 통일.
- 인증 카드: 일어난 시각을 아주 크게, 깬 미션과 연속 일수, 바탕 그라데이션은 일어난 시각에 따라 달라짐. 손님이 보는 문구에 가운뎃점과 긴 줄표는 쓰지 않음.
- 주의: D 조사의 무드 메모는 핀 이미지를 직접 보지 못하고 제목과 대표색으로 썼어요. 무드 고르기 전에 링크를 한 번 열어 보는 게 좋아요.
