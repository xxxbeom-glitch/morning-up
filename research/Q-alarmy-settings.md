# Q. 알라미 설정 메뉴와 우리 설정 비교, 추천 배치 (TSK-263용)

- 조사: [리서치 6], 2026-11-27. 알라미 26.43.0.
- 자료: ① P 문서 4절(11-26 폰 확인, 프로 구독 상태), M 문서 1-7절(설정 탭), ② 알라미 설치 파일 안의 화면 글자 자원(한국어, 영어)을 읽어 메뉴 이름과 하위 항목을 확인. ③ 우리 코드 `feature/settings/SettingsScreen.kt`, `strings.xml`, `EditScreen.kt`.
- 결정 178대로 **흐름과 배치만** 따르고, 알라미 문구는 옮기지 않아요. 아래 '알라미' 칸의 이름은 뜻만 줄여 적었어요.

## 2. 알라미 설정 탭 구성 (메뉴 나무)

M 문서 1-7절 + 글자 자원으로 확인한 하위 항목이에요. ★는 유료.

| 묶음(위에서부터) | 들어 있는 것 |
|---|---|
| 프로필 | 로그인(선택), 함께한 날 수 |
| 프로 | 구독 상태, 남은 날 |
| 전원 끄기 방지 ★ | 알람 중 전원 메뉴 막기, 지원 안 되는 기기 안내 |
| 앱 삭제 방지 ★ | 알람 중 앱 삭제 막기(스크린타임 권한) |
| 알람 울림 최적화 | 점검 목록: 필수 권한, **방해 금지에서 허용**, 배터리 최적화 제외. 각 줄을 누르면 폰 설정 가는 길 안내 |
| 알람 고급설정 | **알람**: 알림 창에 대기 알람 표시, 새 알람 기본값, 볼륨과 소리, 부드럽게 깨우기, 미루기 횟수 제한 / **미션**: 미션 제한 시간, 미션 중 음소거와 최대 횟수, 해제 뒤 아침 탭 숨기기, 자동 해제 / **알람 회피 방지** ★: 알람 전 수정 방지 |
| 테마 | 화면 모드(라이트, 다크), 색 4가지 |
| 사운드 출력 | 폰 스피커만 / 연결된 기기 |
| 앱 알림 설정 | 서비스 알림, 혜택과 이벤트 알림 |
| 시스템 설정(일반) | 언어, 앱 종료 확인창 숨기기 |
| 아래쪽 | 공지, 자주 묻는 질문, **문의하기**(Zendesk, TSK-267 문서), 정보(평가, 오픈소스, 약관, 개인정보, 광고 개인화) |
| 실험실 | 알라미 실험실(베타 기능 소개 창) |

배치 규칙(P 문서 4절과 같음): **알람 하나에만 걸리는 것은 편집 화면, 모든 알람에 걸리는 것은 설정 탭.** 위쪽은 '알람이 확실히 울리게 하는 것', 아래쪽은 '앱 정보와 도움'이에요.

## 4. 추천 배치 (TSK-234 '중요도 순 재배치'와 함께)

결정 192(제목만으로 알면 설명 빼기)를 따라 설명 글은 꼭 필요한 줄만 남겨요.

| 카드 | 줄(순서) | 바뀐 점 |
|---|---|---|
| 1 알람이 잘 울리게 | 권한 점검(꺼진 것 있으면 표시), **방해 금지 잠깐 풀기**, 알람 미리 울려 보기 | 방해 금지를 '울리게 하는 것' 묶음으로 옮김(알라미 '울림 최적화'와 같은 자리) |
| 2 알람 | **한 주 시작 요일**(일요일 / 월요일, 시트), 다음 알람 늘 보이기 | 새 줄 |
| 3 소리 | **이어폰, 블루투스로도 울리기**(스위치) | 새 줄. 켜는 순간 연결된 기기가 없으면 토스트 한 줄 |
| 4 미션 중 | 전원 종료 방지 | 그대로 |
| 5 화면 | 날씨 애니메이션 | 그대로 |
| 6 구독 | (구독 화면 생기면) 구독 상태, 구매 복원 | TSK-235와 같이 |
| 7 실험실 | Crazy Mode, 움직이는 버튼, 미션 포기 사용하기, 좀비모드(결정 188) | 그대로 |
| 8 도움 | 자주 묻는 질문, **문의하기**(TSK-267) | 이름 바꿈 |
| 9 앱 정보 | 버전, 오픈소스 라이선스, 개인정보 처리방침 | 처리방침 줄 추가(스토어 필수) |

### 4-1. '한 주 시작 요일' 개발 메모
- 지금 편집 화면은 `EditScreen.kt`의 `DayOrder`(일~토)로 고정, 홈 카드는 `DayOfWeek.entries`(월~일)로 그려요. **이미 두 화면 순서가 달라요.** 설정 하나로 두 곳이 같은 순서를 쓰게 하는 것이 먼저예요.
- 저장된 반복 요일 값(비트)은 그대로이고 보여 주는 순서만 바뀌어요. 이전 값 옮기기 필요 없음.
- '평일', '주말', '매일' 같은 묶음 이름은 순서와 무관해요.

### 4-2. '이어폰, 블루투스로도 울리기' 개발 메모
- 지금 알람 소리는 `USAGE_ALARM` 통로예요. 안드로이드는 이어폰이 꽂혀 있어도 알람 통로를 **폰 스피커와 이어폰 양쪽**으로 내는 경우가 많아요(기기마다 다름). 그래서 '스위치 꺼짐 = 폰 스피커' 처음 값은 지금 동작 그대로예요.
- 켜면 `MediaPlayer.setPreferredDevice()`(API 28+)로 연결된 블루투스(A2DP), 유선 이어폰을 고르고, 없으면 그대로 폰 스피커. 블루투스가 잠든 사이 끊길 수 있어 **울리기 시작할 때마다 다시 확인**해요.
- 위험: 이어폰을 귀에서 뺀 채 자면 알람을 못 들어요. 그래서 처음 값은 꺼짐, 켤 때 시트 한 줄로 알려요. 다시 울림(쉬고 다시 울림) 두 번째부터는 폰 스피커로 돌리는 안전장치도 검토할 만해요.
- QA: Z플립5 + 블루투스 이어폰으로 '켬/끔 × 연결/끊김' 4칸 확인(user 확인).

### 4-3. 방해 금지 정리
- 지금 스위치는 울리는 동안만 방해 금지를 '알람만 허용'으로 잠깐 바꾸고(`AlarmDndOverride`) 끝나면 되돌려요. 방해 금지 접근 권한이 필요해요.
- 사실 안드로이드 기본 방해 금지는 '알람 허용'이 처음부터 켜져 있는 경우가 많아, **이 스위치가 필요한 사람은 방해 금지에서 알람까지 막아 둔 사람**뿐이에요. 그래서 점검 묶음(카드 1)에 두고, 권한 점검 화면에서 '방해 금지가 알람을 막고 있어요'일 때만 강조하는 흐름을 추천해요.
- 하위 안내(폰 설정 가는 길)는 삼성 기준 한 줄 + '기기마다 위치가 달라요' 한 줄이면 충분해요(알라미도 같은 구성).

## 5. 로그인 없이 구글 플레이 계정으로 구독 확인

| 단계 | 하는 일 |
|---|---|
| 1 | 앱을 열 때 Play Billing의 `queryPurchasesAsync(SUBS)`로 지금 폰에 로그인된 구글 계정의 구독을 물어요. 구글 플레이가 계정을 알아서 쓰므로 **우리 앱 로그인이 필요 없어요** |
| 2 | 구매가 있고 `acknowledged`면 유료 기능 열기. 결과를 기기에 저장해 인터넷이 없을 때도 마지막 상태를 써요(알람은 오프라인이 기본) |
| 3 | 새로 산 직후에는 3일 안에 `acknowledgePurchase` 해야 해요(안 하면 자동 환불) |
| 4 | 폰을 바꾸거나 앱을 다시 깔면, 같은 구글 계정이면 1번 조회만으로 그대로 돌아와요. 설정에 '구매 복원' 줄을 두면 사용자가 직접 다시 조회할 수 있어요 |
| 5 | 결제 관리(해지, 결제 수단)는 앱에서 하지 않고 플레이 스토어 구독 화면으로 보내요(딥링크) |

- 한계: 서버 검증이 없으면 조작된 폰에서 뚫릴 수 있어요. 처음엔 기기 안 확인으로 시작하고, 매출이 생기면 Play Developer API로 서버 확인을 더해요(Firebase Functions 등은 공용 프로젝트 README 규칙 먼저).
- 구독은 구글 계정에 묶여 있어서, 알람 설정(기기 안 Room)은 폰을 바꾸면 따라가지 않아요. 알라미는 로그인으로 '알람 불러오기'를 해요. 우리는 출시 뒤 필요하면 안드로이드 자동 백업(Auto Backup)으로 로그인 없이 옮기는 것을 먼저 검토해요.
