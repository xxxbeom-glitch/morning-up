# I. 유료 모델 방향과 '확실히 잠깨기' 유료 기능 조사

- 조사일: 2026-11-24 / 담당: [리서치 1] / 일: TSK-169
- 이 문서는 **법률 자문이 아니라 조사**예요. 법 조항, 플레이 정책은 출시 전에 원문과 전문가 확인이 필요해요.
- 가격, 비율은 조사일 기준이고 지역, 시기에 따라 바뀌어요. 출처가 없거나 약한 숫자는 그렇다고 적었어요.

---

## 0. 결론 먼저

1. **방향은 맞아요.** "다른 앱에서 돈 내는 기능(미션 묶기, 기상 확인, 다시 잠들기 방지, 광고 없음)은 무료, 우리 유료는 '확실히 잠깨기'"는 알라미와 정면으로 겹치지 않는 자리예요. 단, **스토어 글과 광고에 '알라미' 이름을 쓰지 않아요**(플레이 메타데이터 정책 위험). "다른 앱에선 유료인 기능을 무료로"처럼 써요.
2. **'유료 사용자 5%'는 확인되지 않았어요.** 찾은 숫자는 2021년 **약 1.6%**(월 사용자 450만 명 중 유료 약 7만 명)예요. 그래도 구독이 매출의 약 28~40%라서, 소수 유료 사용자가 꽤 큰 돈을 낸다는 점은 맞아요.
3. **2주 무료 → 3개월 매달 100원은 구글 플레이에서 만들 수 있어요.** 한 혜택(offer)에 '무료 체험 + 할인 반복 결제' 두 단계를 넣을 수 있고, 한국 최저 가격은 70원이라 100원도 돼요. 대신 **우리 손에 남는 돈은 한 달 약 77원**이라 수익은 사실상 0이고, **넉 달째 정가로 바뀔 때 별점 1점과 해지가 몰릴 위험**이 커요. 한국 전자상거래법상 **무료 → 유료로 넘어갈 때 따로 명시적 동의**를 받아야 해요.
4. **버튼 속이기(아이디어 1, 가짜 버튼 섞기)는 '확실히 잠깨기'의 얼굴이 될 만한 후보예요.** 깨우는 힘이 가장 직접적이고 눈에 띄어서 홍보 영상 한 컷으로 설명돼요. 대신 접근성, 별점 위험이 가장 커서 안전장치(기본 꺼짐, 시간 상한)가 꼭 필요해요. 아이디어 2(여러 번 묻기)는 결정 145를 늘리는 거라 가장 싸고 안전해요. 둘을 같은 무게로 1순위 묶음에 넣었고, 그 밖에 후보 8개를 아래 4번에 적었어요.
5. **추천안:** 1차 출시는 유료 없이 내고, '확실히 잠깨기' 2~3개를 **무료 '실험실(베타)'** 로 먼저 써 보게 해서 실제로 켜는 사람 비율을 봐요. 2차에 유료로 바꿀 때는 **2주 무료 → 첫 달 100원 → 월 정가**(3개월이 아니라 1개월)로 하고, 정가를 처음부터 크게 보여 줘요. 이유는 7번.

읽는 법
- 알라미는 **광고가 주 수입**이고 구독은 3분의 1이 안 돼요. 그래서 알라미는 광고를 줄이기 어렵고, 알람 끄는 화면 광고가 리뷰 불만 1위예요([A-competitors.md](A-competitors.md)).
- 유료 사용자는 1~2%대일 가능성이 커요. 이들이 돈을 내는 이유는 주로 **광고 제거 + 확실히 깨는 기능(기상 확인, 다시 잠들기 방지)** 이에요. 즉 우리 목표 고객과 '확실히 잠깨기'가 정확히 같은 사람들이에요.

## 3. '알라미 유료 기능 무료 + 하드코어 유료' 방향 평가

| | 내용 |
|---|---|
| 장점 1 | 메시지가 한 줄로 쉬워요: "다른 앱에선 돈 내는 기능, 여기선 무료" |
| 장점 2 | 무료 범위가 넓어서 별점과 입소문에 유리해요. 광고 제거 옵션을 없앤 알람몬이 반대 사례예요 |
| 장점 3 | 유료 상품이 '편의'가 아니라 '더 센 경험'이라 무료 사용자가 손해 본다는 느낌이 적어요 |
| 위험 1 | 알라미 유료 사용자는 1~2%대라 **데려올 수 있는 사람 자체가 적어요.** 이들은 이미 알라미 미션, 기록에 익숙해서 옮기는 데 이유가 하나 더 필요해요 |
| 위험 2 | 무료가 너무 좋으면 유료 전환율이 아주 낮을 수 있어요. '하드코어'를 원하는 사람이 얼마나 되는지 아직 모름 |
| 위험 3 | 스토어 글, 광고에 '알라미'를 넣으면 플레이 메타데이터 정책(다른 앱 이름 언급, 키워드 끼워 넣기)에 걸릴 수 있어요. 비교 광고는 한국 표시광고법상 사실이고 객관적이어야 해요 |
| 위험 4 | '짜증 나는 기능'은 잘못 만들면 "안 꺼져요" 별점 1점으로 바로 돌아와요(아래 6번) |
| 대안 A | **유료 없이 무료 + 후원(커피 한 잔) 버튼.** 가장 가볍지만 수익 거의 없음 |
| 대안 B | **평생 이용권 한 번 결제**(예: 9,900원 안팎). 구독 자동 갱신 규제와 '넉 달째 요금 폭탄' 걱정이 없어요. 대신 꾸준한 수입은 없음 |
| 대안 C | **소리, 미션 팩 낱개 판매**(사극 벨소리, 역한 소리 팩 등). 플레이 정책상 일회성 혜택은 구독이 아니라 낱개 상품으로 팔아야 해요 |

판단: 방향은 유지하되, **유료가 정말 팔리는지는 무료 '실험실'로 먼저 재 보는 것**이 안전해요.

## 4. '확실히 잠깨기' 유료 기능 후보

모든 후보에 공통으로 붙일 안전장치
- 기본은 꺼짐. 사용자가 낮에 직접 켜고, 켜기 전에 '미리 해보기'로 맛보기.
- **시간 상한**: 어떤 기능이든 일정 시간(예 60초)이 지나면 보통 모드로 돌아가요. 알람이 영영 안 꺼지는 일은 없게.
- 통화 중, 긴급 전화, 접근성 기능(TalkBack 등)을 켠 상태에서는 자동으로 보통 모드.

### 사용자 아이디어 평가

| 아이디어 | 깨우는 힘 | 짜증 | 위험 | 만들기 | 평가 |
|---|---|---|---|---|---|
| 1. 도망가는 '알람 끄기' 버튼 (왔다 갔다, 사라졌다 나타남) | 높음. 눈을 뜨고 손을 써야 해요 | 높음 | 화면 접근성, 잠결 오작동, "버그인 줄 알았다" 리뷰 | 보통 | **추천(1순위).** 이 상품을 가장 잘 보여 주는 기능이에요. "알람 끄기부터가 미션"이라는 철학과 딱 맞고, 다른 알람 앱에서 흔하지 않아요. 단계(살짝 흔들림 → 자리 바꿈 → 숨바꼭질 → 가짜 버튼 섞기, 3번)를 두고 '일정 시간 지나면 멈춤' 상한을 둬요 |
| 2. '정말 깼어요?' 여러 번 | 높음. 다시 잠드는 걸 막아요 | 보통 | 알림이 늦게 오면 실패. 배터리 | 낮음(결정 145 확장) | **추천(1순위).** 결정 145의 '바퀴 상한 2번, 확인 1번'을 유료에서 '확인 3~5번, 간격 무작위'로 늘려요. 이미 만드는 구조를 재활용해요. 눈에 덜 띄지만 실제 '다시 잠듦'을 막는 힘은 가장 커요 |

1번과 2번 비교: 1번은 **끄는 순간**을, 2번은 **끈 뒤 다시 잠드는 것**을 막아요. 겹치지 않아서 둘을 함께 묶을 때 가장 센 상품이 돼요. 만들기 부담은 2번이 작고, 알리기 쉬운 건 1번이에요.

### 1번(버튼 속이기)을 만들 때 생각할 것

참고: 11-16에 울림 화면 버튼이 떠다니는 시안은 한 번 빠졌지만, 사용자가 지금 방향을 다시 정하는 중이라 **막는 조건이 아니라 참고**로만 봤어요. 그때 걱정(울림 화면이 복잡해짐)은 '기본 화면은 그대로, 켠 사람만 움직임'으로 풀 수 있어요.

| 항목 | 기본(무료) | 유료 옵션 켬 |
|---|---|---|
| 화면 구성 | 하늘, 날짜, 시각, 버튼 | 같음(버튼만 움직임) 또는 가짜 버튼 추가 |
| 버튼 | 제자리 | 움직임, 숨기기, 가짜 섞기 중 강도 고르기 |
| 켜는 곳 | - | 전체 설정의 '확실히 잠깨기'(결정 145처럼 앱 전체 설정) |
| 끝 | - | 일정 시간(예 15~30초, 값은 정함) 뒤 제자리로 멈춤 |
| 정할 것 | - | 강도 단계 수, 상한 시간, 미션 시작 버튼에도 걸지(미션 있는 알람) 아니면 '알람 끄기'(미션 없는 알람)에만 걸지 |

## 5. 2주 무료 → 3개월 매달 100원, 플레이에서 되나

### 한국 법에서 걸리는 점 (법률 자문 아님)
- 2025-02-14부터 개정 전자상거래법: **무료 → 유료 전환, 정기결제 금액 증액 때 결제일 전 30일 안에 소비자에게 따로 명시적 동의**를 받고, 가격과 해지 방법을 알려야 해요. "거부 안 하면 동의" 방식과 가입 때 한꺼번에 받은 동의는 인정 안 됨. 위반 시 과태료 최대 500만 원 또는 영업정지. ([법률신문](https://www.lawtimes.co.kr/news/articleView.html?idxno=205545), [뉴시스 Q&A](https://www.newsis.com/view/NISX20250213_0003063585), [정책브리핑](https://www.korea.kr/news/policyNewsView.do?newsId=156721985))
- 해설상 **기존 가입자에게 준 일시적 할인이 끝나는 것은 '증액'이 아니라고** 봐요(같은 법률신문 기사). 그래도 100원 → 정가는 체감상 큰 인상이라 미리 크게 알리는 게 안전해요.
- '순차공개 가격'(처음엔 싼 값만 보여 주고 나중에 진짜 값 공개)도 다크패턴 금지 유형이에요. **결제 화면에 정가를 100원만큼 크게** 보여 줘야 해요.
- 구글 플레이의 기본 체험 종료 알림만으로 한국법의 '명시적 동의'가 채워지는지는 확인하지 못했어요. **출시 전 확인 필요.** 앱 안에서 체험 끝나기 전 '계속 쓸래요' 동의 화면을 따로 두는 쪽이 안전해 보여요.

|---|---|---|---|
| 가입 문턱 | 아주 낮음 | 아주 낮음 | 보통 |

정가는 아직 정할 근거가 없어요. 알라미 미국 월 $4.99보다 확실히 싸게(예: 월 1,900원, 연 12,000원) 가설로 두고, 실험실 데이터로 정하는 걸 추천해요.

## 7. 추천안

**1차 출시는 유료 없이 내고, '확실히 잠깨기'를 무료 실험실로 먼저 열어요. 2차에 유료로 바꿀 때는 '2주 무료 → 첫 달 100원 → 월 정가'로 해요.**

| 단계 | 할 일 |
|---|---|
| 1차 출시 | 무료에 미션 묶기, 기상 확인(결정 145), 다시 잠들기 방지, 광고 없음 그대로. 설정에 '확실히 잠깨기(실험실)'로 2번(여러 번 묻기), 1번(도망 버튼) 두 개만 무료로 열고, 켠 사람 비율과 끄기까지 걸린 시간을 기록 |
| 판단 | 실험실을 켜는 사람이 의미 있게 많으면 유료화. 적으면 대안 B(평생 이용권)나 C(소리 팩)로 |
| 2차 유료화 | 실험실 기능 + 3, 5, 6번을 묶어 구독. 2주 무료 → 첫 달 100원 → 월 정가(예: 1,900원, 가설). 실험실 때 쓰던 사람은 '얼리버드' 혜택 |

이유
1. 사용자 말대로 지금 가장 중요한 건 사용자 확보예요. 유료 결제 화면이 없으면 출시 심사, 한국법 동의 절차, 환불 처리를 1차에 전부 건너뛸 수 있어요.
2. '하드코어를 원하는 사람이 있는가'가 이 모델의 가장 큰 가정인데, 실험실로 돈 안 들이고 확인할 수 있어요.
3. 100원 기간을 3개월에서 1개월로 줄이면 사용자 확보 효과는 거의 같고, 넉 달째 '요금 폭탄' 리뷰 위험과 진짜 지불 의사를 아는 시간이 크게 줄어요.
4. 1번(버튼 속이기)과 2번(여러 번 묻기)은 막는 시점이 달라 함께 있을 때 가장 세고, 2번은 결정 145 구조를 그대로 써서 개발 부담이 작아요. 1번은 실험실에서 별점, 접근성 반응을 먼저 보기에 가장 좋은 후보예요.

## 8. 사용자에게 물을 것

1. 1차 출시에 '확실히 잠깨기'를 **무료 실험실**로 먼저 넣을지, 아니면 처음부터 유료로 낼지.
2. 100원 기간을 **3개월 그대로** 둘지, **1개월로 줄일지**.
3. 버튼 속이기의 강도 단계와 시간 상한(예 15~30초), 접근성 기능 켠 사람은 자동으로 끄는 규칙에 동의하는지.
4. 출시판에 광고를 넣을지(광고 없음이 이 모델의 전제예요).
