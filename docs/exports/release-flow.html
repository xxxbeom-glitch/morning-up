지금부터 구글 플레이 출시까지

앱 기능은 0~10단계 개발을 한 바퀴 다 돌았어요. 남은 일은 대부분 고치고, 시험하고, 등록하는 일이에요.

9단계출시까지 남은 큰 단위
5~7주출시 전까지 예상 기간
계정 있음'루미안' 계정, 온톡 출시 경험

지금 바로: 판매자 상태 선언

플레이 콘솔에 알림이 떠 있어요. 하지 않으면 계정의 앱(온톡 포함)이 삭제될 수 있어요. 사용자가 직접 제출하고, 넣을 정보는 그때 같이 골라요.

기한: 2027년 2월 전
