섞어 쓰기 설명

줄 하나에 상태 표시를 하나만 두자는 뜻이에요. 같은 다섯 줄을 지금 모양과 섞어 쓰기 모양으로 그렸어요(예시 값).

지금라벨 아래 값 + 오른쪽 토글

미루기
5분, 3번
다시 잠들기 방지
꺼짐
좀비모드
3분, 3번
다음 알람 항상 표시
상태 바에 보여요
이어폰, 블루투스로 울리기
꺼짐

켜짐을 토글과 값 글자로 두 번 보여 줘요. 줄을 누를지 토글을 누를지 헷갈려요.

섞어 쓰기줄마다 표시 하나

미루기
5분, 3번
다시 잠들기 방지
끔
좀비모드
3분, 3번
다음 알람 항상 표시
이어폰, 블루투스로 울리기

위 세 줄은 누르면 시트가 열리고, 끄기는 시트의 '안 함'. 아래 두 줄은 토글만 눌러요.

섞어 쓰기 규칙 세 가지
  1. 고를 값이 있는 줄: 값은 오른쪽, 화살표, 토글 없음. 끄면 값이 '끔' 또는 '안 함'(연한 글자색).
  2. 켜고 끄기만 있는 줄: 토글만, 아래 글 없음.
  3. 그래서 모든 줄이 한 줄 높이(52)로 같아지고, 지금 설정 메인과 같은 모양이 돼요.
