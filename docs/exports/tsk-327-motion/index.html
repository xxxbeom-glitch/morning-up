정할 것

  1. 권한 시트 그림을 두 가지로 나눌까요? 추천은 나누기예요. 알림은 팝업형, 전체 화면 알림과 다른 앱 위에 표시는 설정 스위치형이에요. 실제 폰에서 뜨는 화면이 서로 달라서요.

  4. 미션 오답은 추천이 빨간 칠 600ms만이에요. 흔들기는 넣지 않아요.
