Crazy Mode 제목 타이포 레퍼런스

설정 맨 위 구독 카드의 제목을 로고처럼 보이게 할 방향 네 가지예요. 방향마다 깊은 밤 배경에 추천 글자를 먼저 보여 주고, 그 아래에 모은 화면을 붙였어요. 화면은 모두 Mobbin에서 가져왔어요.

A. 굵고 좁은 글자, 기울임

CRAZY MODE추천: Barlow Condensed Black Italic, 대문자
폰트 라이선스: SIL OFL 1.1 (상업적 무료)

B. 그라데이션 글자

Crazy Mode추천: Unbounded Black, 보라에서 분홍, 주황(새벽빛)
폰트 라이선스: SIL OFL 1.1 (상업적 무료)

C. 손글씨, 마커

Crazy Mode추천: Crazy만 Permanent Marker, Mode는 Pretendard Bold
폰트 라이선스: Apache 2.0 (상업적 무료)

D. 테두리 글자, 네온 라벨

Crazy Mode추천: Unbounded Black 테두리만 + 보라 빛 번짐
폰트 라이선스: SIL OFL 1.1 (상업적 무료)
TSK-316. 시안 A(굵은 기울임), B(그라데이션)는 피그마 '결정 필요' 구역에 실제 카드로 올려 두었어요.
