TSK-308 진단, 11-28, [기획 13]

일어나 화면 흐름 진단

11-27 메모 30여 개를 화면에 붙여 보니, 하나하나 따로 고칠 문제가 아니라 원인 여섯 가지에서 나온 증상이었어요. 원인을 먼저 고치려면 디자인 전에 세 가지를 정해야 해요. 아래는 결론, 알라미와 나란히 본 흐름도, 원인, 고칠 안, 디자인 순서 차례예요.

결론 먼저

먼저 정할 것 ①설정은 세 층으로

맨 위 Crazy Mode 카드(구독 겸함, plus_label), 그 아래 '알람이 꼭 울리게' 핵심 카드, 그 아래 일반 카드. 서브 라벨과 한 주 시작은 지워요.

먼저 정할 것 ②간격은 '미루기' 한 곳에서만

지금은 미루기, 다시 울림, 다시 잠들기 방지, 좀비모드에 간격이 네 번 나와요. 아무도 안 끄면 '알람 자동 해제' 시간 뒤 멈추고, 미루기 간격만큼 쉬었다 다시 울려요.

먼저 정할 것 ③문구는 갤럭시 메뉴 이름 그대로

폰 설정 이름은 폰에 보이는 글자 그대로 작은따옴표로, 설명은 한 문장에 할 일 하나. 명칭 표를 먼저 만들고 전체 문구 순화에 같이 넘겨요.

그다음 디자인 순서C 부품 규칙 → A 설정 → D 안내 → B 온보딩 → E 애니메이션

다른 묶음이 기대는 규칙부터 정하고, 결정이 끝난 설정을 그다음에 그려요.

알라미와 일어나, 화면 흐름 나란히 보기

단계마다 위 줄이 알라미(11-25, 11-26 Z플립5 캡처), 아래 줄이 일어나(피그마 11-27 구역 최신 시안)예요. 그림을 누르면 크게 보여요. 주황 테두리와 숫자는 메모에서 UX 문제로 짚은 화면과 메모 번호예요(메모 3~9의 요청은 +로 표시).

메모별 문제와 자리

메모 번호마다 어느 화면인지, 어느 원인에서 나왔는지, 어느 디자인 묶음에서 고치는지예요. 원인 기호는 다음 절의 R1~R6이에요.

원인 분석

증상을 모아 보면 여섯 갈래예요. 원인을 하나 고치면 메모 여러 개가 같이 풀려요.

먼저 정할 것 ① 설정 화면 구조

알라미 설정은 구독 → 전원 끄기 방지 → 앱 삭제 방지를 다른 레벨로 맨 위에 두고, 그 아래 '알람 울림 최적화', '알람 고급설정', '테마'처럼 목록이 이어져요(캡처 76, 77). 우리 T1은 모든 줄이 같은 카드, 같은 글자 크기라 무엇이 중요한지 안 보여요(R1).

먼저 정할 것 ② 스누즈를 켰을 때 다시 울림 간격

지금 알람 하나에 '간격'을 고르는 자리가 네 곳이에요. 미루기(S9, 눌러서 미룸), 다시 울림(S3, 아무도 안 끄면 저절로), 다시 잠들기 방지(S4, 끈 뒤 깨어 있는지 물음), 좀비모드(T3-5). 이름도 '다시'가 겹치고 횟수 단위도 '번'과 '회'가 섞여 있어요(S9 '3번', T3-5 '3회'). 메모의 "다시 울림 간격은 어떻게 조정돼?"는 이 겹침 때문에 생긴 질문이에요(R6).

알라미는 알람마다 '알람 미루기'(간격과 횟수, 캡처 29), 모든 알람에 '알람 자동 해제'(설정 고급, 캡처 80) 둘뿐이에요. 미루는 동안 화면에는 남은 시간과 남은 횟수를 보여 줘요(캡처 49).
