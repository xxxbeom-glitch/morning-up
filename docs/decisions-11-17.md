# 11-17 논스탑 개발 중 정한 것

사용자가 자리를 비운 동안 "묻지 말고 끝까지, 정해지지 않은 건 추천안으로"라는 지시에 따라 정한 것들이에요. 바꾸고 싶으면 말해 주세요.

| # | 무엇 | 이렇게 정함 | 이유 |
|---|---|---|---|
| 1 | 방해 금지 모드 예외 | 줄은 시안대로 T2-A '필수 권한' 카드에 두되, 꺼져도 경고(빨간 삼각형, 배너)는 띄우지 않음 | 알람은 알람 소리 통로로 울려서 방해 금지 중에도 보통 울려요(dev-plan 6단계 '빼자고 제안') |
| 2 | 삼성 '절전 예외 앱에 추가' 줄 | 토글 대신 화살표, 누르면 기기 배터리 화면 | 앱에서 켜졌는지 알 수 없어서 토글을 그리면 틀린 값을 보여요 |
| 3 | 알람 음량 줄 | 누르면 기기 볼륨 창 | 알람 음량은 권한이 아니라 기기 볼륨이라서요 |
| 4 | 권한 줄 누름 | 지금은 바로 기기 설정 화면으로 보냄. P1~P4 안내 창은 뒤 단위에서 그 사이에 넣음 | |
| 5 | 디버그 빌드 음소거 | 디버그 빌드만 알람 소리, 미리듣기 소리를 0으로. 진동은 그대로 둠 | 사용자 지시(벨소리 mute). 진동이 있어야 울리는지 손으로 알 수 있어요. 출시 빌드는 영향 없음 |
| 6 | H2 배너 문구 | 꺼진 필수 권한 중 맨 앞 하나만 배너에 보여 줌. '켜기'는 그 권한의 기기 설정으로 바로 보냄 | 배너가 길어지지 않고, 나머지는 설정 탭 경고 아이콘과 T2에서 보여요 |
| 7 | P1~P4 요청 창 | 꺼진 권한 줄을 누르면 공용 Dialog(나중에, 허용하기)를 먼저 띄우고 기기 설정으로 보냄. 켜진 줄은 바로 기기 설정 | 피그마 P1~P4 문구 그대로. 다른 앱 위에 표시, 방해 금지, 알람 음량 창은 그림이 없어 같은 모양과 새 문구로 만듦 |
| 8 | 알림 권한 묻기 | 안드로이드 13 이상에서 알림 권한 자체가 없으면 시스템 요청 창을 먼저 띄우고, 거절되면(두 번 거절해 시스템이 더 묻지 않을 때 포함) 앱 알림 설정으로 보냄 | '설정에서 켜 주세요' 안내 창을 따로 만들지 않아도 돼요 |
| 9 | 첫 저장 때 묻기(F21) | 첫 알람을 저장하고 홈에 돌아온 뒤 0.7초 있다가 알림, 전체 화면 알림, 배터리 순서로 꺼진 것만 한 번씩 묻고 다시 묻지 않음. 앱을 열 때 띄우던 알림 권한 창은 뺌 | 앱을 열 때마다 팝업을 띄우지 않는다는 기획(F21) |
| 10 | 전원 종료 방지 동작 | 접근성 서비스가 창 바뀜 신호의 앱 이름과 창 종류만 보고, 전원 메뉴(GlobalActions)면 '뒤로'로 닫음. 화면 내용 읽기는 끔. 전원 종료 방지를 켠 미션 알람의 미션 중일 때만 동작 | P6 약속('화면 내용은 읽거나 저장하지 않아요')을 지키는 가장 작은 방법이에요. 삼성 전원 메뉴 이름은 실기기에서 다시 확인해요 |
| 11 | P6, P7 흐름 | T2-A '선택 권한' 카드 줄이나 알람 편집 '전원 종료 방지' 토글을 켤 때 서비스가 꺼져 있으면, 처음엔 P6 동의, 동의한 뒤로는 P7 안내로 바로 감 | 피그마 'S0나 T2-A에서 토글을 켤 때 처음 한 번' |
| 12 | P7 '이렇게 찾아요' 움직임 카드 | 아직 넣지 않음. 3단계 글 카드와 '접근성 설정 열기' 버튼만 | 스켈레톤 장면과 움직임 다듬기가 남은 일로 기록돼 있어요(11-16) |
| 13 | 자주 묻는 질문 | 앱 안 접었다 펴는 목록 7개(안 울림, 잠금 화면, 미션 못 끝냄, 진동만, 공휴일, 이번만 쉬기, 전원 종료 방지) | 문구는 새로 씀. 손님이 보는 글이라 가운뎃점과 긴 줄표를 쓰지 않았어요 |
| 14 | 개인정보 처리방침 줄 | 아직 넣지 않음 | 방침 글과 올릴 주소가 없어요. 10단계 출시 준비에서 넣어요 |
| 15 | T5 오픈소스 라이선스 | 쓰는 라이브러리 이름과 라이선스 목록, Pretendard OFL 전문은 접었다 펴기 | 구글 라이선스 플러그인은 Play 서비스 의존이 생겨서 쓰지 않았어요 |
| 16 | H8 '내일 다시 켜기' 쉬는 날 | 누르면 알람을 켜고 바로 다음 한 번 울릴 날짜만 건너뛰어요. 카드는 꺼진 모양에 '○요일에 다시 울려요'. 쉬는 중 카드의 토글을 켜면 쉬기를 풀어요 | 엔진에 이미 있는 '한 번 건너뛰기 날짜'를 그대로 써요 |
| 17 | '내일 다시 켜기' 버튼이 남는 동안 | 이번에 앱을 켜 둔 동안만 보여요(앱을 완전히 닫으면 사라짐) | 끈 직후에만 묻는 버튼이라 따로 저장하지 않았어요 |
| 18 | H3 선택 모드 '삭제' | 확인 창을 먼저 띄우고, 지운 뒤 '되돌리기'로 모두 되살려요. 길게 누르면 바로 삭제 확인 대신 선택 모드로 들어가요 | 피그마 'H4 시트 폐기, 길게 누르면 선택 모드' |
| 19 | H3 선택 모드 '복사' | 고른 알람을 같은 설정으로 하나씩 더 만들고 토스트 '알람 ○개를 복사했어요' | 시안에 복사 뒤 화면이 없어서 가장 작은 안 |
| 20 | 선택 모드 하단 바 | 하단 메뉴를 숨기고 같은 자리에 켜기, 끄기, 복사, 삭제 바. 아무것도 안 골랐으면 복사와 삭제는 흐리게 | 휴대폰 '뒤로'는 선택 모드를 닫아요 |
| 21 | 더보기 메뉴 모양 | 흰 카드(모서리 카드와 같음) 안에 아이콘 20과 글자 줄 두 개 | 피그마 Menu Item 부품 크기를 자세히 못 맞춰서, 폰 확인 뒤 다듬을 수 있어요 |
