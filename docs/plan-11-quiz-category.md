# Pop Quiz 분야 고르기 기획 (TSK-269)

- 작성: [기획 11], 2026-11-27. 11-16 사용자 확정 '고르는 줄 없이 섞어서 무작위'를 이 일로 바꿔요(Leader가 결정 번호를 매겨요).
- 문제 은행: `feature/mission/src/main/res/raw/mission_content.json` `popQuiz` 350문제, 분야 7개(`QuizCategory`).

## 결론

- Pop Quiz 미션 설정 시트에 **'분야' 줄**을 넣고 7개 분야를 칩으로 **여러 개** 골라요. 처음 값은 **전체**(지금과 같음).
- 하나 이상은 꼭 남아요. 고른 분야의 그 단계 문제가 10개보다 적으면 **같은 분야의 옆 단계 문제를 빌려** 채워요(문제가 금방 반복되지 않게).
- 알람 편집 미션 줄 값에 분야가 '전체'가 아닐 때만 붙여요. 예: '1단계, 3문제, 과학 용어 외 1개'.

## 1. 분야 목록과 문제 수

| 분야(화면 이름) | 키 | 전체 | 단계별(1~7) | 가장 적은 단계 |
|---|---|---|---|---|
| 경제 용어 | Economy | 56 | 6, 6, 5, 11, 8, 13, 7 | 3단계 5개 |
| 사회 용어 | Society | 55 | 9, 6, 8, 10, 7, 9, 6 | 2, 7단계 6개 |
| 국사 | KoreanHistory | 55 | 7, 8, 8, 5, 12, 6, 9 | 4단계 5개 |
| 세계사 | WorldHistory | 45 | 6, 7, 7, 5, 5, 6, 9 | 4, 5단계 5개 |
| 과학 용어 | Science | 64 | 10, 10, 15, 5, 9, 9, 6 | 4단계 5개 |
| 인물 | People | 38 | 6, 7, 4, 5, 4, 4, 8 | 3, 5, 6단계 4개 |
| 사회 이슈 | Issues | 37 | 6, 6, 3, 9, 5, 3, 5 | 3단계, 6단계 3개 |

- 한 분야만 고르면 단계마다 3~15문제라, 문제 수를 5로 두면 며칠 만에 같은 문제가 다시 나와요. 그래서 2절의 '빌려 채우기'를 둬요.
- 분야 이름은 지금 미션 화면 위에 보이는 이름(`mission_quiz_category_*`)을 그대로 써요.

## 2. 문제 고르는 규칙

1. 문제 묶음 = 고른 분야 중 그 알람 단계의 문제.
2. 10개보다 적으면 고른 분야의 한 단계 아래, 한 단계 위 문제를 더해요. 그래도 적으면 두 단계 아래, 위까지. 같은 분야 안에서만 빌려요.
3. 나머지 규칙(다 내기 전엔 같은 문제 안 나옴, 틀리면 새 문제, 정답 안 보여 줌)은 지금 `PopQuizGame` 그대로예요.
4. 문제 은행이 바뀌어도 이 규칙이면 따로 손댈 것이 없어요.

## 3. 화면 (S1 Pop Quiz 설정 시트)

| 자리 | 내용 |
|---|---|
| 줄 순서 | 예제 → 난이도 → 문제 수 → **분야**(새로, 맨 아래) |
| 분야 줄 | 제목 '분야', 오른쪽 작은 글 '전체' 또는 'n개 골랐어요' |
| 칩 | '전체' 칩 + 7개 분야 칩, 두 줄로 감김. 고른 칩은 칠로 표시(테두리 금지 규칙, Choice Chip 부품) |
| 전체 칩 | 누르면 7개 모두 고름. 7개가 다 골라져 있으면 전체 칩도 칠해져 있음. 다 골라진 상태에서 분야 칩 하나를 누르면 그 하나만 빠짐 |
| 마지막 하나 | 하나만 남았을 때 그 칩을 누르면 빠지지 않고 토스트 '분야를 하나 이상 골라 주세요' |
| 예제 영역 | 고른 분야 중 하나의 예제를 보여 줘요(지금 예제 배열에 분야를 붙여야 함, 개발 메모) |
| 미리보기 | 고른 분야로 문제를 내요 |

- 미션 설정 화면은 [디자인] TSK-264(크게, 드럼롤 방식)로 다시 그리는 중이에요. 분야 줄은 그 시안의 맨 아래에 넣도록 TSK-264에 댓글로 알려요.

## 4. 새 문구

| 리소스 | 문구 |
|---|---|
| `edit_mission_category` | 분야 |
| `edit_mission_category_all` | 전체 |
| `edit_mission_category_count` | %1$d개 골랐어요 |
| `edit_mission_category_min` | 분야를 하나 이상 골라 주세요 |
| `edit_mission_value_questions_category` | %1$d단계, %2$d문제, %3$s |
| (분야 요약) | 하나면 그 이름, 둘 이상이면 `ui_mission_more` 모양('과학 용어 외 1개') |

## 5. 개발 메모

- `MissionSetting`에 `quizCategories: Set<QuizCategory>`를 더해요. 처음 값은 전체이고, 전체일 때는 저장하지 않아요(`EncodeDefault.Mode.NEVER`, `forTest`와 같은 방식). 옛 저장값은 전체로 읽혀요.
- `PopQuizGame`의 `pool`을 2절 규칙으로 바꿔요. 시험: 사회 이슈만, 3단계, 5문제일 때 묶음이 10개 이상인지.
- Pop Quiz가 아닌 미션에는 이 값이 없어요.
