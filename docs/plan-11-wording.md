# 앱 문구 정리: 알람/알림 용어 기준과 바꿀 문구 표 (TSK-256, TSK-265, TSK-232)

- 작성: [기획 11], 2026-11-27. 근거: 결정 192(알람과 알림을 사전 뜻대로, 제목만으로 이해되면 설명 글 뺌), 11-27 사용자 문구 목록, 결정 178(문구는 우리 것).
- 이 문서만 보고 개발이 `strings.xml`을 바로 고칠 수 있게 **파일, 리소스 이름, 지금 문구, 새 문구**를 적었어요.
- 사용자 원문을 그대로 쓴 줄은 '사용자' 표시를 했어요. 띄어쓰기만 맞춤법대로 고친 곳은 따로 적었어요.
- 실험실 이름(결정 188)은 [개발 26]이 TSK-261로 바꾸는 중이라 이 표에서는 겹치지 않게 빼고, 설명 글만 맞췄어요.

## 결론

| 무엇 | 정한 것 |
|---|---|
| 알람 | 사용자가 정한 시각에 **울리는 것**. 화면, 버튼, 설정 이름에서 울림과 관련된 것은 모두 '알람' |
| 알림 | 폰 **알림 패널**에 뜨는 메시지. 안드로이드 공식 이름(알림 권한, 전체 화면 알림)도 '알림' |
| 끄기와 해제 | 울리는 알람을 멈추는 것은 **해제**, 알람 스위치를 내리는 것은 **끄기** |
| 재확인 | 알람 해제 뒤 다시 잠들었는지 묻는 것(W2, W3)은 **재수면 여부를 재확인**. 그만두는 것은 **재확인 해제** |
| 바꿀 문구 | 약 70개 리소스(아래 3절). 사용자 목록 전부와 TSK-232('정말 깼어요?') 포함 |
| 새로 만들 리소스 | 4개(`edit_title_new`, `home_wake_check_soon_band_now`, `home_recheck_release`, `recheck_release_action`) |
| 지울 리소스 | 설명 글 8개(4절 1~8번, TSK-265). `edit_mission_add_desc` 포함 |

## 1. 용어 기준표

| 쓸 말 | 뜻 | 이렇게 써요 | 이렇게 쓰지 않아요 |
|---|---|---|---|
| 알람 | 정한 시각에 울리는 것, 그 설정 하나 | 알람이 울려요, 알람 생성, 다음 알람 | ~~알림이 울립니다~~ |
| 알림 | 폰 알림 패널의 메시지, 알림 권한 | 알림 권한, 전체 화면 알림, 알림 패널 | ~~알람 창~~ |
| 알림 패널 | 위에서 끌어내리는 알림 목록 | 시스템 알림 패널에 보여줘요 | ~~알림창, 알림 창, 노티바~~ |
| 해제 | 울리는 알람을 멈춤(미션, 버튼, 미션 포기) | 알람을 해제했어요, 눌러서 알람을 해제하세요 | ~~알람을 꺼요, 알람을 껐어요~~ |
| 끄기, 켜기 | 알람 스위치, 설정 스위치 | 모든 알람 끄기, 이번만 쉬기 | ~~알람 해제(스위치 뜻으로)~~ |
| 예정된 알람 | 아직 울리지 않은, 켜진 알람 | 예정된 알람이 없어요 | ~~울릴 알람~~ |
| 알람 생성 / 알람 편집 | 새로 만들 때 / 이미 있는 것을 고칠 때 | 제목만 나눠요 | ~~새 알람인데 '알람 편집'~~ |
| 재수면 여부 재확인 | W2, W3로 다시 잠들었는지 묻는 것 | n분 후 재확인할게요 | ~~깼는지 물어볼게요, 한 번 더 물어볼게요~~ |
| 재확인 해제 | 남은 재확인을 그만둠(TSK-266) | 재확인을 해제해주세요 | ~~확인 멈춤~~ |
| 방해 금지 모드 | 폰의 방해 금지 | 방해 금지 모드에서 허용하기 | ~~방해 금지 잠깐 풀기~~ |
| 미션 | 알람을 해제하려고 푸는 것 | 미션 시작 | |

- 말끝: 앱 화면은 해요체가 기본이에요. 사용자가 직접 준 문구('~하세요', '~해주세요', '~할게요')는 그대로 써요.
- 사용자 원문 '방해금지모드'는 맞춤법대로 '방해 금지 모드'로 띄어 써요. 뜻은 같아요.
- '폰'과 '스마트폰': 사용자가 준 흔들기 설명만 '스마트폰', 나머지 화면은 지금처럼 '폰'(짧아서). 바꾸려면 한 번에 바꿔요.
