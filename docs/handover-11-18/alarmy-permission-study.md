# 알라미 권한 조사 (11-18)

기기: 갤럭시 S24+ (안드로이드 17 빌드), 알라미 26.43.0 (`droom.sleepIfUCan`), 지운 뒤 다시 깔고 처음 실행.
회전 처음 값: accelerometer_rotation 0, user_rotation 0.
시험 알람 볼륨: 알라미 편집 화면 볼륨 막대 약 5%.

## 처음 깔았을 때 권한 상태 (dumpsys)
| 권한 | 처음 상태 |
|---|---|
| 정확한 알람 | `USE_EXACT_ALARM` 설치 때 자동 허용 (사용자가 끌 수 없음) |
| 전체 화면 알림 | 처음부터 허용 |
| 방해 금지 접근 | 일반 권한만 허용, 실제 접근 목록은 확인 안 함 |
| 알림 | 처음엔 꺼짐 (온보딩에서 물음) |
| 다른 앱 위에 표시 | 꺼짐 |
| 배터리 | 최적화 켜짐 (제한 있음) |

## 첫 실행에서 묻는 순서 (캡처 01~15)
1. 소개 3장 → '알라미 시작하기'
2. 온보딩 1/4 알람 시간. '다음' 누르면 먼저 앱 설명 화면 "알람이 울리려면 꼭 필요해요" + 그림(가짜 알림 창 '알림 권한을 허용해주세요 / 알림 기능이 꺼져있으면 알람이 울릴 때 확인하기 어려워요', '허용'에 손가락) → 시스템 알림 창. 거절해도 막지 않고 2/4로.
3. 2/4 배경, 3/4 소리 + 볼륨 시트, 4/4 미션.
4. 온보딩 끝에 전체 화면 '필수 권한 1 / 1': 제목 "잠금해제 없이 알람을 바로 끄려면", 설명 "다른 앱 위에 표시 권한을 허용해주세요", 토글 그림, 버튼 '설정하러 가기', 오른쪽 위 X. 켜진 권한(전체 화면 알림)은 건너뛰고 꺼진 것만 셈. 배터리는 여기서 안 물음.
5. '설정하러 가기' → 기기 '다른 앱 위에 표시' 전체 앱 목록(알라미 줄 강조). 안 켜고 돌아오면 다시 묻지 않고 구독 화면.

## 홈, 설정의 경고 (알림 꺼짐, 다른 앱 위 꺼짐, 배터리 제한 상태)
- 홈: 경고 배너 없음. 설정 탭 아이콘에 빨간 점만.
- 설정: 줄마다 경고 없음. '알람 울림 최적화' 안에 접었다 펴는 3칸(알람 필수 권한 안내 → FAQ 웹, 방해 금지 모드 허용, 배터리 최적화 제외).
- 배터리 칸 '설정하러 가기' → 시스템 팝업 '배터리 사용량 최적화 중지' (취소/확인) 한 번으로 끝남 (`ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`).

## 저장할 때
- 알림 꺼짐, 다른 앱 위 꺼짐 상태에서 알람 저장: 권한 안내 없음. 미션 추가 권유 시트만 뜨고 저장됨. 앱 평가 팝업.

### 홈 키 시험 (19:54, 다른 앱 위 O, 잠금 상태)
- 홈 키 → 같은 순간 알라미가 알람 화면을 다시 맨 앞에 올림(BAL_ALLOW_SAW_PERMISSION). 10초 지켜봐도 계속 맨 앞. 최근 앱 키, 뒤로 키도 알람 화면 그대로 (캡처 88, 89). 소리 계속.

### 홈 키 시험 (19:46, 다른 앱 위 X, 잠금 상태)
- 알람 화면에서 홈 키 → 알람 화면 사라지고 잠금 화면만 남음. 알라미가 약 5초 뒤 알람 화면을 다시 띄우려 했지만 시스템이 막음(BAL_BLOCK). 한 번만 시도하고 더 시도하지 않음.
- 소리는 계속 남. 잠금 화면 알림 창에 '눌러서 알람 끄기' 알림이 있지만, 누르면 잠금 해제를 요구함 (캡처 80~83).
- 잠금 화면은 몇 초 뒤 꺼짐 → 사용자가 본 "화면이 잠깐 켜졌다 꺼짐, 소리는 계속"의 원인.
- 알라미 특징: 앱을 강제 종료해도 울리던 알람을 기억했다가, 앱이 다시 실행되면 그 알람을 이어서 울림.
- 볼륨: 알라미는 울릴 때 시스템 알람 볼륨을 직접 맞춤(가장 낮은 칸 설정 시 15칸 중 1칸).

## 한눈에 보는 결론

| 질문 | 답 |
|---|---|
| 잠금 화면에서 알람 화면이 뜨려면? | '알림 + 전체 화면 알림' 또는 '다른 앱 위에 표시' 중 하나만 있으면 뜸 |
| 둘 다 없으면? | 화면이 안 켜지고 소리만 남. 잠금을 풀어도 알람 화면이 안 뜸 |
| 홈 키를 누르면? | 다른 앱 위 표시가 있으면 알람 화면이 바로 다시 올라옴. 없으면 알람 화면을 잃고, 잠금 상태에선 잠금을 풀어야 끌 수 있음 |
| 알라미는 권한을 얼마나 조르나? | 거의 안 조름. 알림은 온보딩에서 한 번, 다른 앱 위는 온보딩 끝에 한 번(X로 넘김 가능), 그 뒤 홈 배너도 저장 때 안내도 없음. 설정 탭 빨간 점뿐 |

## 권한마다 있을 때, 없을 때, 알라미의 안내

| 권한 | 있을 때 | 없을 때 | 알라미의 안내 |
|---|---|---|---|
| 정확한 알람 | 제때 울림 | (이 폰에선 자동 허용이라 못 끔) | 묻지 않음(`USE_EXACT_ALARM`) |
| 알림 | 전체 화면 알림이 동작해 잠금 위 알람 화면이 뜸. 알림 창에 '눌러서 알람 끄기' | 전체 화면 알림도 같이 못 씀. 다른 앱 위 표시가 없으면 화면 안 켜짐 | 온보딩 1단계 뒤 설명 화면(건너뛰기 없음) → 시스템 창. 거절해도 계속 진행, 다시 안 물음 |
| 전체 화면 알림 | 알림과 함께 있으면 잠금 위 알람 화면 띄움 | 다른 앱 위 표시도 없으면 화면 안 켜지고 소리만 남(20:06 시험 확인) | 묻지 않음(처음부터 허용) |
| 다른 앱 위에 표시 | 알림이 없어도 화면 켜고 알람 화면 띄움. 홈 키 눌러도 바로 다시 올라옴 | 홈 한 번에 알람 화면을 잃음 | 온보딩 끝 '필수 권한 1 / 1'(X 있음) → 기기 전체 앱 목록. 안 켜도 다시 안 물음 |
| 배터리 사용 제한 없음 | (이번 시험 범위 밖, 몇 분 뒤 알람이라 차이 없음) | 오래 둔 폰에서 늦게 울릴 위험(일반 지식) | 온보딩에서 안 물음. 설정 '알람 울림 최적화' 안에서 시스템 팝업 한 번으로 받음 |

## 우리 정책 검토 (사용자 안 + Leader 피드백)

| 항목 | 사용자 안 | 시험으로 본 것 | 추천 |
|---|---|---|---|
| 알림 | 필수, 없으면 저장 못 함 | 알림이 없으면 전체 화면 알림도 죽음. 다른 앱 위 표시까지 없으면 화면이 안 켜짐 | 필수는 맞아요. 다만 '저장 못 함'은 고쳐서: 저장은 되게 하고, 저장 때 알림 시트를 꼭 거치게 해요. 두 번 거절이면 앱 알림 설정으로 바로 보내요. 이유: 알람을 잡았는데 안 저장되면 아예 안 울려서 더 위험하고, 다른 앱 위 표시만 있어도 울림 화면은 떠요 |
| 다른 앱 위에 표시 | H2 배너 + 저장 때 안내, '나중에'면 저장 | 이 권한 하나만 있어도 잠금 위 화면이 뜨고, 홈 키로도 못 내림. 가장 강한 권한 | 그대로(결정 105 필수). 저장 때 안내는 하루 한 번 |
| 전체 화면 알림 | H2 배너 + 저장 때 안내 | 알림과 묶여야 효과. 다른 앱 위 표시가 있으면 없어도 됨 | 다른 앱 위 표시와 한 장(알람 화면 시트)으로 묶기. 둘 중 하나라도 있으면 배너 급하지 않게 |
| 정확한 알람 | 2번처럼 | 대부분 폰에서 자동 허용 | 꺼졌을 때만, 2번처럼 |
| 배터리 | H2 배너 + 전날 밤 푸시 하루 한 번 | 알라미는 시스템 팝업 한 번으로 받음 | 그대로. 받는 방법은 시스템 팝업(개발 방이 구글 플레이 정책 확인) |
| 배너 | 한 번에 하나, 급한 순서 | | 순서: 알림+다른 앱 위 둘 다 없음 → 알림 → 다른 앱 위 → 정확한 알람 → 배터리 |
| 홈 키 | (새로 나온 것) | 알라미는 다른 앱 위 표시가 있을 때 홈 키 즉시 알람 화면을 다시 올림 | 우리도 넣기 추천(다른 앱 위 표시가 있을 때만 가능). 지금 우리 코드엔 없음 |

## 알라미와 같은 권한 구조로 가도 될까

| 구분 | 내용 | 이유 |
|---|---|---|
| 그대로 따라도 됨 | 알림을 묻기 전 앱 설명 화면을 먼저 보여 주기 | 시스템 창만 띄우는 것보다 허용률이 높고, 정책 문제 없음 |
| 그대로 따라도 됨 | 꺼진 권한만 묻고 켜진 건 건너뛰기, '필수 권한 n / m'처럼 남은 개수 보여 주기 | 우리 첫 저장 시트 초안과 같음 |
| 그대로 따라도 됨 | 배터리는 시스템 팝업 한 번으로 받기 | 사용자가 설정 화면을 헤매지 않음 |
| 그대로 따라도 됨 | 다른 앱 위 표시가 있으면 홈 키 뒤 알람 화면 다시 올리기 | 깨우기 앱 본래 목적과 맞음 |
| 바꿔야 함 | 거절 뒤 다시 안 묻고 경고도 거의 없음(빨간 점뿐) | 사용자가 알람이 안 뜨는 걸 모른 채 지나감. 우리는 H2 배너와 '확인 필요' 말풍선으로 계속 보여 줌 |
| 바꿔야 함 | 다른 앱 위 표시 '설정하러 가기'가 전체 앱 목록으로 감 | 우리 앱 줄로 바로 가는 화면을 쓰고, 안 되면 "목록에서 morning-up을 찾아 켜 주세요" 도움말 |
| 바꿔야 함 | 권한을 온보딩에서 몰아서 물음 | 우리는 첫 저장 때 시트로 묻기로 함(사용자 결정) |
| 따라 하면 안 됨 | 권한 화면 바로 뒤 구독 화면, 저장 뒤 평가 팝업 | 조르는 느낌. 권한 흐름과 광고, 평가를 섞지 않아요 |
| 따라 하면 안 됨 | 알림 설명 화면에 건너뛰기가 없는데 거절하면 그냥 넘어감 | 겉으론 강제처럼 보이고 실제론 아님. 우리는 '나중에'를 솔직하게 두고, 대신 배너로 다시 알려요 |
| 따라 하면 안 됨 | 앱이 강제 종료돼도 끝난 알람을 다시 울림 | 사용자가 혼란스러움(이번 시험에서 실제로 겪음). 우리 앱은 울림 중 강제 종료 뒤 재실행 때 처리 규칙을 따로 정해요 |

**한 줄 결론: 고쳐서 따라가요.** 묻는 방식(설명 화면, 꺼진 것만, 시스템 팝업)과 홈 키 재표시는 그대로 쓰고, 거절 뒤에 아무 말 없는 부분은 우리 배너 규칙으로 바꿔요. 시험에서 권한이 없으면 화면이 아예 안 켜지는 게 확인돼, 알라미처럼 조용히 넘어가면 안 되기 때문이에요.

## '건너뛰기 없는 권한' 관찰에 대해

| 질문 | 답 |
|---|---|
| 앱 화면에 건너뛰기가 없는 권한 | 알림 하나. 설명 화면에 '다음'만 있음. 다른 앱 위 표시 화면은 오른쪽 위 X로 넘길 수 있음 |
| 시스템 창에서 '허용 안 함'을 누르면 | 막지 않고 다음 온보딩으로 넘어감. 다시 묻지 않음. 알람 저장도 됨 |
