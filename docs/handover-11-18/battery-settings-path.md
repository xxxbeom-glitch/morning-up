# 배터리 제한 해제 경로 (갤럭시 S24+ SM-S926N, Android 17, 11-18 확인)

폰 설정은 바꾸지 않았음. 회전 값 시작/끝 모두 accelerometer_rotation=0, user_rotation=0.
캡처: 같은 폴더 `battery-shots/`

## 경로 1. 앱별 배터리 (추천)
설정 > 애플리케이션 > morning-up > 배터리 > '제한 없음'
- 앱 정보 화면 제목: '애플리케이션 정보', 사용량 묶음 안 '배터리' 줄 (설명: '마지막으로 완전히 충전한 이후로 사용 안 함')
- 배터리 화면 선택지 3개(라디오):
  - 제한 없음: 백그라운드에서도 이 앱이 배터리를 제한 없이 사용합니다. 배터리 사용가능 시간이 줄어들 수 있습니다.
  - 최적화: 이 앱의 사용 패턴에 맞춰 최적화합니다. 가능한 많은 앱에 적용하는 것을 추천합니다.
  - 제한: 이 앱이 백그라운드에서 실행 중인 동안에는 배터리 사용을 제한합니다. 앱이 제대로 작동하지 않거나 알림이 늦게 도착할 수도 있습니다.
- 지금 폰의 morning-up(debug)은 이미 '제한 없음'. 새로 깐 앱의 기본값은 '최적화'.
- 캡처: 00_settings_home, 00c_settings_scroll2(애플리케이션 줄), 01_app_info, 02_app_battery

## 경로 2. 삼성 배터리 메뉴
설정 > 배터리 > 백그라운드 앱 사용 제한 > 자동 절전 예외 앱 > '+' > 앱 선택에서 morning-up 체크 > '추가'
- 백그라운드 앱 사용 제한 화면: 설명 '자주 사용하지 않는 앱은 배터리를 적게 사용하도록 설정해 보세요.'
  - '사용하지 않는 앱을 절전 상태로 전환' (스위치, 지금 켜짐)
  - '자동 절전 예외 앱' (0)
  - '절전 상태 앱' (0) / '초절전 상태 앱' (22)
- 자동 절전 예외 앱: 비어 있으면 '앱이 없습니다', 오른쪽 위 '+'
- 앱 선택 화면: 제목 '앱 선택', 왼쪽 위 '전체', 오른쪽 위 '추가'와 검색, 목록 머리 '모든 앱'
- 주의: 이미 '제한 없음'인 morning-up은 이 앱 선택 목록에 안 나옴(moneycast 다음이 MultiStar).
- 같은 배터리 화면에 '절전 모드' 스위치(꺼짐)도 있지만 앱 예외와는 별개.
- 캡처: 00b_settings_scroll1(배터리 줄), 10_battery, 10b_battery_scroll, 11_background_limit, 12_never_sleeping_apps, 13_add_apps_picker, 14_picker_end, 16_picker_no_morningup

## 경로 3. 앱이 직접 띄우는 화면
- 지금 앱 코드(PermissionSettings.kt)는 `ACTION_IGNORE_BATTERY_OPTIMIZATION_SETTINGS`를 엶 → 삼성에서는 '배터리 사용 관리' 화면(탭 '개인' / '보안 폴더', 앱 목록). 사용자가 목록에서 morning-up을 찾아 눌러야 함. 캡처: 20_ignore_opt_settings
- '배터리 최적화 무시' 팝업(`ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`)은 앱 매니페스트에 `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` 권한이 없고, 이미 예외 상태라 띄워 볼 수 없었음. 문구 미확인.

## 추천
애니메이션은 경로 1: 'morning-up' > '배터리' > '제한 없음' 선택.
이유: 단계가 짧고, 선택지 이름이 화면에 그대로 보이며, 앱에서 앱 정보 화면을 바로 열면(APPLICATION_DETAILS_SETTINGS) 사용자는 '배터리' > '제한 없음' 두 번만 누르면 됨. 단, 결정에 '스위치를 켜는 장면'으로 되어 있었는데 실제는 스위치가 아니라 라디오 선택(동그라미)임.

## 피그마 반영 (11-18, 사용자 지시)
- 새 부품 `Motion Battery Path` (666:7746, `디자인 시스템` 페이지, Step=1~9). 기존 `Permission Skeleton` 배터리 모양(줌인 크롭 폰, 색 변수)을 복제해 씀.
- 흐름: 설정 > 애플리케이션 > morning-up > 애플리케이션 정보(배터리, '최적화') > 배터리('제한 없음' 스위치 켜기). 각 화면에서 누름 표시 후 왼쪽으로 밀려 다음 화면.
- 타이밍: 대기 0.8/0.5초, 누름 0.15초 EASE_OUT, 화면 넘김 0.4초 GENTLE, 스위치 켜짐 0.5초 GENTLE, 1.6초 머문 뒤 0.4초 디졸브로 처음부터.
- 사용자 지시로 실제의 라디오 대신 스위치로 그림.
- O2-3 새안(617:9804) 그림 칸(617:9857)에 Step=1 인스턴스(666:16121) 넣음. '애니메이션 자리' 글(617:9858)은 숨김.
- 피그마 재생으로는 확인 안 함.

## 폰 목업 빼고 카드만 (11-18, 사용자 지시 "폰 목업은 빼고, 딱 설정 카드내용만")

- 남은 것: 흰 설정 카드(줄, 스켈레톤, 스위치, 누름 표시). 움직임 흐름과 타이밍은 그대로.

- 가운데 맞춤: viewport y 30 → -6, 모서리 0. 그림 칸(328×360) 안에서 카드(226×204)가 왼쪽 51, 위 78로 위아래 양옆 가운데.
- 바꾸기 전 원본: 복제본 `Motion Battery Path (폰 목업 원본 11-18, 안 씀)` (668:15430, 같은 `디자인 시스템` 페이지, 원래 부품 바로 아래). 앱이나 화면에서는 안 씀.
- O2-3 캡처: `o2-3-card-only.png` (같은 폴더, Step=1 상태).
