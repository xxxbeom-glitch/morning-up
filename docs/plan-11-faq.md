- 작성: [기획 11], 2026-11-27. 근거: 지금 FAQ 7개(`feature/settings/.../strings.xml` `faq_q1`~`faq_a7`), `docs/permission-matrix.md`, 결정 175, 189, 194, `docs/plan-11-wording.md` 용어.
- 손님이 보는 글이라 가운뎃점과 긴 줄표를 쓰지 않았어요.

## 결론

- FAQ를 **세 묶음**으로 나눠요: ① 알람이 울리지 않을 때(상황별 9개) ② 권한(8개) ③ 기능(7개). 지금 7개 → 24개.
- 상황별 답은 **'이렇게 확인해 주세요' 순서**로 쓰고, 권한과 관계있는 답 아래에는 **'권한 화면 열기'** 글자 버튼을 달아 T2로 바로 가요.
- 지금 답 중 사실이 바뀐 것 2개를 고쳐요: 미션 다시 시작(결정 189), 이번만 쉬기(결정 175).
- 확인이 필요한 답 1개('진동만 울리기')는 개발 확인 뒤 넣어요(3절 메모).

## 2. 알람이 울리지 않을 때 (상황별)

| # | 질문 | 답 | 버튼 |
|---|---|---|---|
| A1 | 알람이 아예 울리지 않았어요 | 이 순서로 확인해 주세요. 1. 설정 '권한'에서 필수 권한이 모두 켜져 있는지 2. 배터리 사용이 '제한 없음'인지 3. 삼성 폰이면 '절전 예외 앱'에 일어나가 있는지. 다 켜져 있으면 설정의 '알람 미리 울려 보기'로 1분 뒤에 울려 보세요. | 권한 화면 열기 |
| A2 | 알람 화면은 떴는데 소리가 안 났어요 | 방해 금지 모드나 수면 모드가 소리를 막았을 수 있어요. 폰 설정의 방해 금지 모드에서 '알람'을 켜 주세요. 모드 및 루틴으로 켜지는 모드도 같은 스위치를 따라요. 알람 편집의 볼륨과 폰의 알람 볼륨도 확인해 주세요. | 방해 금지 모드에서 허용하기 열기 |
| A3 | 잠금 화면에 알람 화면이 안 떠요 | 설정 '권한'에서 알림과 전체 화면 알림을 켜 주세요. 꺼져 있으면 화면 대신 위에서 알림으로만 내려와요. | 권한 화면 열기 |
| A4 | 다른 앱을 쓰는 중에 알람 화면이 사라져요 | 설정 '권한'에서 '다른 앱 위에 표시'를 켜 주세요. 꺼져 있으면 홈 버튼을 눌렀을 때 알람 화면이 뒤로 숨어요. | 권한 화면 열기 |
| A5 | 알람이 몇 분 늦게 울려요 | 절전 기능이 알람을 늦췄을 수 있어요. 설정 '권한'에서 배터리 사용 제한을 해제해 주세요. 안드로이드 12 폰은 '정확한 알람'도 켜 주세요. | 권한 화면 열기 |
| A6 | 며칠 앱을 안 열었더니 알람이 안 울렸어요 | 삼성 폰은 오래 안 연 앱을 잠자기 상태로 바꿔요. 설정 '권한'에서 '절전 예외 앱에 추가'를 해 두면 앱을 열지 않아도 울려요. | 권한 화면 열기 |
| A7 | 폰이 꺼져 있던 동안 알람이 지나갔어요 | 폰이 꺼져 있으면 알람이 울릴 수 없어요. 폰을 켜면 '알람을 놓쳤어요' 알림으로 알려 드리고, 다음 알람부터는 그대로 울려요. 배터리가 적으면 전날 밤 9시에 충전 안내를 보내 드려요. | 없음 |
| A8 | 앱을 강제로 종료했더니 알람이 안 울렸어요 | 폰 설정에서 '강제 종료'를 누르면 안드로이드가 예정된 알람을 모두 지워요. 다음에 앱을 열면 알람을 다시 맞추고 알려 드려요. 최근 앱 목록에서 밀어 닫는 것은 괜찮아요. | 없음 |
| A9 | 알람이 울렸는데 바로 꺼졌어요 | 1분 동안 해제하지 않으면 알람이 잠시 멈췄다가 '다시 울림' 간격만큼 쉰 뒤 다시 울려요. 다시 울림이 꺼져 있으면 한 번 울리고 멈춰요. 알람 편집의 '다시 울림'을 확인해 주세요. | 없음 |

- A8 '최근 앱에서 밀어 닫기는 괜찮다'는 말은 QA가 Z플립5에서 한 번 확인하고 넣어요(삼성은 밀어 닫기에도 앱을 멈추는 설정이 있음). 다르게 나오면 문장을 빼요.
- A9는 11-16 결정 '한 번에 1분 울리고 멈춘 뒤 다시 울림 간격만큼 쉬고 다시 울림'과 결정 187(새 알람 다시 울림 꺼짐)을 따른 거예요.

## 3. 권한

권한 답은 모두 같은 틀이에요: **무엇을 하는지 / 끄면 어떻게 되는지 / 어디서 켜는지**.

| # | 질문 | 답 |
|---|---|---|
| B1 | 알림 권한은 왜 필요한가요? | 알람이 울릴 때 해제 화면을 띄우는 데 써요. 끄면 소리만 나고 화면이 안 뜰 수 있어요. 미션을 못 할 때 쓰는 '미션 포기'도 알림으로 와요. |
| B2 | 전체 화면 알림은 무엇인가요? | 잠금 화면 위로 알람 화면을 바로 띄우는 권한이에요. 안드로이드 14부터 끌 수 있고, 끄면 잠금 화면에서 알림으로만 보여요. |
| B3 | 다른 앱 위에 표시는 왜 필요한가요? | 다른 앱을 쓰는 중에도 알람 화면을 맨 앞에 띄워요. 끄면 홈 버튼을 눌렀을 때 알람 화면이 사라질 수 있어요. |
| B4 | 배터리 사용 제한을 해제하면 배터리가 빨리 닳나요? | 일어나는 알람 시각과 알람이 울리는 동안에만 움직여서 평소 배터리 사용은 거의 늘지 않아요. 해제하지 않으면 절전 기능 때문에 알람이 늦게 울릴 수 있어요. |
| B5 | 정확한 알람은 무엇인가요? | 안드로이드 12 폰에서 정한 시각에 딱 맞춰 울리게 하는 권한이에요. 안드로이드 13 이상은 따로 켤 필요가 없어서 목록에 보이지 않아요. |
| B6 | 방해 금지 모드에서도 울리게 하려면요? | 폰 설정의 방해 금지 모드에서 '알람'을 켜 주세요. 앱이 이 설정을 대신 바꿀 수는 없어요. 설정의 '방해 금지 모드에서 허용하기'를 켜면 알람이 울리는 동안만 소리를 낼 수 있어요. |
| B7 | 접근성 권한은 왜 필요한가요? | '전원 종료 방지'를 켤 때만 써요. 미션 중 전원 메뉴가 열리면 바로 닫는 데만 쓰고, 화면 내용은 읽거나 저장하지 않아요. 쓰지 않으면 켜지 않아도 돼요. |
| B8 | 위치 권한은 왜 묻나요? | 날씨에 맞춰 하늘 배경을 바꾸는 데만 써요. 대략적인 위치만 쓰고, 허용하지 않아도 알람은 그대로 울려요. |

- B4 '거의 늘지 않아요'는 [리서치 6]의 TSK-271(배터리 소모 코드 점검) 결과를 보고 확정해요. 결과가 다르면 문장을 고쳐요.

## 4. 기능

| # | 질문 | 답 | 지금과 다른 점 |
|---|---|---|---|
| C1 | 미션을 다 못 끝내면 어떻게 되나요? | 미션 시간이 지나면 알람이 다시 울려요. 다시 '미션 시작'을 누르면 첫 미션부터 다시 해요. | 결정 189(지금 답은 '하던 미션부터 이어서') |
| C2 | 미션을 할 수 없는 상황이면요? | 알림 패널의 '미션 포기'를 누르고 나오는 문장을 그대로 따라 쓰면 알람이 해제돼요. | 새로 |
| C3 | 공휴일에는 알람을 쉬고 싶어요 | 반복 알람의 편집 화면에서 '공휴일에는 끄기'를 켜 주세요. 대체공휴일도 쉬어요. | 그대로 |
| C4 | 다음 한 번만 알람을 쉬고 싶어요 | 홈에서 반복 알람을 끄면 카드에 '이번만 쉬기'가 나와요. 누르면 아직 오지 않은 다음 알람 하나만 쉬고, 그다음부터는 다시 울려요. | 결정 175 뜻을 분명히 |
| C5 | 알람을 끈 뒤 다시 잠들까 봐 걱정돼요 | 알람 편집의 '다시 잠들기 방지'를 켜면 알람을 해제하고 정한 시간이 지난 뒤 '일어나셨죠?'를 물어요. 버튼을 10초간 눌러야 끝나요. 완전히 일어났다면 홈이나 알림 패널에서 재확인을 해제할 수 있어요. | 새로(TSK-266) |
| C6 | 미션 중에 전원을 꺼 버리면요? | 설정에서 '전원 종료 방지'를 켜면 미션을 하는 동안 전원 메뉴가 열려도 바로 닫혀요. 처음 켤 때 접근성 권한을 켜는 방법을 안내해 드려요. | 그대로 |
| C7 | 소리 없이 진동만 울리게 할 수 있나요? | (개발 확인 뒤 씀) | 지금 답 '알람음을 끄면 진동만'은 알람음 목록에 '끄기'가 없어 맞지 않을 수 있어요. 볼륨 0과 진동으로 되는지 개발이 확인하고, 안 되면 이 질문을 빼요 |
