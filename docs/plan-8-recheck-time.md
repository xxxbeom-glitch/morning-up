# 다시 확인(W3) 시간 줄이는 안 (TSK-213, [기획 8], 11-26)

사용자 원문(11-26): "알람 재재확인에서 시간을 좀 정했음 좋겠어 지금은 너무 시간이 길어서 조절이 필요해."

결정 번호는 Leader가 매겨요. 이 문서는 사용자 확인 전 안이에요.

## 결론

- '재재확인'은 W3 '정말 깼어요?'로 봐요(W2 '깨어 있나요?'가 첫 재확인, W3가 두 번째). 시간이 길게 느껴지는 곳은 **W3까지 기다리는 시간**과 **W3 대답할 시간(처음 10분)** 둘 다예요.
- 추천: W3 기다리는 시간을 W2와 떼어 **1분, 2분, 3분(처음 2분)**, W3 대답할 시간을 **1분, 2분, 3분(처음 2분)**으로 줄여요.
- 미션 끝에서 다 끝날 때까지 가장 긴 시간이 **17분 → 8분**으로 줄어요. W3에서 다시 잠들면 다시 울리기까지 더 자는 시간도 **10분 → 2분**이에요.
- 여러 번 묻기(실험실)도 같은 이유로 **3~7분 무작위, 30분 상한**으로 줄이기를 추천해요(사용자 확인 필요, 원문이 실험실까지 말한 건 아니라서 따로 물어요).

### 지금 처음 값으로 걸리는 시간 (미션 끝부터)

| 구간 | 시간 |
|---|---|
| 미션 끝 → W2 뜸 | 3분 |
| W2 대답할 시간 | 최대 1분 |
| W2 '깼어요' → W3 뜸 | 3분 |
| W3 대답할 시간 | 최대 10분 |
| **합계(가장 길 때)** | **17분** |

- W3에서 다시 잠들면 10분을 더 잔 뒤에야 다시 울려요. 결정 145는 '샤워하고 와도 억울하지 않게' 10분을 골랐지만, 미리 끝내기(알림, 홈 띠)가 이미 그 몫을 해요.

## 2. '재재확인'이 가리키는 것

| 후보 | 근거 | 판단 |
|---|---|---|
| W3 기다리는 시간(W2 → W3) | W3는 W2 다음의 두 번째 재확인이라 '재재확인'과 맞음. 지금은 W2와 같은 값이라 W3만 줄일 수 없음 | 줄여요 |
| W3 대답할 시간 | 처음 값 10분이 다른 시간(1분, 3분)보다 훨씬 김. '너무 길다'에 가장 맞는 값 | 줄여요 |
| W2 쪽 시간(미션 끝 → W2, W2 대답) | '재확인'이지 '재재확인'은 아님 | 그대로 둬요 |

원문이 둘 중 하나로 좁혀지지 않아서 **둘 다** 줄이는 안을 내요. 사용자가 하나만이라고 하면 그쪽만 써요.

## 3. 줄인 안

### 고르기 값과 처음 값

| 무엇 | 지금 | A안 (추천) | B안 (조금만) | C안 (가장 짧게) |
|---|---|---|---|---|
| W3 기다리는 시간 (W2 '깼어요' → W3) | W2와 같은 3분 (3, 5, 10분) | **따로, 1, 2, 3분 (처음 2분)** | 따로, 2, 3, 5분 (처음 3분) | 따로 두지 않고 1분 고정 |
| W3 대답할 시간 | 10분 (3, 5, 10분) | **1, 2, 3분 (처음 2분)** | 2, 3, 5분 (처음 3분) | 1분 고정 |
| 가장 길 때 합계 (미션 끝부터) | 17분 | **8분** | 10분 | 6분 |
| W3에서 다시 잠들면 더 자는 시간 | 10분 | **2분** | 3분 | 1분 |

### A안을 추천하는 이유

- 사용자가 '조절'을 말했으니 고르기는 남기고, 고르는 범위를 짧게 옮겨요. C안은 고를 수 없어서 원문과 어긋나요.
- W3 동작은 10초 누르기 하나라 2분이면 화장실에 있어도 돌아올 수 있어요. 더 오래 걸릴 때는 알림이나 홈 띠로 미리 끝내면 돼요.
- W2 대답할 시간(30초, 1분, 3분)과 비슷한 크기라 흐름이 고르게 느껴져요.
- 알라미 '다시 잠들기 방지'는 끈 뒤 **1, 3, 5, 7, 10분 후** 중에서 물어요(`research/M-alarmy-compare.md`, 유료라 대답할 시간과 실제 동작은 못 봤어요). 우리 W3 기다리는 시간 1~3분은 알라미의 짧은 쪽과 같고, W2 앞 3분을 더하면 미션 끝에서 W3까지 4~6분으로 알라미 범위 안이에요.

### 같이 바뀌는 것

| 어디 | 바뀌는 것 |
|---|---|
| T1-2 '한 번 더 확인' 시트 | 줄 둘: '언제 물을까요' 1분 후, 2분 후, 3분 후 / '확인할 시간' 1분, 2분, 3분. T1 카드에는 줄이 늘지 않아요 |
| T1-1 시트 | 바꾸지 않아요. 다만 '다시 물어보기'가 이제 W2에만 쓰인다는 것만 달라요 |
| W2-1 알림 'N분 뒤 한 번 더 물어볼게요' | N이 W3 기다리는 시간을 따라요 |
| W3 알림음 | 대답할 시간이 3분 이하라 '2분마다'는 거의 울리지 않아요. **1분마다**로 바꾸기를 추천해요(대답할 시간 안에 한 번은 울리게) |
| 저장된 옛 값 | W3 대답할 시간 5분, 10분으로 저장된 폰은 새 처음 값 2분으로 옮겨요. 3분은 그대로 |
| 결정 145 | 2절 '확인할 시간 3, 5, 10분, 처음 10분'과 흐름표 4단계 'W2와 같은 간격'이 바뀌어요 |

## 4. 여러 번 묻기(실험실)도 줄일지 (따로 물음)

| 무엇 | 지금 | 추천 |
|---|---|---|
| 둘째부터 간격 | 5~15분 무작위 | 3~7분 무작위 |
| 한 바퀴 상한 | 60분 | 30분 |
| 각 W3 대답할 시간 | 전체 설정 '확인할 시간' 그대로 | 그대로(A안이면 처음 2분) |

- 지금 처음 3번이면 가장 길 때 미션 끝에서 3 + 1 + 15 + 10 + 15 + 10 = 54분이에요. 추천대로면 3 + 1 + 7 + 2 + 7 + 2 = 22분이에요.
- 무작위라 언제 올지 모르게 하는 뜻은 그대로예요.
