# 설정 메뉴 새 배치 기획 (TSK-276)

- 작성: [기획 11], 2026-11-27. 근거: `research/Q-alarmy-settings.md`(TSK-263, [리서치 6]), 결정 178(흐름은 알라미), 결정 188(실험실), 192(설명 글), `docs/plan-11-wording.md`(이름), TSK-234(중요도 순 재배치).
- 리서치 4절 추천 배치를 바탕으로 이름, 처음 값, 시트 모양, 디자인 목록까지 정했어요.

## 결론

| 무엇 | 정한 것 |
|---|---|
| 순서 | 위는 '알람이 확실히 울리게 하는 것', 아래는 '도움과 앱 정보'(알라미와 같은 규칙). 카드 8개 |
| 한 주 시작 요일 | 설정 > 알람 카드에 새 줄. 일요일, 월요일 중 고름. **처음 값 일요일**. 홈 카드와 알람 편집 요일 줄이 같은 순서를 따라요 |
| 이어폰, 블루투스로 울리기 | 설정 > 소리 카드에 새 스위치. **처음 값 꺼짐**(지금 동작 그대로). 켤 때 안내 시트 한 번, 다시 울림 두 번째부터는 폰 스피커로 |
| 방해 금지 | '방해 금지 모드에서 허용하기'를 첫 카드 '알람이 잘 울리게'로 옮겨요. 줄을 누르면 T2-1 페이지(위에 스위치, 아래에 폰 설정 안내) |
| 빼는 줄 | 화면 모드(임시)는 출시 정리 TSK-270에서 빼요 |
| 새로 넣는 줄 | 한 주 시작 요일, 이어폰과 블루투스, 문의하기(의견 보내기 이름 바꿈, TSK-277), 개인정보 처리방침 |

## 2. 한 주 시작 요일

| 항목 | 내용 |
|---|---|
| 줄 | 한 주 시작 요일 / 값 '일요일' |
| 시트 | 제목 '한 주 시작 요일', 칩 두 개 '일요일', '월요일'(Choice Chip, 칠로 표시), 고르면 바로 닫히고 저장. 설명 글 없음 |
| 처음 값 | 일요일. 한국 달력과 지금 피그마 S0 순서(일~토)가 같아요 |
| 바뀌는 곳 | 알람 편집 요일 줄, 홈 알람 카드 요일 칸, 다음 알람 알림의 요일 글이 아닌 줄 순서만. 첫 실행 시간 단계에는 요일이 없어요 |
| 저장된 값 | 반복 요일 저장값은 그대로, 보여 주는 순서만 바뀌어요. 옮기기 없음 |

- 개발 주의(리서치 4-1): 지금 편집은 일~토, 홈은 월~일이라 **두 화면이 이미 달라요.** 이 설정을 넣으면서 한 곳(설정값)에서 순서를 받게 고쳐요. 이번 출시에서 고칠 오류로 봐요.

## 3. 이어폰, 블루투스로 울리기

| 항목 | 내용 |
|---|---|
| 처음 값 | 꺼짐 = 폰 스피커(지금 동작) |
| 켤 때 | 아래에서 안내 시트가 한 번 떠요. 제목 '이어폰이나 블루투스로 울릴까요?', 본문 '이어폰을 빼고 잠들면 알람을 못 들을 수 있어요. 연결이 끊겨 있으면 폰 스피커로 울려요.', 버튼 '취소' / '켜기' |
| 켰을 때 동작 | 울리기 시작할 때마다 연결된 블루투스, 유선 이어폰을 찾아 그쪽으로 울려요. 없으면 폰 스피커 |
| 안전장치 | 다시 울림 두 번째부터는 연결과 상관없이 **폰 스피커로** 울려요. 이어폰을 귀에서 뺀 채 자도 결국 깨우게요 |
| 끌 때 | 시트 없이 바로 꺼짐 |

- 안전장치는 리서치 4-2에서 '검토할 만하다'고 한 것을 넣기로 정했어요. 무료 기본 기능을 오류 없이(결정 193)가 먼저라서, 못 깨우는 경우를 막는 쪽을 골랐어요.
- 알라미의 '연결된 기기로 울릴까요?' 제안 띄우기는 2차로 미뤄요.
- QA: Z플립5 + 블루투스 이어폰으로 켬/끔 × 연결/끊김 4칸, 다시 울림 두 번째 폰 스피커 1칸(사용자 확인, 소리 없이 시험 규칙은 그때 지시대로).

## 4. 방해 금지 모드에서 허용하기 (T2-1 페이지)

| 자리 | 내용 |
|---|---|
| 페이지 제목 | 방해 금지 모드에서 허용하기 |
| 맨 위 줄 | 스위치 '알람이 울리는 동안만 허용'. 켤 때 방해 금지 접근 권한이 없으면 폰 설정을 열어요 |
| 아래 안내 | 지금 T2-1의 세 단계 안내(방해 금지에서 '알람' 켜기, 모드 및 루틴, 허용할 앱)를 그대로 두고 맨 아래 '방해 금지 설정 열기' |
| 들어오는 곳 | 설정 카드 1, T2 권한의 '방해 금지 모드에서 허용' 줄, H2 방해 금지 배너, FAQ A2 버튼 |

- 리서치 4-3대로, 이 스위치가 필요한 사람은 방해 금지에서 알람까지 막아 둔 사람뿐이에요. 그래서 설정 카드 1의 값은 조용히 두고, 방해 금지가 알람을 막고 있을 때만 '권한 점검' 줄이 '확인이 필요해요'로 바뀌어요(지금 H2 배너 규칙과 같음).
