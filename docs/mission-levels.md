# 미션 레벨과 설정 정의 (제안, 2026-11-16)

상태: 제안. 사용자 확정 전이에요. 확정되면 피그마 설정 시트(S1-3, S1-4 등) 예시와 `docs/design-system.md`에 반영해요.

## 결론

| 미션 | 설정 줄 | 7단계가 바꾸는 것 | 기본값 |
|---|---|---|---|
| Drop Words | 난이도, 속도, 문제 수 | 난이도는 단어 종류(늘 쓰는 말에서 전문 용어까지, 한글만). 속도 1~4는 따로 | 1단계, 속도 1, 10문제 |
| Pop Quiz | 난이도, 문제 수 | 문제 수준(초등 상식에서 전문 용어까지), 오답 보기가 얼마나 비슷한지 | 1단계, 3문제 |
| Quick Math | 난이도, 문제 수 | 연산 과정 수, 자릿수, 연산 종류 | 1단계, 3문제 |
| Shake Shake | 흔드는 횟수만 | 단계 없음. 세기 기준은 하나로 고정 | 10번 |

- 59초 타이머는 단계와 상관없이 모든 미션에 똑같아요. '손을 놓은 시간'이라 어렵게 만드는 데 쓰지 않아요.
- 어려움은 '머리를 써야 하는 정도'로만 올려요. 글자 크기, 대비, 누르는 칸 크기는 단계가 올라도 그대로예요.

## 1. 미션별 7단계

### Drop Words (11-16 사용자 피드백 반영)

난이도와 속도를 따로 골라요. 난이도는 '어떤 단어가 나오나', 속도는 '얼마나 빨리 내려오나'예요. 단어는 모두 한글이에요(영어와 암호는 키패드 배열 때문에 빼요).

난이도: 기본 1단계. 사용자가 예시를 보고 직접 올려요.

| 단계 | 나오는 단어 | 이름 아래 예시 |
|---|---|---|
| 1 | 늘 쓰는 2글자 낱말 | 예: 사과, 나무 |
| 2 | 늘 쓰는 3글자 낱말 | 예: 운동화, 자동차 |
| 3 | 받침이 많은 낱말 | 예: 닭볶음, 깻잎전 |
| 4 | 사자성어 | 예: 일석이조, 우공이산 |
| 5 | 전문 용어 (의료, 법, 경제) | 예: 고혈압, 소멸시효 |
| 6 | 겹받침이 많은 낱말 | 예: 읊조리다, 넓적다리 |
| 7 | 긴 전문 용어 (의료, 법, 화학) | 예: 탄산수소나트륨 |

속도: 1~4, 기본 1. 빠를수록 한 번에 떠 있는 단어도 늘어요.

| 속도 | 칸 위에서 바닥까지 | 한 번에 떠 있는 단어 | 이름 아래 예시 |
|---|---|---|---|
| 1 | 10초 | 1개 | 바닥까지 10초 |
| 2 | 8초 | 2개 | 바닥까지 8초 |
| 3 | 6초 | 2개 | 바닥까지 6초 |
| 4 | 4초 | 3개 | 바닥까지 4초 |

- 문제 수(맞힐 단어 수)는 사용자가 골라요(5~30문제, 1씩, 기본 10문제). (11-19 사용자 결정: 줄 이름을 '단어 수'에서 '문제 수'로, 5개씩에서 1씩으로)
- 단어 은행 크기: 단계마다 60단어예요(11-20 사용자 결정 '추천안대로'). 30문제 한 판에서도 같은 단어가 다시 나오지 않고, 기본 10문제로 6일 동안 겹치지 않아요. 단계 사이에도 같은 단어가 없어요.
- 7단계처럼 긴 단어도 키패드는 그대로예요. 화면에 떠 있는 단어의 음절과 비슷한 가짜 음절로 19칸을 채워요.

### Pop Quiz

| 단계 | 문제 수준 | 오답 보기 | 이름 아래 예시 |
|---|---|---|---|
| 1 | 초등 저학년 상식 | 확실히 다른 것 | 예: 한글을 만든 왕은? |
| 2 | 초등 고학년 상식 | 확실히 다른 것 | 예: 물이 끓는 온도는? |
| 3 | 중학교 교과 상식 | 같은 분야 | 예: 광합성에 필요한 기체는? |
| 4 | 뉴스에 자주 나오는 말 | 같은 분야 | 예: 물가가 계속 오르는 현상은? |
| 5 | 고등학교 교과, 교양 | 비슷한 말 | 예: 임진왜란이 일어난 해는? |
| 6 | 전문 용어 | 비슷한 말 | 예: 경기 침체 속 물가 상승은? |
| 7 | 깊은 교양 | 아주 비슷한 말 | 예: 30년 전쟁을 끝낸 조약은? |

- 4단계 예시는 M2 시안 문제(인플레이션)와 같아요.
- 분야(11-16 사용자 확정): 분야 고르기 줄은 두지 않아요. 경제, 사회, 국사, 세계사, 과학, 인물, 사회 이슈를 섞어 문제마다 무작위로 내요.
- 문제 수는 모두 합쳐 맞혀야 하는 수예요. 틀리면 오답 표시를 크게 보여 주고 새 문제로 바꿔요. 맞힌 수는 그대로예요(11-17 사용자 지시: 처음부터 돌아가지 않음).
- 문제 출처(11-16 사용자 결정): 온라인 백과사전, 네이버 지식백과, 표준국어대사전 같은 공식 사전과 백과에서 사실을 확인해 만들어요. 사실(연도, 뜻, 이름)은 가져다 써도 되지만 사전의 설명 글을 그대로 옮기면 저작권 문제가 생기므로, 문제와 보기 문장은 직접 써요. 문제마다 확인한 출처를 기록해 둬요.
- 문제 은행 크기: 단계마다 50문제예요(11-20 사용자 결정 '추천안대로'). 10문제 설정으로 매일 풀어도 5일 동안 같은 문제가 나오지 않아요. 단계 사이에도 같은 문제, 같은 사실을 묻는 문제를 두지 않아요. 문제마다 확인한 출처는 `docs/mission-content-sources.md`에 있어요.

### Quick Math

지금 피그마 S1-3과 `design-system.md`에 적힌 목록을 그대로 두고, 문제를 만드는 규칙만 더했어요.

| 단계 | 문제 종류 | 이름 아래 예시 | 답 크기 |
|---|---|---|---|
| 1 | 한 자리 덧셈 | 예: 7 + 5 | 두 자리까지 |
| 2 | 두 자리 덧셈, 뺄셈 (받아올림 있음) | 예: 47 + 38 | 세 자리까지 |
| 3 | 두 자리 × 한 자리 | 예: 24 × 7 | 세 자리 |
| 4 | 곱하고 더하기 두 과정 | 예: (24 × 7) + 58 | 세 자리 |
| 5 | 두 자리 × 두 자리 | 예: 38 × 26 | 세~네 자리 |
| 6 | 두 자리 × 두 자리 + 세 자리 | 예: (38 × 26) + 457 | 네 자리 |
| 7 | 소수점 문제: 소수 곱하고 더하기 (11-17 사용자 지시 '최고 어려운 건 소수점 문제') | 예: (3.6 × 2.5) + 14.75 (답 23.75, 예시는 사용자 확인 전) | 소수 둘째 자리까지 |

- 7단계는 머리로만 풀기 어렵지만 그대로 둬요(11-16 사용자 확정: 원하는 사람만 골라요). 11-17부터 7단계는 소수점 문제라 키패드 왼쪽 아래에 '.' 키가 있어요. 1~6단계에서도 '.' 키는 늘 보여요(키패드 모양을 바꾸지 않음).
- 예전 7단계 '(167 × 37) + 1872'는 11-17 소수점 문제로 바뀌었어요.
- 만드는 규칙: 답은 늘 0보다 커요(뺄셈 답이 음수 안 됨). × 1, × 10, + 0처럼 너무 쉬운 숫자는 빼요. 같은 숫자가 겹치는 문제(11 × 11)도 빼요.
- 참고: 세션을 열 때 받은 예시 목록(3+5, 14+8, 24−17, …, 48÷6+9)과 지금 피그마, 문서의 목록이 달라요. 피그마와 문서 쪽이 최신이라 그쪽을 기준으로 했어요.

### Shake Shake (단계 없음, 추천)

| 항목 | 정의 |
|---|---|
| 한 번으로 세는 흔들기 | 손목만 까딱하면 안 세고, 팔을 크게 한 번 흔들어야 세는 세기 |
| 너무 빠른 흔들기 | 0.25초 안에 두 번 들어오면 한 번으로 셈(진동이나 떨림으로 숫자가 줄지 않게) |
| 세기 기준 | 하나로 고정. 폰마다 센서가 달라 개발 때 실제 갤럭시 폰에서 맞춰요 |

- 세기를 단계로 고르게 하지 않는 이유: 사용자가 '3단계 세기'와 '5단계 세기'의 차이를 느끼기 어렵고, 어려움은 횟수로 충분히 조절돼요.
- 만약 단계를 넣는다면 3단계(살살, 보통, 세게)까지만 추천해요.

## 2. 설정 항목과 범위

| 미션 | 줄 | 버튼 | 범위 | 한 번 누를 때 | 기본값 | 값 표기 |
|---|---|---|---|---|---|---|
| Drop Words | 난이도 | < > | 1~7단계 | 1단계 | 1단계 | 1단계 |
| Drop Words | 속도 | < > | 1~4 | 1 | 1 | 1 |
| Drop Words | 문제 수 | − + | 5~30문제 | 1문제 | 10문제 | 10문제 |
| Pop Quiz | 난이도 | < > | 1~7단계 | 1단계 | 1단계 | 1단계 |
| Pop Quiz | 문제 수 | − + | 2~10문제 | 1문제 | 3문제 | 3문제 |
| Quick Math | 난이도 | < > | 1~7단계 | 1단계 | 1단계 | 1단계 |
| Quick Math | 문제 수 | − + | 1~10문제 | 1문제 | 3문제 | 3문제 |
| Shake Shake | 흔드는 횟수 | − + | 10~200번 | 1번 | 10번 | 10번 |

- 한 번에 1씩 바뀌는 줄(세 미션의 문제 수, 흔드는 횟수)은 − + 버튼을 꾹 누르고 있으면 빠르게 계속 바뀌어요(추천). 흔드는 횟수는 10에서 200까지 190번을 눌러야 해서예요.
- 끝 값에서는 버튼이 Disabled예요(1단계의 <, 7단계의 >, 최소값의 −, 최대값의 +). 지금 부품 규칙 그대로예요.
- Pop Quiz와 Quick Math의 '문제 수'도 모두 합쳐 맞힌 수예요(화면 '정답 2 / 3', 11-17부터 '연속'이 빠지고 틀려도 처음부터 하지 않음). Drop Words의 '문제 수'는 모두 합쳐 맞힌 단어 수예요(화면 '정답 4 / 10'). (11-19 사용자 결정: '단어 수'에서 '문제 수'로, 1씩)
- Pop Quiz만 최소 2문제인 이유: 4지선다는 1문제면 찍어서 맞힐 확률이 25%예요. 2문제면 6%, 3문제면 1.6%.
- Quick Math는 직접 입력이라 찍을 수 없어 1문제부터 돼요.
- 고른 카드 설명 줄: 'Drop Words 1단계, 속도 1, 단어 10개', 'Pop Quiz 1단계, 3문제', 'Quick Math 1단계, 3문제', 'Shake Shake 10번'.

## 3. 이름 아래 예시 문구

- 난이도 줄의 서브(`Caption/Medium` `text/secondary`)에 '예: ...' 한 줄로 보여 줘요. 넘길 때 값과 같이 바뀌어요.
- 문구는 1번 표들의 '이름 아래 예시' 칸 그대로예요.
- 규칙: 한 줄에 들어가게 짧게(시트 폭 기준 약 20자), 가운뎃점과 긴 줄표는 쓰지 않아요. Pop Quiz는 답을 보여 주지 않고 문제만 써요.
- Shake Shake는 난이도 줄이 없어 예시도 없어요.

## 4. 잠 덜 깬 사람도 하고, 대충은 못 끄게

| 쪽 | 장치 |
|---|---|
| 할 수 있게 | 시간 제한이 없어요. 59초는 손을 놓은 시간이라 천천히 해도 돼요 |
| 할 수 있게 | 틀려도 벌이 없어요. 새 문제로 바뀔 뿐 알람은 다시 울리지 않아요 |
| 할 수 있게 | 단계가 올라도 글자 크기, 대비, 키 크기(56)는 그대로예요 |
| 할 수 있게 | 처음 값은 가장 쉬운 1단계와 짧은 개수(3문제, 10개, 10번)예요. 사용자가 예시를 보고 올려요(11-16 사용자 결정) |
| 할 수 있게 | Drop Words에서 바닥에 닿은 단어는 벌 없이 사라져요(11-16 사용자 확정) |
| 대충 못 끄게 | (11-17 바뀜) 틀려도 처음부터 하지 않아요. 대신 오답 때 크게 보여 주고 새 문제로 바꿔요 |
| 대충 못 끄게 | Pop Quiz는 최소 2문제라 찍어서 통과하기 어려워요 |
| 대충 못 끄게 | 키패드가 무작위이고 정답마다 다시 섞여서 손 위치를 외워 칠 수 없어요 |
| 대충 못 끄게 | 흔들기는 팔을 흔들어야 세요. 누워서 손목만 까딱하면 안 줄어요 |
| 대충 못 끄게 | 59초 손을 놓으면 알람이 다시 울려요. 미션을 끝내야만 꺼져요 |

## 5. 미션 사이 공통 규칙

| 상황 | 규칙 |
|---|---|
| 틀렸을 때 (Pop Quiz) | 고른 답이 빨개지고 큰 X와 '틀렸어요'가 뜨며 폰이 짧게 떨린 뒤 새 문제로 바뀌어요(M2-1). 맞힌 수는 그대로예요. 알람은 다시 울리지 않아요 |
| 틀렸을 때 (Drop Words, Quick Math) | 큰 표시 없이 입력 칸 테두리와 글자만 빨개지고 폰이 짧게 떨려요. 약 1초 뒤 Drop Words는 칸이 비워지고 Quick Math는 새 문제로 바뀌어요(M1-1, M3-1). 맞힌 수는 그대로예요 |
| 틀렸을 때 (Drop Words) | 확인 키가 없어서, 친 글자가 떠 있는 어떤 단어의 앞부분과도 안 맞는 순간 입력칸이 짧게 흔들리고 비워져요. 정답 수는 그대로예요 |
| 단어가 바닥에 닿았을 때 | 벌 없이 사라지고 새 단어가 내려와요(11-16 사용자 확정) |
| 계속 못 풀 때 | 비상 탈출은 두지 않아요(11-16 사용자 결정). 단계를 사용자가 고르고 처음 값이 가장 쉬우며 미리보기로 미리 해 볼 수 있어서, 고른 미션은 결국 풀 수 있는 문제예요 |
| 59초가 끝났을 때 | 알람이 다시 울리고 알람 울림 화면(D)으로 가요. 다시 시작하면 그 미션 진행은 처음부터예요(정답 수, 연속 정답, 남은 횟수 모두) |
| 미션을 여러 개 골랐을 때 | 고른 순서대로 이어서 해요. 시간이 끝나 돌아가면 이미 끝낸 미션은 다시 하지 않고 하던 미션부터 해요 |
| 미션 중 소리 | 미션을 시작하면 알람 소리를 작게 줄였다가, 59초가 끝나면 원래 크기로 다시 울려요 |
| 미리보기 | 시트에서 고른 단계와 개수 그대로 해요. 알람 소리는 없어요. 59초 타이머는 보이지만 0이 돼도 알람이 울리지 않고 시트로 돌아가요. 왼쪽 위 닫기 버튼으로 언제든 나와요. 끝내면 '잘했어요' 짧게 보여 주고 시트로 돌아가요. 기록은 남기지 않아요 |
