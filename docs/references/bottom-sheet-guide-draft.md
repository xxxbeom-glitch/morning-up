### 3-1. 타입별 고정 구조

**타입 1 하나 고르기** (EX8, h328)
- Sheet Header(제목만) → content 8/24/0/24, gap 4, Radio Row → 빈 footer h100 → Nav Bar
- 고른 줄은 칠로만 표시해요. 테두리 없음.

**타입 2 값 조절** (EX3 h348, EX4 h580)
- Sheet Header(제목 + 설명) → content 4~8/24/0/24 → footer '완료' → Nav Bar
- 정확한 숫자(횟수, 분, 문제 수, 난이도)는 **카운트(+, -) Value Switch Row**로 해요 (11-27 사용자 결정: 문제 수와 난이도 모두 카운트).
- 슬라이더(1244:22321)는 '속도'처럼 느낌으로 고르는 값에만 써요 (EX4).
- 범위가 넓은 카운트(1~30 같은)는 길게 누르면 빨리 올라가게 하는 안을 개발에 같이 넘겨요.
- 설명 한 줄은 값 줄 바로 아래, 간격 8. 범위를 적어요 ('1회에서 10회까지').

**타입 3 켜기 + 상세** (EX1-a, EX2, h468)
- Sheet Header(Show Toggle) → content 8/24/0/24, gap 4, Radio Row → footer '완료'
- 시트 안에는 스위치 줄을 따로 두지 않아요. 켜고 끄기는 헤더 Toggle 하나뿐이에요 (11-17 규칙).
- 끄기는 목록 맨 위 '안 함' 옵션으로 두는 방식도 허용해요 (11-27 메모). 둘 중 하나만 써요.

**타입 4 여러 단계** (EX5-a/b h620, EX1-a/b h468)
- 시트 높이는 두 단계 중 **큰 쪽에 맞춰 고정**해요. 단계가 바뀌어도 높이가 흔들리지 않아요.
- 2단계 헤더는 Sheet Page Header: 왼쪽 < (Lucide `chevron-left`) + 제목. 닫기 X는 없어요.
- 1단계는 버튼 없이 줄을 누르면 넘어가요. 2단계는 '완료' 하나.
- 폰 뒤로 가기: 2단계 → 1단계, 1단계 → 닫힘. 스크림을 누르면 어느 단계든 닫혀요.
- 진행 표시('1/2', 점)는 넣지 않아요. 두 단계뿐이고 PL2도 진행 표시가 없어요.
- 넘김 움직임은 표시만 해요(왼쪽으로 밀림). 애니메이션 값은 보류 규칙에 따라 나중에 정해요.
- 레퍼런스: G 묶음 40~47 (ChatGPT, DoorDash, Beside, Reddit, Grab, eBay, Instacart).

**타입 5 안내** (EX7, h436)
- Sheet Header(제목 + 설명) → content 4/24/0/24, gap 12, 그림 칸 312×176 → footer 행동 버튼 하나
- '다음에 하기' 같은 빠져나가는 길은 **두 번째 버튼으로 두지 않고** 뒤로 가기와 스크림으로 해요. 단, 꼭 다시 물어야 하는 권한(PL2 2단계)은 지금처럼 글 버튼 '다음에 하기'를 주 버튼 아래 둬요.

**가운데 다이얼로그** (EX9, h192)
- Dialog 부품(137:709): 폭 328, padding 24, gap 24. head(gap 16) + actions(gap 8).
- 버튼: 왼쪽 Button Alt Secondary Medium('취소'), 오른쪽 Button Medium(주 행동). 
- 시트 대신 다이얼로그를 쓰는 때: 고를 값이 없고 예/아니오만 물을 때 (예: 이어폰으로 울릴까요, 나가기).
- 그래서 T3-4 미션 포기(본문 없는 시트 + 두 버튼)도 다이얼로그로 바꾸는 안이에요.

## 6. 인포 박스 부품 안

지금은 같은 역할의 안내가 세 가지 모양이에요(T3-1 notice, PL2 '※' 안내문, Dialog Warning 옵션). 하나의 부품 두 가지 종류로 묶는 안이에요.

| 종류 | 언제 | 모양 | 아이콘 (Lucide) | 예제 부품 |
|---|---|---|---|---|
| Warning | 켜면 다른 기능이 막히는 등 꼭 알아야 할 것 | fill `status/warning` 연한 칠, 모서리 12, 안 여백 12/16, 글 14 | `triangle-alert` 16 | 1244:22301 (EX4에서 사용) |
| Note | 알아 두면 좋은 도움말 | fill `background/base`, 모서리 12, 안 여백 12/16, 글 14 | `info` 16 | 1244:22307 |

- 테두리 없이 칠로만 구분해요.
- 놓는 곳: 본문 맨 아래, 위 간격 16. 한 시트에 하나만.
- 대체: T3-1 notice '켜면 '미루기'는 쓸 수 없어요' → Warning. PL2 안내문 '※ …' → Note ('※' 기호는 아이콘으로 바꿈).
- 글은 한두 줄. UI 이름은 작은따옴표로 감싸요.
