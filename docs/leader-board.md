# Leader 상황판

Leader 방이 일을 나눠 주거나 결과를 받을 때마다 고친다. Leader가 압축되면 이 파일부터 다시 읽는다.

## 운영 규칙 (11-18)
- 사용자는 Leader 방에만 말해도 된다. Leader가 맞는 방에 넘기고 결과를 받아 보고한다.
- 분야 방이 꽉 차면 묻지 않고 새 세션으로 넘긴다. 이름 번호 +1. 넘긴 뒤 Leader에 한 줄 알린다.
- Leader는 새로 열지 않고 이 방에서 압축하며 계속 쓴다.
- 이름: `Leader` / `[분야 번호] 하는 일` / 하위 세션 `[분야 번호-n] 하는 일`. 일이 없으면 `대기 중`.
- 3단계: Leader → 팀 방 → 일꾼 세션. 팀 방은 일꾼을 묻지 않고 자유롭게 만든다. 일꾼은 더 아래 세션을 못 만든다.
- 새 팀 방과 일꾼은 Opus 5.5로 만든다. 같은 파일을 동시에 고칠 수 있으면 worktree로 나눈다.
- 끝난 일꾼은 팀 방이 결과와 worklog 기록을 확인한 뒤 보관한다.
- 전체 규칙 원본: 전역 `C:\Users\sky08\.claude\CLAUDE.md` (11-18 반영).
