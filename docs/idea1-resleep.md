# 아이디어 1: 다 끈 뒤 다시 잠드는 경우 (확정: A안, 11-23)

11-23 [기획 2] 작성. 원문은 `docs/ideas-11-22.md` 1번.

> **확정 (11-23 사용자 "둘 다 그렇게")**: A안, 처음 값 2번은 결정 136, 처음 값 3분 후, 1분은 결정 137 (`decisions-11-23.md`). 넘길 일도 그 문서 끝에 있어요.

## 결론

- 지금 '다시 잠들기 방지'는 **한 번만** 물어요. '깼어요'를 한 번 누르면 그날 알람은 완전히 끝나요. 사용자가 말한 "다 끝났는데 또 잠듦"이 바로 이 빈틈이에요.
- 추천: **'다시 잠들기 방지' 시트에 '몇 번 물을까요'(1번, 2번, 3번) 줄 하나만 더해요.** 울림 화면과 W2는 그대로 두고, 확인만 여러 번 해요. 안 누르면 지금처럼 알람이 처음부터 다시 울려요.

## 1. '세션 1~3'이 가리키는 것

사용자 말의 '세션'은 알람 하나가 끝나기까지 지나는 화면 단계로 봤어요.

| 단계 | 화면 | 지금 하는 일 | 마지막 버튼 |
|---|---|---|---|
| 1 | D0 알람 울림 | 하늘, 날짜, 시각, '미션 시작'(미션 없으면 '알람 끄기') | '미션 시작' |
| 2 | M 미션 | 고른 미션을 차례로 풀어요 | 미션 끝 |
| 3 | W1 해제 완료 (+ 켜져 있으면 W2 '깨어 있나요?') | 인사와 날씨 한마디. 다시 잠들기 방지가 켜져 있으면 N분 뒤 W2가 떠요 | W1 '확인', W2 '깼어요' |

- 원문의 '일어났어요' 버튼은 지금 앱의 W2 '깼어요'(또는 W1 '확인')예요.
- '1~3 다시 반복'은 "끝난 뒤에도 다시 확인하고, 안 깼으면 울림부터 다시"로 이해했어요.

## 2. 지금 '다시 잠들기 방지'와 겹치는 것, 빠진 것

지금 규칙 출처: 결정 80, 83 (`decisions-11-17.md`), 울림 상태표 (`adr/0002-alarm-engine.md`), `dev-readiness.md` 3번 표 6~7.

| 항목 | 지금 | 원문 바람 | 판단 |
|---|---|---|---|
| 끈 뒤 다시 확인 | 있음. N분 뒤 W2 '깨어 있나요?' 한 번 (3, 5, 10분 후) | 있음 | 겹침 |
| 답 안 하면 | 알람이 다시 울리고 미션을 처음부터, 다시 울림 횟수도 처음 값으로 | 1~3 다시 반복 | 겹침 (이미 '1~3 반복'을 해요) |
| '깼어요'를 누른 뒤 | 끝. 더 묻지 않음 | 또 잠들 수 있으니 더 확인 | **빠짐** |
| 확인 횟수 고르기 | 없음 (늘 1번) | 설정에서 고르기 | **빠짐** |
| 잠결에 '깼어요'를 눌러 버림 | 원형 버튼 한 번이면 끝 | (원문에는 없음) | 약점. 아래 안 C 참고 |

- 함께 찾은 것: 처음 값이 문서마다 달라요. 결정 83은 '3분 후, 답할 시간 1분', `dev-plan.md` 245줄과 `dev-readiness.md` F9는 '1분 후, 1분'이에요. 이 일을 정할 때 같이 맞추면 좋아요.

## 3. 안 비교

| | A 확인 횟수 늘리기 (추천) | B 울림부터 통째로 반복 | C W2를 작은 미션으로 |
|---|---|---|---|
| 하는 일 | '깼어요'를 눌러도 N분 뒤 또 W2. 1~3번까지 | '깼어요' 뒤 N분마다 D0 알람과 미션을 1~3번 다시 | '깼어요' 대신 쉬운 문제 1개(예: 한 자리 덧셈)를 풀어야 넘어감 |
| 다시 잠든 사람 | W2에 답 못 함 → 알람이 처음부터 울림 | 알람이 다시 울림 | 답 못 함 → 처음부터 울림 |
| 깨어 있는 사람 부담 | 작음. 버튼 한 번씩 | 큼. 깨어 있어도 알람과 미션을 또 함 | 중간. 문제 하나씩 |
| 화면 규칙 | 울림 화면 그대로, 스누즈 없음 지킴 | 사실상 스누즈처럼 보여서 '스누즈 없음' 결정과 부딪힘 | 울림 화면은 그대로. W2만 바뀜 |
| 설정 모양 | 기존 S4 시트(토글+바텀시트)에 줄 하나 | 새 설정 묶음 필요 | 시트에 '문제로 답하기' 토글 하나 |
| 만들기 | 작음. 지금 W2 예약을 횟수만큼 되풀이 | 큼. 울림 상태표를 새로 짜야 함 | 중간. 미션 부품을 W2에 넣음 |
| 걱정 | 잠결에 '깼어요'만 누르면 여전히 빠져나감 | 귀찮아서 기능을 끄게 됨 | W2가 단순하지 않아짐 |

### 알라미는 어떻게 하나 (짧게)

- 알라미에도 '다시 잠들기 방지'가 있고, 편집 화면에 자물쇠 표시가 붙은 유료 기능이에요(우리 조사 `research-alarmy-mission-flow.md` 9번 줄).
- 알려진 방식은 우리와 같아요. 끈 뒤 몇 분 지나 확인 알림을 띄우고, 시간 안에 안 누르면 다시 울려요. 이번에는 웹에서 다시 확인하지 않았어요.
- 사용자가 알라미로 다시 잠든 경험이 많다면, 이 기능을 무료로 넣고 확인 횟수까지 고를 수 있게 하는 것이 차별점이 될 수 있어요.

## 4. 추천: A안

- 이유 1: 원문 바람(끝난 뒤에도 다시 확인, 안 깼으면 다시 울림)을 가장 작은 변화로 채워요. '답 안 하면 처음부터'는 이미 있어요.
- 이유 2: 울림 화면을 단순하게, 스누즈 없음, 설정은 토글+바텀시트라는 규칙을 그대로 지켜요.
- 이유 3: 깨어 있는 사람은 버튼만 몇 번 누르면 돼서 기능을 끄고 싶어지지 않아요.

### A안 모양 (초안)

- S4 '다시 잠들기 방지' 시트 줄: '다시 물어보기' 3, 5, 10분 후 / '대답할 시간' 30초, 1분, 3분 / **'몇 번 물을까요' 1번, 2번, 3번 (새 줄)**
- 처음 값 추천: 2번. 1번이면 지금과 같아요.
- 흐름: 미션 끝 → W1 → N분 뒤 W2 → '깼어요' → (남은 횟수가 있으면) N분 뒤 W2 다시 → … → 마지막 '깼어요'에서 끝.
- 중간에 답을 못 하면: 지금 규칙대로 알람이 처음부터 울리고, 미션을 다시 하고, 확인 횟수도 처음 값으로 돌아가요.
- 시트 설명 문구(결정 80) '알람을 끈 뒤 깼는지 한 번 더 물어요'는 '알람을 끈 뒤 깼는지 다시 물어요'로 바꾸는 것을 추천해요.
- C안은 A안을 써 본 뒤 "잠결에 '깼어요'만 누르고 또 잤다"가 나오면 그때 더해요.
