# 아이디어 3: MVP에서 수면 라운지 빼기 (확정: 결정 140, 141)

> **확정 (11-23 사용자 "둘 다 그렇게")**: 하단 메뉴 탭 2개(A안), 피그마 구역은 그대로 두고 'MVP 제외' 표시만. 결정 141. 옛 결정과 계획 문서 표시도 끝났어요. 넘길 일은 `decisions-11-23.md` 끝에 있어요.

11-23 [기획 2] 작성. 원문은 `docs/ideas-11-22.md` 3번. 사용자 결정: "일단 MVP로 수면 라운지는 빼자, 오로지 잠이 깨는 데만 집중하자."
결정 기록: `decisions-11-23.md` 결정 140. 코드와 피그마는 이 방에서 고치지 않았어요.

## 결론

- 수면 라운지는 **코드를 지우지 않고 숨겨요.** 첫 버전 사용자에게는 보이지 않고, 나중에 스위치 하나로 되살릴 수 있게 해요.
- 하단 메뉴는 '알람', '설정' **탭 2개**가 돼요(추천). 잠들기 탭과 Z1, Z2 화면, 재생 서비스, 재생 알림이 사라져요.
- 출시판에서는 재생 서비스의 권한 선언(`FOREGROUND_SERVICE_MEDIA_PLAYBACK`)도 빼야 해요. 구글 플레이가 쓰지 않는 기능의 권한 이유를 물을 수 있어서예요.

## 2. 하단 메뉴가 바뀌면

| 안 | 모습 | 좋은 점 | 걱정 |
|---|---|---|---|
| A 탭 2개 (추천) | 하단 메뉴 '알람', '설정' | 지금 구조와 부품을 그대로 써요. 설정 탭 '확인 필요' 말풍선(권한 알림)도 그대로 둬요. 나중에 탭을 다시 넣기 쉬워요 | 탭 2개는 칸이 넓어 보여서 간격 조정이 필요해요 |
| B 하단 메뉴 없앰 | 홈 위쪽에 설정 아이콘 | 화면이 넓고 단순해요 | 홈 머리 디자인과 '확인 필요' 말풍선 자리를 새로 정해야 해요. 되살릴 때 다시 바꿔야 해요 |

- A안이면 화면 흐름은 그대로예요. 홈(H0)과 설정(T1)이 탭으로 오가고, 잠들기에서 시작하던 흐름은 없어요.
- 밤(18~4시)에 앱을 켜도 첫 화면은 그대로 홈이에요. 잠들기 탭을 첫 화면으로 보이던 규칙은 없어서 바뀌는 게 없어요.

## 3. 숨기는 방법 (개발에 넘길 때 참고)

- 스위치 하나(예: 빌드 설정 `SLEEP_LOUNGE = false`)로 탭, 이동 경로, 재생 서비스 선언을 같이 끄고 켜요.
- 재생 서비스 선언은 `core/alarm`에서 `feature/sleep` 쪽으로 옮기거나, 출시판 매니페스트에서 빼서 스위치를 끄면 권한도 같이 빠지게 해요.
- `feature/sleep` 모듈과 시험 코드는 그대로 둬요.

## 4. 참고: 남의 미커밋 수정

- 작업 폴더에 `app/src/main/kotlin/com/lumian/morningup/ui/MorningUpApp.kt` 미커밋 수정이 있어요(11-18 사용자 지시: 잠들기 탭일 때 하단 메뉴는 다크로 바꾸지 않고 지금 시각 테마를 따름. 화면만 다크).
- 이 방은 손대지 않았어요. 탭을 숨기는 개발 일이 같은 파일을 고치니, 개발 방이 이 수정을 먼저 커밋하거나 정리한 뒤 시작해야 해요.
