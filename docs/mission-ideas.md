# 미션 아이디어와 피드백 (2026-11-15)

사용자가 낸 아이디어와 Claude 피드백. 표시: ✅ 바로 해도 됨 / ⚠️ 조건 붙이면 됨 / ❌ 지금은 빼기

## 한눈에 보기

| # | 아이디어 | 판단 | MVP | 핵심 이유 |
|---|---|---|---|---|
| 1 | 움직이는 문장 타이핑 | ✅ | 넣기 | 알라미와 확실히 다르고 만들기 쉬움 |
| 2 | 어려운 주관식 퀴즈 | ⚠️ | 다음 버전 | 답을 모르면 알람을 영원히 못 끔. 문제 데이터도 직접 만들어야 함 |
| 3 | 헷갈리는 4지선다 (사과/샤과/서과) | ✅ | 넣기 | 오답 보기를 자동으로 만들 수 있어 문제 만들기가 쉬움 |
| 4 | 두더지잡기 | ✅ | 넣기 | 장르는 자유. 그림과 규칙 조합만 직접 만들면 됨 |
| 5 | 미션 여러 개 묶기 | ✅ | 넣기 (구조) | 아이디어 자체는 독점 불가. 무료로 풀면 차별점 |
| 6 | 다시 잠들기 방지 | ✅ | 넣기 | 일반 알림과 예약 알람만으로 구현 가능 |
| 7 | 전원 끄기 방지 | ❌ | 빼기 | 구글플레이 정책 위험이 큼 (아래 설명) |

## 1. 움직이는 문장 타이핑 ✅
- 좋은 점: "보고 치기"를 어렵게 만드는 방식이라 알라미 따라쓰기와 체감이 확실히 다름. 화면에서 바로 보여줄 수 있어 홍보 영상에도 좋음.
- 붙일 조건
  - 난이도 3단계: 천천히 흔들림 / 순간이동 / 글자마다 따로 움직임.
  - 글자 크기와 대비는 충분히 크게 유지. 어렵게 하는 건 위치뿐, 읽기 자체가 불가능하면 안 됨.
  - 문장은 직접 만들기 (알라미 예시 문장 사용 금지).
  - 한글 입력은 조합 중인 글자가 있으니, 다 쳤을 때 비교하는 방식으로.

## 2. 어려운 주관식 퀴즈 ⚠️
- 문제: 답을 모르면 끌 방법이 없음. 화가 난 사용자는 앱을 지우거나 별점 1점을 줌. 외국 인명은 표기가 여러 개(라부아지에/라브와지에)라 맞게 써도 틀릴 수 있음.
- 고치는 방법 (추천: A)
  - A. 기억 퀴즈로 바꾸기: 어려운 단어와 짧은 설명을 5초 보여주고 가린 뒤 입력. 어렵지만 풀 수는 있음.
  - B. 시간이 지나면 초성 힌트 (ㄹㅂㅇㅈㅇ) → 첫 글자 → 정답 보고 따라 치기 순으로 쉬워지게.
  - 정답은 여러 표기를 모두 인정.
- 문제 데이터를 수백 개 직접 만들어야 해서 MVP 뒤로 미루기 추천.

## 3. 헷갈리는 4지선다 ✅
- 좋은 점: 한글을 자음과 모음으로 쪼개 한 부분만 바꾸면 오답 보기를 자동으로 만들 수 있음. 문제 데이터는 단어 목록만 있으면 됨.
- 붙일 조건
  - 4지선다는 찍어서 맞출 확률이 25%라, 연속 3문제 이상 맞혀야 통과 (찍어서 통과할 확률 약 1.6%).
  - 틀리면 처음부터, 새 문제로 다시 (아이디어 그대로).
  - 오답이 실제 단어가 되지 않게 확인 (예: 사과 → 사관은 진짜 단어라 정답 시비).

## 4. 두더지잡기 ✅
- 장르와 "제한시간 안에 몇 마리" 규칙은 흔한 방식이라 써도 됨. 캐릭터, 그림, 효과음은 직접 만들기.
- 붙일 조건: 잠결에 손가락이 부정확하니 누르는 영역은 넉넉하게. 난이도별 목표 수와 시간 조절.

## 5. 미션 여러 개 묶기 ✅
- "미션을 연달아 붙인다"는 생각 자체는 독점할 수 없음. 화면 배치와 이름만 알라미와 다르게.
- 알라미는 유료 기능이라, 무료로 풀면 그대로 차별점이 됨 (기획 3번과 같은 방향).
- 처음부터 "알람 1개 = 미션 목록"으로 데이터 구조를 잡아 두면 됨.

## 6. 다시 잠들기 방지 ✅
- 알람을 끈 뒤 몇 분 후 "깨어 있나요?" 알림을 보내고, 정해진 시간 안에 누르지 않으면 알람을 다시 울리는 방식. 일반 알림과 예약 알람만 쓰므로 정책 문제 없음.

## 7. 전원 끄기 방지 ❌ (지금은 빼기)
- 안드로이드는 원래 앱이 전원 끄기를 막을 수 없음. 하려면 "접근성 서비스"(장애인 보조용 권한)로 전원 메뉴를 감지해 닫아야 함.
- 구글플레이는 접근성 권한을 보조 목적이 아닌 곳에 쓰는 것을 엄격하게 심사함. 개인 개발자 첫 앱에서 거절되거나 계정 경고를 받을 위험이 큼. (알라미가 어떻게 허가받았는지는 별도 확인 필요)
- 대신: 폰을 다시 켜면 알람을 자동으로 다시 예약하고, 미션 중 앱이 꺼지면 다시 울리게 만들기. 이건 정책 문제 없음.

## 전체에 붙일 안전장치
- 비상 해제: 미션을 계속 실패해도 일정 시간(예: 15분)이 지나면 끌 수 있는 길을 둠. 무한 반복은 리뷰 폭탄과 실제 위험(급한 상황)을 부름.
- 미션 미리 해보기: 알람 설정 화면에서 미션을 미리 체험.
- 미션 중에는 알람 소리를 잠깐 줄였다가, 손을 놓으면 다시 키우기.

## 추천 MVP 미션
1. 움직이는 문장 타이핑
2. 헷갈리는 4지선다
3. 두더지잡기
4. 미션 묶기 + 다시 잠들기 방지 (미션이 아닌 기능)

# 2차 아이디어와 결정 (2026-11-16)

## 결정
- 알라미 미션 중 **수학 문제, 흔들기만** 가져온다. 둘 다 여러 앱에 있는 공통 기능이라 써도 됨. 이름, 아이콘, 화면 배치, 문구는 새로 만든다.
- 바코드는 다음 버전 (카메라 권한, 물건 등록 과정 필요).
- 우리집 물건 찾기, 리듬 맞춰 말하기는 알라미 고유 색이 강해 따라 하지 않는다.

## MVP 미션 (갱신)

| 역할 | 미션 |
|---|---|
| 우리만의 미션 | 떨어지는 단어 치기, 헷갈리는 4지선다, 두더지잡기 |
| 기본 미션 | 수학 문제, 흔들기 |
| 미션이 아닌 기능 | 미션 묶기, 다시 잠들기 방지 |

- 수학 문제는 1차 정리에서 "차별점이 약해 보류"였으나, 사용자가 기대하는 기본 미션이고 만들기가 가장 쉬워 넣는 것으로 바꿈.
- 움직이는 문장 타이핑과 암호 타이핑은 따로 두지 않고 타이핑 미션의 난이도 단계로 흡수 (쉬움: 문장, 어려움: 암호).
- 다르게 보이게 하는 방향 (제안): 수학은 앱 전용 숫자 패드, 맞힐 때마다 하늘이 밝아짐. 흔들기는 횟수를 해가 떠오르는 장면으로 표시.

## 사용자 아이디어 2차 피드백

| 아이디어 | 판단 | 핵심 이유 |
|---|---|---|
| 암호 타이핑 (10~99자) | ⚠️ 흡수 | 99자는 잠결에 너무 김. 8~20자, 4글자씩 끊어 표시, 헷갈리는 글자(l/I/1, O/0) 제외, 틀린 글자만 표시. 삼성 키보드에서 비밀번호 입력 방식은 한글이 막힐 수 있어 확인 필요 (앱 전용 키보드도 방법) |
| 상식 퀴즈 (카테고리, 난이도) | ⚠️ 다음 버전 | 하루 3문제를 두 달 안 겹치게 내려면 카테고리당 약 180문제. 틀린 문제 하나가 큰 불만. 남의 문제를 옮기면 안 되고, 위키데이터(자유 사용)로 자동 생성하거나 직접 검수해야 함 |
| 폰 머리 위로 들기 | ⚠️ 다음 버전 | 높이는 센서로 판별 불가, 누워서 폰 드는 자세와 구분 안 됨. "폰 들어올리기 n회"로 바꾸면 가능하지만 흔들기와 성격이 겹침 |
| 떨어지는 단어 치기 | ✅ MVP | 단어가 바닥에 닿으면 하트(남은 기회) 1개 감소, 3개 다 잃으면 새 단어로 다시. 목표 개수 채우면 해제. 속도, 개수, 단어 길이로 난이도 3단계. 바닥은 키보드 바로 위 |
| 전화 걸기 | ❌ 빼기 | 걸기는 되지만 성공 판정이 안 됨. 통화 기록 권한(READ_CALL_LOG)은 기본 전화 앱만 허용, 통화 상태 권한으로는 상대가 받았는지 모름. 새벽에 남을 깨우는 문제 |

## 미션 이름 (2026-11-16, 미션 4개 기준)

사용자가 미션 4개(흔들기, 수학 문제, 4지선다, 떨어지는 단어)로 했을 때의 이름을 정함. 이 구성에서는 두더지잡기가 빠짐. 한글판과 영어판 중 무엇을 쓸지는 아직 정하지 않음.

| 미션 | 한글판 | 영어판 |
|---|---|---|
| 떨어지는 단어 치기 | 단어비 | Drop Words |
| 수학 문제 | 암산 | Quick Math |
| 흔들기 | 흔들흔들 | Shake Shake |
| 4지선다 상식 퀴즈 (11-16 맞춤법에서 바꿈) | 깜짝 퀴즈 | Pop Quiz |

- 한 목록 안에서 한글과 영어를 섞지 않는다. 영어판을 쓰더라도 화면에 한글 이름을 크게 쓰고 영어를 작게 붙이는 방법도 있음.
- 11-16 사용자 결정: 맞춤법 대신 장르를 가리지 않는 난이도별 상식 퀴즈(경제, 사회, 국사, 세계사, 과학 용어, 인물, 사회 이슈 등. 수학은 Quick Math가 있어 뺌)로 바꾸고, 이름을 '바른말 고르기, Right Word'에서 '깜짝 퀴즈, Pop Quiz'로 바꿈.
- 이름 뒤에 '게임'은 붙이지 않는다 (예: 암산게임 → 암산). 한 미션만 다른 종류처럼 보임.

쓰지 않기로 한 이름

| 이름 | 이유 |
|---|---|
| 산성비 | 한컴타자 게임 이름. 관계있는 것처럼 보일 수 있고, 남의 유명한 이름을 빌려 쓰는 문제(부정경쟁) 소지. 뜻도 앱 분위기와 맞지 않음 |
| 수학의 정석 | 유명 수학 참고서 이름. 같은 문제 소지, 상표 등록 가능성 큼 (확인 못 함) |
| Up&down | 한국에서 '업다운'은 숫자 맞히기 게임으로 통해 흔들기 미션이 떠오르지 않음 |
| 흔들기, 수학 문제, 따라쓰기 | 알라미 미션 이름과 같음 |
