## 1. 움직이는 문장 타이핑 ✅
- 좋은 점: "보고 치기"를 어렵게 만드는 방식이라 알라미 따라쓰기와 체감이 확실히 다름. 화면에서 바로 보여줄 수 있어 홍보 영상에도 좋음.
- 붙일 조건
  - 난이도 3단계: 천천히 흔들림 / 순간이동 / 글자마다 따로 움직임.
  - 글자 크기와 대비는 충분히 크게 유지. 어렵게 하는 건 위치뿐, 읽기 자체가 불가능하면 안 됨.
  - 문장은 직접 만들기 (알라미 예시 문장 사용 금지).
  - 한글 입력은 조합 중인 글자가 있으니, 다 쳤을 때 비교하는 방식으로.

## 2. 어려운 주관식 퀴즈 ⚠️
- 문제: 답을 모르면 끌 방법이 없음. 화가 난 사용자는 앱을 지우거나 별점 1점을 줌. 외국 인명은 표기가 여러 개(라부아지에/라브와지에)라 맞게 써도 틀릴 수 있음.
- 고치는 방법 (추천: A)
  - A. 기억 퀴즈로 바꾸기: 어려운 단어와 짧은 설명을 5초 보여주고 가린 뒤 입력. 어렵지만 풀 수는 있음.
  - B. 시간이 지나면 초성 힌트 (ㄹㅂㅇㅈㅇ) → 첫 글자 → 정답 보고 따라 치기 순으로 쉬워지게.
  - 정답은 여러 표기를 모두 인정.
- 문제 데이터를 수백 개 직접 만들어야 해서 MVP 뒤로 미루기 추천.

## 3. 헷갈리는 4지선다 ✅
- 좋은 점: 한글을 자음과 모음으로 쪼개 한 부분만 바꾸면 오답 보기를 자동으로 만들 수 있음. 문제 데이터는 단어 목록만 있으면 됨.
- 붙일 조건
  - 4지선다는 찍어서 맞출 확률이 25%라, 연속 3문제 이상 맞혀야 통과 (찍어서 통과할 확률 약 1.6%).
  - 틀리면 처음부터, 새 문제로 다시 (아이디어 그대로).
  - 오답이 실제 단어가 되지 않게 확인 (예: 사과 → 사관은 진짜 단어라 정답 시비).

## 4. 두더지잡기 ✅
- 장르와 "제한시간 안에 몇 마리" 규칙은 흔한 방식이라 써도 됨. 캐릭터, 그림, 효과음은 직접 만들기.
- 붙일 조건: 잠결에 손가락이 부정확하니 누르는 영역은 넉넉하게. 난이도별 목표 수와 시간 조절.

## 5. 미션 여러 개 묶기 ✅
- "미션을 연달아 붙인다"는 생각 자체는 독점할 수 없음. 화면 배치와 이름만 알라미와 다르게.
- 알라미는 유료 기능이라, 무료로 풀면 그대로 차별점이 됨 (기획 3번과 같은 방향).
- 처음부터 "알람 1개 = 미션 목록"으로 데이터 구조를 잡아 두면 됨.

## 6. 다시 잠들기 방지 ✅
- 알람을 끈 뒤 몇 분 후 "깨어 있나요?" 알림을 보내고, 정해진 시간 안에 누르지 않으면 알람을 다시 울리는 방식. 일반 알림과 예약 알람만 쓰므로 정책 문제 없음.

## 7. 전원 끄기 방지 ❌ (지금은 빼기)
- 안드로이드는 원래 앱이 전원 끄기를 막을 수 없음. 하려면 "접근성 서비스"(장애인 보조용 권한)로 전원 메뉴를 감지해 닫아야 함.
- 구글플레이는 접근성 권한을 보조 목적이 아닌 곳에 쓰는 것을 엄격하게 심사함. 개인 개발자 첫 앱에서 거절되거나 계정 경고를 받을 위험이 큼. (알라미가 어떻게 허가받았는지는 별도 확인 필요)
- 대신: 폰을 다시 켜면 알람을 자동으로 다시 예약하고, 미션 중 앱이 꺼지면 다시 울리게 만들기. 이건 정책 문제 없음.

## 전체에 붙일 안전장치
- 비상 해제: 미션을 계속 실패해도 일정 시간(예: 15분)이 지나면 끌 수 있는 길을 둠. 무한 반복은 리뷰 폭탄과 실제 위험(급한 상황)을 부름.
- 미션 미리 해보기: 알람 설정 화면에서 미션을 미리 체험.
- 미션 중에는 알람 소리를 잠깐 줄였다가, 손을 놓으면 다시 키우기.
