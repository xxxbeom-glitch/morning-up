# 도움말 빈틈 안내 문구 (초안, TSK-083)

11-23 [기획 5] 작성. 근거: 결정 140, 141(수면 라운지 첫 버전 제외), 143(기기 호환성 대책), 145(다시 잠들기 방지 '한 번 더 확인'), `idea6-device-compat.md`.
앱 안 '자주 묻는 질문'(설정 > 도움말)과 결정 143 경고에 넣을 글이에요. 손님이 보는 글이라 가운뎃점과 긴 줄표로 말을 잇지 않았어요. 버튼과 메뉴 이름은 작은따옴표로 썼어요.

## 결론

- 앱이 막을 수 없는 빈틈은 네 가지예요: **강제 종료, 폰이 꺼져 있음, 방해 금지의 '알람 허용' 꺼짐, 삼성 최대 절전 모드.** 자주 묻는 질문 맨 앞에 한 항목으로 묶고, 하나씩 풀어 쓴 항목을 뒤에 둬요.
- 결정 145의 새 흐름('깼어요' 뒤 '정말 깼어요?')을 묻는 항목 3개를 더해요.
- 지금 자주 묻는 질문 7개 중 2개는 앱과 말이 달라 고쳐야 해요(아래 3절).
- 수면 라운지(결정 140)는 첫 버전에 없어서 도움말에 넣을 글이 없어요. 대신 남은 흔적 두 곳을 지워야 해요(아래 4절).

## 1. 자주 묻는 질문에 더할 항목

순서는 지금 항목 7개 앞에 1~5를, 뒤에 6~8을 둬요. 문자열 키는 개발이 정해요(`faq_q8`부터 등).

| # | 질문 | 답 |
|---|---|---|
| 1 | 알람이 울리지 않을 수 있는 경우가 있나요? | 네, 앱이 막을 수 없는 경우가 네 가지 있어요. 앱을 '강제 종료'했을 때, 폰이 꺼져 있을 때, 방해 금지 모드에서 '알람 허용'을 꺼 두었을 때, 삼성 '최대 절전 모드'를 켰을 때예요. 아래 질문에서 하나씩 알려 드릴게요. |
| 2 | 앱을 강제 종료하면 어떻게 되나요? | 설정의 '강제 종료'나 정리 앱으로 앱을 멈추면 안드로이드가 예약된 알람을 모두 지워요. 앱을 다시 열 때까지 알람이 울리지 않아요. 삼성과 대부분의 폰에서 최근 앱 화면을 밀어서 닫는 것은 괜찮아요. 혹시 예약이 지워졌던 흔적이 보이면 앱을 열 때 알려 드려요. |
| 3 | 폰이 꺼져 있으면요? | 꺼져 있는 동안에는 울리지 않아요. 알람 시각에서 10분 안에 폰을 켜면 바로 울리고, 그보다 늦으면 '놓친 알람' 알림만 남겨요. |
| 4 | 방해 금지나 수면 모드에서도 울리나요? | 기본 설정이면 울려요. 다만 방해 금지(삼성 '수면 모드' 포함)에서 '알람 허용'을 꺼 두면 소리가 나지 않아요. 앱이 이 상태를 알아채면 미리 알려 드려요. 폰 설정의 방해 금지에서 '알람'을 허용해 주세요. |
| 5 | 삼성 최대 절전 모드에서는요? | 최대 절전 모드에서는 허용한 몇 개 앱만 움직여서 알람이 울리지 않을 수 있어요. 최대 절전 모드를 켤 때 morning-up을 허용 앱에 넣어 주세요. |
| 6 | '깼어요'를 눌렀는데 또 물어봐요 | '다시 잠들기 방지'와 '한 번 더 확인'이 켜져 있으면, '깼어요'를 누른 뒤 몇 분 뒤에 '정말 깼어요?'를 한 번 더 물어요. 버튼을 10초 동안 꾹 누르면 끝나요. 시간 안에 하지 않으면 알람이 처음부터 다시 울려요. |
| 7 | '정말 깼어요?'를 미리 끝낼 수 있나요? | 네. '깼어요'를 누르면 알림 창에 다음에 물어볼 시각이 떠요. 그 알림을 눌러 '깼어요'를 10초 동안 누르면 바로 끝나요. 알림이 꺼져 있으면 홈 위쪽 '한 번 더 확인이 남았어요'를 눌러도 돼요. 출근길에 나서기 전에 미리 끝내 두면 편해요. |
| 8 | 다시 묻는 간격이나 횟수는 어디서 바꾸나요? | 알람마다 켜고 끄는 것은 알람 편집의 '다시 잠들기 방지'에서 해요. 묻는 간격, 대답할 시간, '한 번 더 확인'과 확인할 시간은 설정에서 한 번에 바꿔요. 모든 알람에 같이 적용돼요. |

참고: 6~8번의 '정말 깼어요?', '한 번 더 확인', '확인할 시간' 같은 이름은 결정 145와 디자인(TSK-163)에서 정한 이름이에요. 화면 이름이 바뀌면 이 글도 같이 고쳐요.

## 2. 결정 143 경고 문구

개발(결정 143)이 넣는 경고에 쓸 글이에요. 이미 개발 방이 문구를 정했다면 이 표와 맞춰 보기만 해요.

| 언제 | 어디 | 문구 |
|---|---|---|
| 방해 금지에서 알람이 막혀 있음 | 설정 '권한' 화면 줄 아래 설명, 전날 밤 확인 알림 | 제목 '방해 금지에서 알람이 꺼져 있어요' / 본문 '이대로면 내일 알람 소리가 나지 않아요. 눌러서 '알람'을 허용해 주세요.' |
| 울리기 직전 알람 볼륨이 0이라 최소로 올림 | 울림 뒤 조용한 알림 한 번 | '알람 볼륨이 0이라 작게 올려서 울렸어요.' |
| 강제 종료 흔적을 알아챔 | 앱을 열 때 대화상자 한 번 | 제목 '알람이 꺼져 있었던 것 같아요' / 본문 '앱이 강제 종료되면 알람이 울리지 않아요. 다시 예약해 두었어요.' / 버튼 '확인', '자세히 보기'(자주 묻는 질문 2번으로) |
| 배터리 '제한' 상태 | 지금 있는 H2 배너, 배터리 알림 그대로 | 지금 문구 그대로('배터리 사용 제한이 켜져 있어요') |

## 3. 지금 자주 묻는 질문에서 고칠 곳

| 키 | 지금 | 문제 | 고칠 글 |
|---|---|---|---|
| `faq_q6`, `faq_a6` | 내일 한 번만 알람을 쉬고 싶어요 / 홈에서 반복 알람을 끄면 카드에 '내일 다시 켜기'가 나와요… | 버튼 이름은 '이번만 쉬기'(11-16 확정, 11-23 Leader 확인). 앱의 `home_rest_offer` '내일 다시 켜기'는 ISS-037로 개발이 고쳐요 | 질문: '다음 한 번만 알람을 쉬고 싶어요' / 답: '홈에서 반복 알람을 끄면 카드에 '이번만 쉬기'가 나와요. 누르면 다음 한 번만 쉬고 그다음부터는 다시 울려요.' |
| `faq_a7` | 알람 편집에서 '전원 종료 방지'를 켜면… | 결정 101로 전원 종료 방지는 설정에 있어요(앱 설정 화면 `settings_power_guard` 줄) | 설정에서 '전원 종료 방지'를 켜면 미션을 하는 동안 전원 메뉴가 열려도 바로 닫혀요. 처음 켤 때 접근성 권한을 켜는 방법을 안내해 드려요. (11-23 Leader 확인) |
| `faq_a1` | 설정의 '권한'에서 필수 권한이… | 빈틈 안내가 없어요 | 끝에 한 문장 더하기: '강제 종료나 방해 금지처럼 앱이 막을 수 없는 경우는 아래 질문을 봐 주세요.' |

## 5. 온보딩에 한 줄 넣을지

- `idea6-device-compat.md`는 '온보딩이나 도움말에 강제 종료 한 줄'이라고 했어요. 온보딩은 이미 권한 화면이 여럿이라 더 넣지 않고, 위 1, 2번 항목과 강제 종료 흔적 대화상자로 충분하다고 봐요.
