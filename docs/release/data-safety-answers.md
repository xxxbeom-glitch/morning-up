# 플레이 콘솔 데이터 보안 양식 답변 (초안, TSK-092)

11-23 [기획 5] 작성. 지금 코드(`WeatherRepository.kt`, `SettingsScreen.kt`, 매니페스트)와 `docs/privacy-policy-draft.md`를 기준으로 했어요. 플레이 콘솔에 넣지 않았어요(사용자가 직접 넣어요).
구글 정책 원문은 이번에 다시 확인하지 않았어요. 아래 '구글 기준'은 데이터 보안 양식 안내에서 알려진 정의를 옮긴 것이라, 넣기 전에 콘솔 화면의 설명과 한 번 맞춰 봐요.

## 결론

- **모으는 것은 '대략적인 위치' 하나**예요(날씨 켜고 위치 허용한 사람만, 선택). 다른 곳에 '공유'는 없음, 전송 중 암호화 있음, 서버에 보관 안 함.
- 사진, 흔들기 센서, 진단 기록, 알람 설정은 폰 밖으로 안 나가서 '수집'이 아니에요.
- '의견 보내기' 메일은 사용자가 자기 메일 앱으로 직접 보내는 것이라 앱의 수집이 아니에요.

## 1. 데이터 수집 및 보안

| 콘솔 질문 | 답 | 이유 |
|---|---|---|
| 앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** | 날씨를 받으려고 반올림한 위치를 앱 밖(Open-Meteo)으로 보내요. 구글 기준으로 기기 밖으로 보내면 '수집'이에요 |
| 수집하는 모든 사용자 데이터는 전송 중에 암호화되나요? | **예** | `https://api.open-meteo.com`으로만 보내요 |
| 사용자가 데이터 삭제를 요청할 수 있는 방법을 제공하나요? | **아니요** | 계정이 없고, 보낸 위치를 저희가 보관하지 않아요. 폰 안 데이터는 앱 삭제나 '저장공간'에서 지워져요. 콘솔에 '데이터를 보관하지 않음'에 해당하는 선택지가 있으면 그걸 골라요 |
| (계정 삭제 URL) | 해당 없음 | 계정 만들기가 없어요 |

대략적인 위치를 이렇게 답한 이유:

| 질문 | 답 | 근거 |
|---|---|---|
| 대략적인지 | 대략적 | 구글 기준 '3제곱킬로미터 이상 넓이'. 0.05도 칸은 약 5.5km x 4.5km라 그보다 넓어요(`CELLS_PER_DEGREE = 20.0`). 권한도 `ACCESS_COARSE_LOCATION`만 있어요 |
| 공유인지 | 아니요 | Open-Meteo는 날씨를 알려 주려고 저희 대신 처리하는 곳이라, 구글 기준 '서비스 제공업체에 전송'은 공유에서 빠져요. **11-24 사용자 확정: 공유 없음** |
| 임시 처리인지 | 예 | 위치는 요청에만 쓰고 저장하지 않아요. 폰에는 날씨 종류만 6시간 둬요 |
| 필수인지 | 선택 | 날씨 애니메이션을 끄거나 위치를 허용하지 않아도 앱을 다 쓸 수 있어요 |
| 목적 | 앱 기능 | 홈 하늘과 W1의 날씨 표시. 광고, 분석, 개인 맞춤에는 안 써요 |

## 3. 넣지 않는 것과 이유

| 항목 | 왜 안 넣나 |
|---|---|
| 의견 보내기 메일(메일 주소, 폰 모델, 안드로이드 버전, 앱 버전, 꺼진 권한) | 앱은 메일 앱을 열어 본문을 채워 줄 뿐이고, 보내기는 사용자가 자기 메일 앱으로 해요. 앱 밖 경로로 받는 정보는 이 양식 대상이 아니에요. 개인정보처리방침 4번에는 적었어요 |
| 안드로이드 자동 백업 | 운영체제 기능으로 사용자의 구글 계정에 백업돼요. 저희가 받지 않아요 |
| Open-Meteo가 보는 IP 주소 | 인터넷 요청이면 생기는 값이고 저희가 받거나 보관하지 않아요. 개인정보처리방침 2번에 적었어요 |
| 흔들기 미션의 움직임 감지 | 폰 안에서 횟수만 세고 버려요 |
| '다른 앱 위에 표시' 권한(`SYSTEM_ALERT_WINDOW`) | 알람 울림 화면을 다른 앱 위로 띄우기 위해 써요(다시 울릴 때 맨 앞에 띄우기, 결정 73). 화면을 띄우기만 하고 다른 앱의 내용은 읽지 않아서 수집할 데이터가 없어요. 11-24 ISS-038 확인 |
| 플레이 콘솔 기본 통계, 비정상 종료 통계 | 구글 플레이가 모으는 것이라 앱이 신고하지 않아요 |

## 5. 코드가 바뀌면 다시 볼 것

- 분석 도구, 오류 보고 도구(예: Crashlytics), 광고를 넣으면 '앱 활동', '앱 정보 및 성능', '기기 ID'를 다시 답해야 해요.
- 진단 기록을 '보내기' 기능으로 밖에 보내게 되면 '앱 정보 및 성능 > 기타'가 수집으로 바뀌어요.
- 지역을 직접 고르는 날씨 방식으로 바꾸면 위치 수집이 없어질 수 있어요.
