## 결정 153. 홈에서 알람을 끄거나 지울 때도 '남은 확인을 멈췄어요' 토스트 (결정 145 7절 고침)
- 사용자 확정(11-25): "토스트 넣어"
- 홈에서 그 알람 토글을 끄거나 알람을 지울 때, 남은 확인(W2, W3)이 있었으면 편집 화면 저장 때와 같은 토스트 '남은 확인을 멈췄어요'를 띄워요.
- 남은 확인이 없으면 토스트를 띄우지 않아요.
- 안내 알림이 사라지는 것은 그대로예요.
- 토스트 모양은 기존 저장 토스트(H6) 그대로라 새 프레임은 필요 없어요.
- 이유: 같은 결과(남은 확인 취소)에는 같은 안내를 줘요. 조용히 꺼져 버그처럼 보이던 것을 막아요.
- 고친 곳: `docs/decisions-11-23.md` 결정 145 7절 표 첫 줄 '보이는 것'
- 관련 일: TSK-184(개발, [개발 16])

## 결정 154. '이번만 쉬기' 기준 날과 쉬는 중 남은 시간 표시 (11-16 H8 결정 고침)
- 사용자 확정(11-25): "고쳐"
- 생긴 일: 수요일 알람이 울린 뒤 남은 확인을 기다리는 중에 홈 토글로 끄고 '이번만 쉬기'를 눌렀더니, 목요일을 쉬게 되어 카드에 '금요일에 다시 울려요'가 떴어요. 지금 코드(`HomeViewModel.restOnce`)는 누른 때부터 다음 한 번을 쉬게 만들어져 있어요.
- 규칙
  1. 그 알람이 울리는 중이거나, 울린 뒤 남은 확인(W2, W3)을 기다리는 중에 누른 '이번만 쉬기'는 오늘 것을 쉰 걸로 쳐요. 다음 정상 울림은 건너뛰지 않아요.
  2. ~~그 밖의 때(예: 수요일 밤에 끔)는 지금처럼 다음 한 번을 쉬어요.~~ (결정 156으로 바뀜: 울리는 날에 누르면 그날 것만 쉼)
  3. '울린 뒤'는 그 알람의 남은 확인이 모두 끝나거나 취소된 때 끝나요. 그 뒤에 누르면 2번 규칙을 따라요. '다시 잠들기 방지'가 꺼져 있으면 울림이 끝나는 때(W1) 바로 끝나요.
  4. 홈 토글을 끄면 그 순간 남은 확인이 취소돼요(결정 153). 이렇게 끄면서 생긴 '이번만 쉬기' 버튼은 끄기 직전 상태로 판단해요. 그래서 울린 뒤(남은 확인 대기 중)에 끈 경우면 오늘 것을 쉰 걸로 쳐요. 이게 빠지면 버튼을 누를 때는 늘 '울린 뒤'가 이미 끝나 있어서 고친 게 소용없어요.
- 시각만으로 나누지 않는 이유: 밤에 내일 쉬려고 끈 사람까지 다음 날 울리면 안 돼서예요.
- 쉬는 중 카드 글
  - 다음 울림까지 24시간 안: 'N시간 N분 뒤 다시 울려요'(분이 0이면 'N시간 뒤 다시 울려요')
  - 1시간 안: 'N분 뒤 다시 울려요'
  - 24시간 넘음: 지금처럼 'O요일에 다시 울려요'
  - 수 세기: 홈 위 '…시간 …분 후' 문구와 같은 계산(`TimeUntil`, 분은 올려서 셈, 0분은 나오지 않음)을 써요. 올려서 24시간이 되면(일 칸이 1 이상) 요일 문구로 보여요. (11-25 사용자 지시로 앞의 '시간 내림, 분 올림' 줄을 이걸로 바꿈)
  - 이유: 사용자가 알라미의 남은 시간 표시를 보고 원했어요.
- 고친 곳: `docs/decisions-11-17.md` 16번 줄(H8), `docs/design-system.md` 이번만 쉬기 문구
- 관련 일: TSK-185(기획). 앱 고치기는 개발 몫이에요.

## 결정 155. 버튼 속이기: 버튼 하나가 화면 안을 공처럼 튕겨 다님 (결정 146 2절 고침)
- 사용자 지시(11-25): "미션 시작 버튼 움직이는 거는 딱 버튼 한 개만 유지하고, 이 화면을 하나의 박스나 통으로 생각해서 탱탱볼이나 농구공처럼 계속 랜덤 방향으로 왔다 갔다 튕겨지는 걸 구현하고 싶어. 페이크로 여러 개는 나도 짜증날 것 같아서"
- 아래 기본 규칙은 Leader가 정했어요. 관련 일: TSK-189(기획), TSK-190(개발, [개발 16]), TSK-191(디자인, [디자인 16]).

### 규칙
1. 버튼은 진짜 하나뿐이에요. 가짜 버튼, 숨바꼭질, 강도 3단계(약하게, 보통, 세게)는 없애요.
2. 통은 울림 화면 전체예요(상태 표시줄과 아래 내비게이션 바 안쪽). 버튼은 하늘, 날짜, 시각 위로도 지나가요.
3. 움직임: 버튼이 같은 속도로 곧게 가다가 벽에 닿으면 튕겨요. 튕길 때 각도를 ±15도 무작위로 틀어서 길을 외울 수 없게 해요. 처음 방향도 무작위예요. 거의 수평이나 수직(15도 안쪽)으로 가면 각도를 고쳐 줘요.
4. 속도 칩 3개(느리게, 보통, 빠르게)는 남겨요. 처음 값은 보통이에요. 숫자는 개발이 폰에서 맞춰요(시작값: 1초에 화면 너비의 0.4, 0.7, 1.1배).
5. 크기: 지금 크기(112dp)로 고정해요. 무작위로 바꾸지 않아요. (11-25 사용자 답 "고정"으로 고침. 처음엔 울릴 때마다 40~112dp 무작위였어요)
6. 그대로 두는 것: 화면을 처음 만진 때부터 20초 지나면 원래 자리로 돌아가 멈춤, 움직이는 중에 눌러도 인정, 접근성 기능을 쓰면 자동으로 꺼짐, '미리 해보기', '미션 시작'과 '알람 끄기' 둘 다에 걸기.
7. 저장값의 강도(level)는 쓰지 않아요.
- 분명히 해 둠(기획 6): 처음 만지기 전에도 튕기고 있어요(20초 세기만 첫 터치부터).

## 결정 156. '이번만 쉬기'는 울리는 날에 누르면 그날 것만 쉼 (결정 154 2번 규칙 고침)
- 사용자 확정(11-25): "추천대로 고쳐"
- 생긴 일: S24+에서 수요일 오후(그날 6:30 알람이 울리고 남은 확인도 끝난 뒤)에 '이번만 쉬기'를 누르니 '금요일에 다시 울려요'가 떴어요. 사용자가 처음 지적한 것(11-25 오전, "수요일인데 목요일에 다시 울린다고 떠야 한다")은 모든 경우의 말이었는데, 결정 154가 '울리는 중이거나 남은 확인 대기 중'일 때만으로 좁혀 적었어요. '밤에 내일 쉬려고 끈 사람' 이유는 사용자가 한 말이 아니었어요.
- 규칙 ('이번만' = '오늘만')
  1. 울리는 중이거나 남은 확인(W2, W3) 대기 중에 끈 알람: 지금처럼 그 울림의 날을 쉰 걸로 쳐요(결정 154 1, 3, 4번 그대로). 자정을 넘겨 확인이 이어진 경우도 울린 날 기준이에요.
  2. 그 밖에, 오늘이 그 알람이 울리는 날(반복 요일과 공휴일 규칙으로 판단)이면 오늘 것을 쉬어요. 이미 울렸으면 쉴 것이 없어 다음 울림 그대로, 아직 안 울렸으면 오늘 울림만 건너뛰어요. 어느 쪽이든 내일부터는 정상으로 울려요.
  3. 오늘이 울리지 않는 날(예: 월~금 알람의 토, 일)이면 다음 울림 하나를 쉬어요(지금과 같음).
- 예시 (월~금 6:30 알람)
  | 누른 때 | 다음 울림 |
  |---|---|
  | 수 6:30 울린 뒤 아무 때나(오후, 밤 포함) | 목 6:30 |
  | 수 새벽 5:00(울리기 전) | 목 6:30(수요일 쉼) |
  | 토, 일 | 화 6:30(월요일 쉼) |
- 바뀌는 점: 울리는 날 밤에 끄면서 다음 날 것을 미리 쉬는 방법은 없어져요.
- '모든 알람 끄기', 선택해서 끄기에서 생긴 '이번만 쉬기'도 같은 규칙이에요. 쉬는 중 카드 글(결정 154 아래쪽)은 그대로예요.
- 검수 반성: QA와 Leader 폰 시험 모두 좁힌 규칙을 기준으로 '금요일'을 통과로 봤어요. 앞으로 결정 문서를 만들 때 사용자 원문과 다르게 좁히거나 이유를 덧붙이면 그 점을 사용자에게 따로 확인해요.
- 관련 일: TSK-192(개발), ISS-049

## 결정 157~161. 알라미 비교 추천 1~5 (TSK-195, 근거 `research/M-alarmy-compare.md` 5절, 6절)
- 사용자 지시(11-25): "1,2,3,4,5 해줘" (6절 추천표 1~5위)
- 사용자 확정(11-25): "모두 추천대로". 결정 158은 A안(선택 모드 바), 아래 [사용자 확인 필요] 표시는 모두 추천안대로 확정. H5는 보관 페이지로 옮김. H3-3 바는 다섯 칸(켜기, 끄기, 이번만 쉬기, 복제, 삭제)
- 먼저 알아 둘 것: 지금 홈 카드에는 '더보기' 버튼이 없어요. 카드를 누르면 편집(S0), 길게 누르면 선택 모드(H3-1, H3-2)이고, 선택 모드 아래 바에 '켜기', '끄기', '복사', '삭제'가 있어요(11-16에 카드 길게 누르기 시트 H4를 빼고 정한 구조). 오른쪽 위 '더보기'(H3)는 '모든 알람 끄기', '선택' 두 줄짜리 홈 메뉴예요. 그래서 추천 2, 5의 '카드 더보기'는 그대로 옮길 곳이 없어 아래처럼 정했고, 이 부분은 사용자 확인이 필요해요.
- 아래에서 **[사용자 확인 필요]** 표시는 사용자 말보다 좁히거나 넓히거나 기획이 이유를 덧붙인 곳이에요(결정 156 반성). 표시 없는 곳은 사용자 말과 6절 표를 그대로 옮긴 것이에요.

### 결정 157. 홈 하늘 위 다음 알람 문구를 누르면 그 알람 편집(S0)
1. 하늘 위 큰 문구('N시간 N분 후, 알림이 울립니다')와 그 아래 날짜 줄을 한 덩어리로 눌러요. 누르면 그 문구가 가리키는 알람, 즉 다음에 울릴 알람의 S0가 열려요.
2. '다음에 울릴 알람'은 쉬기를 넣고 센 것이에요. 쉬는 알람이 다른 알람보다 먼저 울리면 그 쉬는 알람이 열려요. 같은 시각에 둘 이상 울리면 목록에서 위에 있는 것(먼저 만든 것)이 열려요.
3. 켜진 알람이 없을 때('울릴 알람이 아직 없어요', '알람이 모두 꺼져 있어요')는 눌러도 아무 일이 없어요. [사용자 확인 필요: 사용자 말에 없는 경우를 기획이 정함. 빈 홈에는 '알람 만들기' 버튼이 따로 있어서 새 알람으로 보내지 않았어요]
4. 선택 모드 중에는 누를 수 없어요. 위 '한 번 더 확인' 띠는 따로 눌리는 그대로예요.
5. 보이는 표시는 더하지 않고 누를 때 눌림 효과만 줘요. 화면 읽기 기능에는 '다음 알람 편집'으로 읽혀요. [사용자 확인 필요: 화살표 같은 표시를 넣을지는 디자인이 시안으로 보여 줘도 돼요]

### 결정 158. 켜진 알람을 끄지 않고 '이번만 쉬기' (추천 2)
1. 들어가는 곳: 선택 모드 아래 바에 '이번만 쉬기'를 더해요. 카드에 새 더보기 버튼은 만들지 않아요. **[사용자 확인 필요]** 사용자가 고른 말은 '카드 더보기'인데 그 버튼이 없어요. 두 안을 비교했어요.
   | | A. 선택 모드 바에 더함 (기획 추천) | B. 카드마다 더보기(⋮) 버튼 새로 |
   |---|---|---|
   | 누르는 수 | 길게 누름, '이번만 쉬기' (2번) | ⋮, '이번만 쉬기' (2번) |
   | 화면 바뀜 | 바 글 하나 더함. 카드 모양 그대로 | 모든 카드에 버튼이 생겨 토글 옆이 붐빔 |
   | 여러 개 한꺼번에 | 됨 | 안 됨 |
   | 11-16 결정과 | 맞음(길게 누르면 선택 모드) | 카드 메뉴를 다시 만드는 셈 |
   - 추천 이유: 지금도 '토글 끄기, 이번만 쉬기' 2번이면 쉴 수 있어서 B로 얻는 걸음 수 이득이 없고, 카드 디자인은 유지하는 게 원칙이에요. B를 고르면 결정 160의 '복제', 결정 159의 '삭제'도 같은 메뉴에 넣어요.
2. 보이는 조건: 고른 알람 가운데 '쉴 울림'이 있는 반복 알람이 하나라도 있으면 보여요. 누르면 그 알람들만 쉬고, 나머지는 그대로예요.
3. 쉬는 기준은 결정 156 그대로예요. 오늘이 울리는 날이고 아직 안 울렸으면 오늘 것, 오늘이 안 울리는 날이면 다음 하나를 쉬어요.
4. **[사용자 확인 필요]** 오늘 이미 울린 알람(남은 확인 대기 포함)은 결정 156으로 '쉴 것이 없어요'. 토글로 끌 때는 '꺼 두되 내일 저절로 켜짐'이라는 뜻이 있지만, 켜진 채로 쉬면 아무것도 바뀌지 않아요. 그래서 이 알람만 고르면 '이번만 쉬기'를 보이지 않아요. 울린 날 밤에 내일 것을 미리 쉬는 방법은 결정 156대로 없어요.
5. 쉬고 난 카드는 지금 쉬는 중 카드(H8-2, 결정 154 문구)와 똑같아요. **[사용자 확인 필요]** 지시의 '켜진 채로'는 '끄는 걸음 없이'로 읽었어요. 토글이 켜진 모양인 쉬는 카드를 따로 만들면 같은 상태가 두 모양이 되어 헷갈려서, 토글 끈 모양 하나로 둬요.
6. '쉬기 취소': 쉬는 카드를 고르면 바에 이미 '켜기'가 보이고, 누르면 쉬기가 풀려 정상으로 울려요(지금 동작). 같은 일을 하는 '쉬기 취소'를 따로 더하지 않아요. 카드 토글을 켜도 똑같이 풀려요. [사용자 확인 필요: 글을 '쉬기 취소'로 따로 보이게 할지]
7. 한 번 알람, 꺼진 알람만 고르면 보이지 않아요. 누른 뒤 선택 모드는 닫히고 알림은 띄우지 않아요(카드 글이 바뀌는 것으로 충분).

### 결정 159. 알람 편집 저장 때 쉬기 처리 (추천 3)
1. 쉬는 알람을 편집해서 저장할 때, 언제 울리는지를 바꾸는 값이 바뀌었으면 쉬기를 풀어요. 대상은 시각, 요일이에요. **[사용자 확인 필요]** '공휴일에는 쉬기' 켬, 끔도 울리는 날을 바꿔서 같이 넣었어요(사용자 말보다 넓힘).
2. 그 밖의 값(소리, 볼륨, 진동, 미션, 이름, 다시 울림, 다시 잠들기 방지 등)만 바꿨으면 쉬기를 그대로 둬요.
3. 바꿨다가 처음 값으로 되돌려 저장하면 '안 바꿈'으로 쳐요(저장 순간 처음 값과 비교).
4. 쉬기를 풀었을 때 저장 토스트(H6) 대신 '이번만 쉬기를 풀었어요. N시간 N분 뒤에 울려요'를 띄워요. 수는 홈 위 문구와 같은 계산이에요. 쉬기를 그대로 둔 저장은 지금 저장 토스트 '알람을 저장했어요. N시간 N분 뒤에 울려요'이고, 이 수는 쉬기를 넣고 센 다음 울림이에요.
5. 편집 화면(S0)의 '…후에 울려요' 안내 글: 시각, 요일을 안 바꾼 동안은 쉬기를 넣고 세요. 바꾸는 순간부터는 쉬기를 뺀 새 울림으로 세요. 알라미처럼 쉬기를 무시한 수를 보여 주지 않아요. [사용자 확인 필요: 사용자 말에 없던 편집 화면 문구를 기획이 정함]
6. 저장하지 않고 나가면 쉬기는 그대로예요.
7. 남은 확인을 멈춘 저장(결정 145)과 겹치지 않아요. 쉬는 알람은 쉬기를 누를 때 남은 확인이 이미 끝났거나 취소돼 있어요.

### 결정 160. 삭제 확인 창(H5)을 없애고 되돌리기 스낵바(H7)만 (추천 4)
1. 선택 모드 '삭제'를 누르면 묻지 않고 바로 지우고, 아래에 스낵바를 띄워요. 하나든 여러 개든, 미션이 있든 없든 같아요.
2. 스낵바 글: 하나면 '알람을 지웠어요', 여러 개면 '알람 N개를 지웠어요'. 버튼 '되돌리기'. 떠 있는 시간은 지금 스낵바와 같아요.
3. '되돌리기'를 누르면 지운 알람이 모두 처음 모습(쉬기 상태 포함)으로 돌아와요. 멈춘 남은 확인은 돌아오지 않아요(결정 153 그대로).
4. 결정 153 토스트와 순서: 스낵바가 먼저, 스낵바가 닫히면(시간이 다 됨, 밀어서 닫음, '되돌리기') 이어서 '남은 확인을 멈췄어요' 토스트예요. 되돌려도 확인은 멈춘 채라 토스트는 그대로 떠요. 이유: '되돌리기'는 몇 초 안에만 누를 수 있어서 먼저 보여야 해요. (지금 앱이 이미 이 순서예요)
5. 스낵바가 떠 있는 중에 또 지우면, 앞의 삭제는 확정되고 새 스낵바로 바뀌어요. 앞에서 줄 서 있던 토스트는 새 것과 합쳐 한 번만 띄워요.
6. 없어지는 글: '이 알람을 삭제할까요?', '알람 N개를 삭제할까요?', 본문 셋, '취소', '삭제'(H5 버튼).

### 결정 161. 알람 복제 (추천 5)
1. 들어가는 곳: 선택 모드 아래 바의 지금 '복사'를 '복제'로 이름만 바꿔요. 이미 있는 기능이에요. [사용자 확인 필요: 결정 158을 B로 고르면 카드 메뉴에도 '복제'를 넣어요]
2. 복제본은 원본과 모든 설정이 같은 새 알람이에요. 켜짐, 꺼짐도 원본을 따라요. 쉬기 날짜와 남은 확인은 복사하지 않아요(지금 동작과 같음).
3. 놓이는 곳: 목록은 다음 울림 순서라, 같은 때 울리는 복제본은 원본 바로 아래에 와요. **[사용자 확인 필요]** 원본이 쉬는 중이면 복제본은 쉬기가 없어 더 먼저 울리므로 원본보다 위에 놓여요. 목록 순서 규칙을 깨지 않으려고 '늘 바로 아래'는 지키지 않아요.
4. 복제 뒤 토스트: 하나면 '알람을 복제했어요', 여러 개면 '알람 N개를 복제했어요'. 선택 모드는 닫혀요.

## 결정 162. 쉬는 중 카드: 다음 울림이 7일 넘게 남으면 날짜를 붙임 (결정 154 표시 규칙 더함)
