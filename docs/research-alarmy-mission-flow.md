# 알라미 기상 미션 설정 흐름 조사 (11-17)

갤럭시 S24+에 깔린 알라미(`droom.sleepIfUCan`, 무료 사용자)에서 알람 편집 → 기상 미션 고르기 → 설정 → 편집으로 돌아오기까지 따라가 봤어요. 캡처는 `research/alarmy-mission-flow/`에 번호 순으로 있어요.

- 기존 1:38 알람(꺼진 상태, 미션 없음) 편집 화면에서 시험했고, 저장하지 않고 X로 나왔어요. 나온 뒤 다시 열어 미션 0/5 그대로인 것을 확인했어요.
- 결제 창은 X로만 닫았어요. 폰 화면 회전 값은 시작과 끝 모두 0/0이에요.

## 한눈에 보기

**알라미는 미션 목록도, 미션 설정도 모두 같은 바텀시트 하나 안에서 넘어가요.** 미션을 누르면 시트가 설정 화면으로 바뀌고, 위쪽은 미리보기(예제 영상이나 예제 문제), 아래쪽은 설정이에요. '완료' 한 번이면 편집 화면으로 바로 돌아와요. 편집 화면 → 미션 칸 → 미션 → 완료, **누르는 횟수 3번**이에요.

## 단계별 표

| 단계 | 캡처 | 화면 이름 | 무엇을 누르나 | 화면 구성 요약 |
|---|---|---|---|---|
| 1 | 01 | 알람 편집 | (시작) | 페이지. 위에서부터 알람 이름, 'n시간 n분 후에 울려요', 시각 드럼롤, 요일 칸, **'기상 미션' 카드(0/5)**, 아래 고정 빨간 '저장'. 미션 카드 안에 + 칸 5개가 가로로 늘어서 있어요(오른쪽은 잘려서 옆으로 밀어 봄) |
| 2 | 02, 03 | 미션 목록 '미션' | 첫 번째 + 칸 | **바텀시트**(화면 위쪽 약 1/7만 남기고 덮음, 뒤 편집 화면이 어둡게 보임). 머리에 제목 '미션'과 오른쪽 X. 묶음 제목 3개(인기있는 미션, 정신부터 깨우는 미션, 몸부터 깨우는 미션) 아래 한 줄짜리 목록(아이콘 + 이름 + AI, NEW, BEST, HOT 같은 작은 딱지). 프로 전용은 아이콘에 PRO 표시. 고르는 표시 없이 줄을 누르면 바로 다음 단계로 가요 |

## 미션 개수, 순서, 지우기

| 항목 | 알라미 |
|---|---|
| 몇 개까지 | 5개(카운트 'n/5'로 늘 보여 줌). 무료는 1개, 나머지 칸은 자물쇠 |
| 넣는 방법 | 빈 + 칸을 하나씩 눌러 하나씩 넣음. 목록에서 여러 개를 한 번에 고르지 않아요 |
| 순서 | 칸 순서 = 미션 순서. 순서 바꾸기는 무료라 확인 못 함 |
| 바꾸기 | 채워진 칸을 누르면 목록이 다시 열리고 다른 미션을 고르면 바뀜 |
| 지우기 | 칸 오른쪽 위 X. 확인 없이 바로 지움 |
| 미리 해보기 | 설정 시트 아래 왼쪽 '미리보기' 버튼. 편집 화면에는 없음 |

## 모닝업 S0~S1 미션 흐름과 비교

모닝업(피그마 S0, S1-2, S1-3~S1-7, `docs/design-system.md` 327~331줄): 편집 S0 '미션 선택' 줄 → **S1-2 미션 고르기 페이지**(카드 목록, 오른쪽 체크 원) → 카드를 누르면 **미션 설정 바텀시트**(난이도와 개수는 '< 값 >' 넘기기, 아래 '미리보기' + '선택 완료') → 페이지로 돌아와 뒤로 → 편집. 편집 화면 미션 카드 안에 '미리 해보기' 버튼이 따로 있어요.

| | 알라미 | 모닝업 지금 |
|---|---|---|
| 미션 목록 | 바텀시트 | 페이지(S1-2) |
| 설정 | 목록과 같은 시트 안에서 화면만 바뀜 | 페이지 위에 바텀시트가 따로 뜸 |
| 편집까지 돌아오는 데 누르는 횟수 (미션 1개) | 3번 (칸, 미션, 완료) | 4번 (미션 줄, 카드, 선택 완료, 뒤로) |
| 미리보기 | 시트 위쪽 절반이 늘 예제(문제가 저절로 풀리는 움직임, 또는 영상) + '미리보기' 버튼 | 예제는 줄 아래 서브 글자 '예: 7 + 5' 한 줄 + '미리보기' 버튼 |
| 난이도 고르기 | 7칸 슬라이더 + 단계 이름(보통, 지옥 모드) | '< 4단계 >' 넘기기 |
| 개수 고르기 | 세로 드럼롤 + 단위 | '− 10 +' 넘기기 |
| 편집 화면에 보이는 모습 | 칸 5개에 아이콘 + 값('11회'), 'n/5' | 설정 줄 한 줄 값('Drop Words 외 1개') + '미리 해보기' 버튼 |
| 지우기 | 편집 화면 칸의 X로 바로 | 시트 안 '선택 해제' |

### 눈에 띄는 차이 5개

1. **목록과 설정이 한 시트 안에 있어요.** 알라미는 미션 목록부터 바텀시트이고, 미션을 누르면 같은 시트가 설정 화면으로 바뀌어요(< 로 목록에 돌아감). 모닝업은 목록은 페이지, 설정은 그 위에 뜨는 또 다른 시트라 층이 두 겹이에요. 모닝업도 S1-2를 시트로 바꾸고 설정을 같은 시트 안 다음 화면으로 넣으면 한 단계 줄어요.
2. **'완료' 한 번이면 편집 화면까지 바로 돌아와요.** 모닝업은 '선택 완료' 뒤에 목록 페이지에서 한 번 더 뒤로 가야 해요.
3. **미리보기가 시트 위쪽 절반을 차지해요.** 버튼을 누르지 않아도 예제 문제가 저절로 풀리는 모습(또는 영상)이 계속 보이고, 난이도를 바꾸면 예제가 바로 바뀌어요. 모닝업은 예제가 줄 아래 작은 글자 한 줄이에요. 위쪽에 예제 영역을 크게 두면 '미리보기'를 안 눌러도 미션이 어떤 건지 알 수 있어요.
4. **편집 화면에서 미션을 칸으로 보여 주고 바로 지워요.** 칸마다 아이콘과 값('11회'), 오른쪽 위 X가 있어 무엇이 몇 개 들어갔는지 한눈에 보이고 지우기도 한 번이에요. 모닝업은 '미션 선택' 줄 값 한 줄이라 안을 보려면 들어가야 해요.
5. **목록에서는 고르기만 하고, 체크나 '선택 완료'로 따로 확정하지 않아요.** 알라미는 칸 하나에 미션 하나씩 넣는 방식이라 목록 줄을 누르면 곧바로 설정으로 가요. 모닝업은 체크 원, '선택 완료', '선택 해제'로 여러 개를 한 화면에서 관리해요. 알라미 방식이 더 단순하지만 여러 개를 넣으려면 칸마다 같은 과정을 반복해야 해요.

### 사용자 아이디어 (11-17): 미리보기 안에서 레벨 고르기

미리보기를 하는 화면 안에 레벨 고르기를 넣어, 레벨을 바꾸면 그 자리에서 바로 그 단계 문제로 바뀌게 하는 안이에요. 알라미는 '위 예제 + 아래 설정'으로 나눴는데, 이 안은 둘을 한 화면으로 합쳐요.

| 안 | 모습 | 좋은 점 | 걸리는 점 |
|---|---|---|---|
| A. 알라미식 | 시트 위쪽 예제(저절로 풀리는 움직임), 아래쪽 '< 4단계 >'와 개수 줄 | 지금 시안(S1-3~S1-7)에 예제 영역만 더하면 돼요 | 직접 풀어 보려면 '미리보기'를 따로 눌러야 해요 |
| B. 미리보기 안에서 고르기 | '미리보기'를 누르면 실제 미션 화면이 뜨고, 위쪽에 '< 4단계 >'가 붙어 바꾸면 문제가 바로 바뀜. 정한 단계로 '이 단계로 정하기' | 직접 풀어 보며 맞는 단계를 고를 수 있어요 | 미션 화면(M1~M4)마다 단계 바꾸기 자리를 넣어야 하고, 개수는 따로 정해야 해요 |

추천: **A를 기본으로 하고, B의 장점은 '미리보기' 화면 위쪽에 '< 단계 >'만 붙이는 정도로 더하기.** 시트에서 예제가 바로 바뀌니 대부분은 미리보기 없이 고르고, 직접 풀어 보고 싶은 사람만 미리보기에서 단계를 바꿔 보게 돼요. 미리보기에서 바꾼 단계는 시트 값에 그대로 반영돼요.

참고(가져오지 않을 점): 난이도 슬라이더와 개수 드럼롤은 모닝업의 '< 값 >' 넘기기 결정(11-16 사용자 지시)과 달라서 그대로 두는 게 맞아요. 지우기와 나가기에 확인 창이 없는 점은 모닝업의 S0-1 '저장 안 하고 나가기'와 다르게 가는 부분이에요.

## 피그마에 그린 추천안 시안 (11-17 확정, 결정 87, 88)

`화면` 페이지 알람 편집 (S) 섹션 오른쪽 끝(x 9320부터, 섹션 폭 11080)에 미션 4개의 예제 영역 시트 4장을 모았어요(섹션 폭 11080). 원래 S1-3~S1-6, M1~M4는 그대로 두었어요. 각 프레임 아래(y 920)에 움직임 메모가 있어요.

| 프레임 | x | 내용 |
|---|---|---|
| `S1-3A Quick Math 설정 시트 (예제 영역)` (`482:7852`) | 9320 | 시트 머리 아래 예제 영역('7 + 5 =', 답 칸 '12'). 난이도 줄 서브 숨김 |
| `S1-5A Drop Words 설정 시트 (예제 영역)` (`484:7940`) | 9760 | 예제 영역에 떨어지는 1단계 낱말(사과, 나무)과 답 칸 '사과'. 난이도 줄과 속도 줄 서브 모두 숨김(속도 서브는 11-17 사용자가 지움) |
| `S1-6A Pop Quiz 설정 시트 (예제 영역)` (`484:8020`) | 10200 | 예제 영역에 1단계 문제 '한글을 만든 왕은?'과 보기 두 개(정답 '세종대왕'이 골라진 모습) |
| `S1-4A Shake Shake 설정 시트 (예제 영역)` (`484:8099`) | 10640 | 난이도가 없어 예제 영역에 폰이 좌우로 흔들리는 그림(가운데 폰, 양쪽 잔상, 흔들림 선)과 아래 '3 / 10'. 실제로는 폰이 좌우로 기울며 반복하는 움직임(11-17 사용자 지시) |

시트 높이는 고정하지 않고 내용에 맞춰요(억지 여백 없음): Drop Words 620(설정 3줄), Quick Math와 Pop Quiz 564(2줄), Shake Shake 508(1줄). 예제 영역(게임 소개)은 모두 312x260으로 같고 '예제' 라벨은 두지 않으며, 버튼은 늘 시트 맨 아래예요(11-17 사용자 지시).

미리보기는 따로 화면을 만들지 않아요. 시트의 '미리보기'를 누르면 원래 미션 화면(M1~M4)이 원래 위쪽 줄(Mission Top Bar) 그대로 **1단계로** 열리고, 단계 바꾸기는 없어요. 단계별 예시는 바텀시트 예제 영역에서만 보여 줘요(11-17 사용자 지시). 그래서 그렸던 미리보기 4장(S1-3B, S1-5B, S1-6B, S1-4B)은 지웠어요.

아이콘은 디자인 시스템의 `icon/x`, `icon/chevron-left`, `icon/chevron-right`(Lucide) 인스턴스예요. 이미 고른 미션 시트(S1-7)는 아직 이 모양으로 바꾸지 않았어요.

앞으로 할 일(11-17 사용자 메모, 아직 손대지 않음): 바텀시트 예제 영역(프리뷰)은 스켈레톤 방식으로 바꿀 예정이에요.
