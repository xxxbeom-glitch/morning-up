# 미션 문제 출처

Pop Quiz 문제마다 사실을 확인한 곳이에요(`docs/mission-levels.md` Pop Quiz 출처 규칙, 11-16 사용자 결정).
11-20 사용자 결정 '추천안대로'로 단계마다 40문제를 더해 50문제가 됐어요. 아래는 그때 더한 280문제예요. 처음 70문제(11-16 임시 데이터)는 출처를 따로 적지 않았어요.

- 문제 글과 보기는 사전 설명을 옮기지 않고 직접 썼어요.
- 출처는 만든 쪽이 알고 있는 교과서, 사전 기준으로 적은 것이에요. 웹에서 한 문제씩 다시 찾지는 않았어요. 따로 검수해서 정답이 흔들리는 문제 3개를 고쳤고, 단계 사이에 같은 사실을 묻는 문제 30개를 바꿨어요(11-20).
- Drop Words 단어(단계마다 60개)는 표준국어대사전에 있는 낱말과 널리 쓰는 전문 용어로 골랐어요.
