# 화면 이름 규칙 (naming)

화면 ID, 피그마 프레임 이름, 구역과 부품 이름, 용어를 한 가지로 맞추는 규칙이에요. 결정 문서(`docs/decisions-*.md`), `docs/design-system.md`, 관리판(`tasks.jsonl`, `issues.jsonl`)이 모두 이 이름을 써요.

> 화면 ID 체계는 확정이에요(결정 144). 피그마 이름 바꾸기는 TSK-158로 [디자인 13]이 해요. 위치 이동, 구역 재배치, 보관 이동은 하지 않아요.

## 1. 화면 ID 체계: 지금 코드를 정리해서 써요 (확정, 결정 144)

| 안 | 예 | 좋은 점 | 나쁜 점 |
|---|---|---|---|
| **A. 지금 코드 정리 (확정, 결정 144)** | `H0`, `S1-3A`, `O2-1`, `PL2-3` | 결정 문서, design-system.md, 커밋 메시지, 사용자 대화에 이미 수백 번 쓰임. 짧아서 말하기 쉬움 | 겹치는 코드 한 개(스플래시 `S`)를 고쳐야 함 |
| B. 새 체계 | `SCR-HOM-001` | 형식이 엄격함 | 옛 문서와 대화가 모두 옛 코드라 대응표를 늘 봐야 함. 길어서 말하기 어려움 |

A안으로 확정했어요(11-23 사용자 "추천안대로 해", 결정 144, `docs/decisions-11-23.md`). 바꾸는 비용이 B보다 훨씬 적고, 이미 모두가 아는 이름이기 때문이에요.

### 코드 모양
`영역 글자` + `화면 번호` + (`-하위 번호`) + (`변형 글자`)

| 영역 글자 | 뜻 | 피그마 구역 |
|---|---|---|
| `O` | 온보딩 (`O1` 스플래시, `O2-1`~`O2-4` 필수 권한, `O3` 선택 권한) | 온보딩 (O) |
| `H` | 알람 탭 홈 (`H0` 홈, `H2-n` 권한 배너, `H8-n` 이번만 쉬기, `H0 홈 / 한 번 더 확인 남음` 띠) | 알람 탭 홈 (H), 홈 하늘 장면 (H0) |
| `S` | 알람 편집 (`S0` 편집, `S1-n` 미션 시트, `S3`~`S6` 설정 시트) | 알람 편집 (S) |
| `D` | 알람 울림 | 알람 울림 (D, M) |
| `M` | 미션 플레이 (`M1` Drop Words, `M2` Pop Quiz, `M3` Quick Math, `M4` Shake Shake, `-1`은 오답, `M5` 미션 포기) | 알람 울림 (D, M) |
| `W` | 알람이 울린 뒤 (`W1` 해제 완료, `W2` 깨어 있나요, `W2-1` 한 번 더 확인 알림, `W3` 정말 깼어요) | 알람이 울린 뒤 (W) |
| `Z` | 잠들기 탭 (지금 숨김) | 잠들기 탭 (Z) |
| `T` | 설정 탭 (`T1-1` 깼는지 묻기 시트, `T1-2` 한 번 더 확인 시트, `T3` 확실히 잠깨기, `T3-1` 버튼 속이기 시트, `T3-2` 여러 번 묻기 시트(11-26 없앰, 결정 177), `T3-3` 버튼 속이기 미리 해보기, `T3-4` 미션 포기 알림 숨기기 확인 시트) | 설정 탭 (T, P), 확실히 잠깨기 실험실 (T3, D, W, H) |
| `P` | 권한 요청, 동의 화면 (`P5` 위치, `P6` 전원 종료 방지) | 설정 탭 (T, P) |
| `PL` | 나중에 띄우는 권한 시트 (`PL2-1`~`PL2-4`) | 나중용 권한 시트 (PL) |
| `N` | 앱 밖 알림 글 (`N1` 내일 알람 점검, `N2` 앱 닫힘) | 권한 경고 (S0, H2, T2-1, 알림) |
| `ICN` | 앱 아이콘 시안 | 앱 아이콘 (ICN) |

규칙:
- **한 번 쓴 코드는 다른 화면에 다시 주지 않아요.** 화면을 보관하면 그 코드는 비워 둬요(예: 옛 `H2` 정확한 알람 배너는 보관, 지금 `H2-1`~`H2-5`는 배너 묶음).
- 하위 번호(`-1`)는 같은 화면의 다른 단계나 겹쳐 뜨는 것(시트, 대화상자)이에요. 변형 글자(`A`, `B`)는 같은 자리의 다른 안이에요.
- 스플래시는 지금 `S 스플래시`라서 알람 편집 `S`와 겹쳐요. **`O1 스플래시`로 바꿔요**(11-19 결정 131에서 이미 'O1 자리'라고 정함).
- 설정의 권한 화면은 11-18 결정 130으로 한 화면 '권한'이 됐어요. 피그마 이름은 아직 `T2-A 알람 울림 권한`이라 **`T2 권한`**으로 바꿔요.
- 제안만 하는 시안(정해지지 않은 안)은 앞에 `[제안]`을 붙여요.

## 2. 프레임 이름 형식

```
ID 화면명 / 상태 / 모드
```

| 칸 | 규칙 | 예 |
|---|---|---|
| ID 화면명 | 코드 한 칸 띄고 화면 이름. 화면 이름은 앱에서 부르는 이름, 명사형 | `S4 다시 잠들기 방지 시트` |
| 상태 | 같은 화면의 다른 상태. 쉼표로 여러 개. 없으면 칸째 뺌 | `미션 없음`, `밤 비`, `1단계 필수 셋 켜짐` |
| 모드 | `Light` 또는 `Dark`. 라이트와 다크 두 장이 다 있는 화면만 붙임 | `Light`, `Dark` |

- 칸 사이는 ` / `(띄어쓰기, 빗금, 띄어쓰기)예요. 피그마 레이어 목록과 검색에서 칸이 잘 보여요.
- **모드 칸은 두 장이 있는 화면에만** 붙여요. 울림(D), 미션(M), 울린 뒤(W), 잠들기(Z), 홈 하늘 장면(H0)은 모드 없이 늘 같은 화면이라 붙이지 않아요. 낮과 밤 장면은 상태 칸에 `밤`으로 적어요.
- **이름에 넣지 않는 것**: 날짜(`11-19`), 결정 번호(`결정 131`), `(새안)`, `(다크)` 괄호, 화면 설명 문장. 날짜와 결정은 `design-system.md`와 결정 문서에 적어요.
- 이름은 40자 안팎. 길어지면 상태 칸을 줄여요(옛 PL2 이름은 80자가 넘었어요).

좋음: `H2-4 권한 경고 배너 / 전체 화면 알림 꺼짐 / Dark`, `W1 해제 완료 / 밤 눈`, `O1 스플래시 / 낮 / Light`
피함: `PL2-1 두 단계 1단계: 처음 (필수 셋 꺼짐, '다음' 비활성) (11-18 결정 129 보충 5, 나중용, 뒤 화면 홈) (다크)`

## 3. 구역(섹션) 이름

```
영역 이름 (코드 글자)
```
예: `알람 탭 홈 (H)`, `알람 울림 (D, M)`, `나중용 권한 시트 (PL)`.

- 날짜와 결정 번호는 넣지 않아요. 지금 `권한: 나중용 권한 시트 두 단계 (PL2, 결정 129 보충 5)` → `나중용 권한 시트 (PL)`, `앱 아이콘 (시안, 11-20)` → `앱 아이콘 (ICN)`.
- 보관 구역만 예외로 날짜를 붙여요: `11-19 보관: 화면 흐름 정리`. 날짜가 보관한 때를 알려 주기 때문이에요.
- 메모만 남은 `11-18 권한 시트와 배너` 구역은 사용자가 정할 때까지 그대로 둬요.

## 4. 부품(컴포넌트) 이름

지금 피그마 부품 이름(`Bottom Sheet`, `Sheet Header`, `Home Sky`, `Ring Sky`, `Nav Bar (시스템)`, `Choice Chip`, `Select Mark Off`)을 그대로 써요. 새 부품은 이렇게 지어요.

| 규칙 | 예 |
|---|---|
| 영어, 단어 첫 글자 대문자, 띄어쓰기 | `Alarm Card`, `Permission Banner` |
| 변형은 피그마 속성(Variant)으로. 이름에 넣지 않음 | `State=On`, `Mode=Dark`, `Scene=밤` |
| 한 화면에만 쓰는 묶음은 부품으로 만들지 않고 프레임 안 레이어 이름만 | `row/Drop Words` |
| 레이어 이름은 `종류/이름` 소문자 종류 | `row/`, `icon/`, `bg/`, `text/` |
| 아이콘은 Lucide 이름 그대로 | `chevron-right`, `check` |

색과 글자 토큰 이름(`primary/default`, `text/secondary`, `Body/Small`)은 `design-system.md`가 원본이에요.

## 5. 용어집

화면 이름, 결정 문서, 일 제목에서 같은 뜻은 같은 말로 써요.

| 용어 | 뜻 | 예 |
|---|---|---|
| 화면 | 한 장 전체를 차지하는 페이지 | H0 홈, T1 설정 |
| 바텀시트(시트) | 아래에서 올라오는 판. 뒤 화면이 스크림 뒤로 보임 | S3 다시 울림 시트, S1-1 미션 고르기 시트 |
| 바텀 모달 | 시트 모양이지만 꼭 답해야 닫히는 판 | P6 전원 종료 방지 동의 |
| 모달(대화상자) | 화면 가운데 뜨는 확인 창. 버튼으로만 닫힘 | H5 알람 삭제 확인, S0-1 저장 안 하고 나가기 |
| 스크림 | 시트나 모달 뒤를 어둡게 덮는 막 | 다크에서 #000000 60% |
| 배너 | 화면 위쪽에 붙어 있는 안내 줄. 문제를 고칠 때까지 남음 | H2-1~H2-5 권한 경고 배너 |
| 토스트 | 잠깐 떴다가 저절로 사라지는 짧은 알림. 버튼 없음 | H6 저장 토스트 |
| 스낵바 | 토스트처럼 사라지지만 버튼('되돌리기')이 있음 | H7 삭제 스낵바 |
| 칩(Choice Chip) | 여러 값 중 하나를 고르는 작은 알약 버튼 | 볼륨 시트의 진동 세기 |
| 토글(스위치) | 켜고 끄는 스위치 | 다시 울림, 다시 잠들기 방지 |
| 드럼롤 | 위아래로 굴려 고르는 시각 선택기 | S0 시각 |
| 하늘 장면 | 홈과 울림 화면 위쪽의 낮, 밤, 날씨 그림 | Home Sky, Ring Sky |
| 미션 | 알람을 끄려면 풀어야 하는 짧은 놀이 | Drop Words, Pop Quiz, Quick Math, Shake Shake |
| 예제 영역 | 미션 설정 시트 안의 게임 소개 그림 칸 | S1-3A |
| 다시 울림 | 아무도 안 끄면 쉬었다 다시 울리는 것 | S3 |
| 다시 잠들기 방지 | 끈 뒤에 깨어 있는지 다시 묻는 것 | S4, W2 |
| 이번만 쉬기 | 반복 알람의 다음 한 번만 건너뜀 | H8-1~H8-5 |
| 필수 권한, 선택 권한 | 알람이 울리는 데 꼭 필요한 권한, 없어도 되는 권한(위치) | O2, O3, T2 |

## 6. 일과 이슈에 화면을 연결하는 규칙

| 필드 | 넣는 값 | 예 |
|---|---|---|
| `screens` | 화면 ID(모드, 상태 없이 코드만) | `screens="S4 W2"` |
| `figma` | 피그마 노드 id. 꼭 그 프레임을 가리켜야 할 때만 | `figma="461:8297"` |
| `refs` | 결정 문서, design-system.md 같은 문서 경로 | `refs="docs/decisions-11-23.md"` |
| `decisions` | 결정 번호 | `decisions="137"` |

- 일 제목에 화면 ID를 넣어도 되지만(`S4 시트 '몇 번 물을까요' 줄 추가`), **필드에도 꼭** 넣어요. 보드가 필드로 찾고 묶어요.
- 화면 ID가 바뀌면(예: `S` → `O1`) 옛 ID가 든 일과 이슈를 `set 키 screens-=S screens+=O1`로 고쳐요.
- 결정 문서와 design-system.md에서 화면을 부를 때도 같은 코드를 써요. 옛 이름은 design-system.md의 '옛 이름 읽는 법' 표를 봐요.
