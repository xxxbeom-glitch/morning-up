## 우리 보드에 가져올 것

- 위 툴바 한 줄: 왼쪽에 보기 탭(칸반, 목록, 타임라인), 오른쪽에 검색과 필터, 정렬 버튼. 필터가 걸리면 툴바 바로 아래에 칩 줄이 생기고 칩마다 `x`, 맨 끝에 "초기화".
- 필터 메뉴는 항목 고르기 → 값 고르기 두 단계, 값 옆에 개수를 보여줘요(2번).
- 필터 때문에 숨은 개수를 "N개 숨김 · 필터 지우기"로 알려줘요(1번).
- 칸반 열 머리에 개수, 카드는 위 키, 가운데 제목, 아래 작은 칩(분야, 마감일, 심각도) 3단 구조(1번).
- 목록은 줄 높이 약 32 이하로 촘촘하게, 상태별 묶음 머리 줄과 열 머리 눌러 정렬. 마감일은 지나면 빨강, 오늘이면 초록 글자(3번).
- 상세 패널은 오른쪽에 고정 폭(약 440~480)으로 붙고 목록에서 고른 줄을 칠해요. 순서는 키와 상태 버튼, 제목, 속성 2열(라벨 왼쪽, 값 오른쪽), 설명, 완료 조건, 체크리스트(진행 막대 + n/m), 연결 항목(관계별 묶음), 활동(5, 6, 7번).
- 활동 칸은 "전체 / 댓글 / 기록" 탭, 기록은 "무엇이 바뀜 · 언제" 한 줄, 댓글은 카드로(6, 7번).
- 타임라인은 왼쪽 그룹 이름 열, 위 두 줄 날짜 머리, 오늘 세로선, 오늘로 가기 버튼, 마일스톤은 마름모, 날짜 없는 일 개수 표시(4번).

## 가져오지 않을 것

- 협업 기능(공유, 초대, 승인, 구독자, 담당자 얼굴 모음): 혼자 쓰는 보드라 필요 없어요.
- AI 필터, 자동화, 개발 도구 연결 같은 부가 메뉴: 오프라인 단일 파일에는 맞지 않아요.
- monday식 칸 전체 색 채우기를 모든 열에 쓰는 것: 화면이 시끄러워져서 상태 칸 하나에만 작게 쓸지 정도로만 참고해요.
