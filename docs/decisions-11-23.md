## 결정 145 자세히

11-23 [기획 5] 작성, 같은 날 사용자 방향을 받아 다시 씀. 근거: 결정 59, 78, 80, 83, 101, 136, 137, 139, 143, `idea1-resleep.md`, `adr/0002-alarm-engine.md` 울림 상태표. **사용자 확정**은 알림 안내와 전체 설정 두 가지이고, 나머지는 모두 **Leader 확정(사용자 위임 11-23)**이에요. 사용자는 개발 전에 요약을 한 번 봐요.

### 1. 확인 동작: 10초 길게 누르기 (Leader 확정)

| | 10초 길게 누르기 (정함) | 밀어서 해제 |
|---|---|---|
| 잠결에 반사적으로 하기 | 어려워요. 10초 동안 손을 대고 있어야 해서 그 사이 정신이 들어요 | 쉬워요. 잠금 화면, 전화 받기와 같은 몸에 밴 동작이라 반쯤 잠든 채로도 해요 |
| 걸리는 시간 | 10초 | 1초 |
| 실수 | 손을 떼면 처음부터라 짜증날 수 있어요. 아래처럼 0.5초 여유를 둬요 | 거의 없음 |
| 접근성 | 톡백은 두 번 탭 후 누르고 있기로 돼요 | 톡백에서 밀기는 따로 처리가 필요해요 |
| 만들기 | 원형 버튼 + 진행 고리 | 밀기 막대 부품 새로 |

- 이유: 이 기능의 목적이 '반쯤 잠든 채 누르고 다시 잠드는 것'을 막는 거예요. 밀기는 그 빈틈을 그대로 남겨요.
- 둘 다 고르게 할지: **첫 버전은 하나만.** 고를 수 있게 하면 쉬운 쪽(밀기)으로 다 옮겨 가서 기능이 약해지고, 설정 줄도 하나 늘어요. 비공개 테스트에서 '10초가 길다'가 많이 나오면 그때 5초로 줄이는 쪽을 먼저 봐요.
- 동작 세부: 누르는 동안 버튼 둘레 고리가 10초에 걸쳐 차요. 0.5초 안에 다시 누르면 이어서 차고, 그보다 오래 떼면 고리가 1초에 걸쳐 비워져요. 다 차면 짧은 진동과 함께 끝나요.

### 2. 확인할 시간: 3분, 5분, 10분, 처음 10분 (Leader 확정)

- 사용자 생각대로 샤워나 양치를 하고 돌아와도 되는 길이예요. 이 단계의 목적은 '정말 깬 사람이 억울하게 미션을 다시 하지 않게'라서 처음 값은 가장 긴 10분이 맞아요.
- 다시 잠든 사람은 최대 10분 더 자고 나서 다시 울려요. 그게 싫은 사람은 3분, 5분을 고르면 돼요.
- 선택지는 전체 설정 시트에 둬요(사용자 확정: 전체 설정 일괄).

### 3. 앞서 낸 '놓치면 한 번 더 크게 묻기'는 빼요 (Leader 확정)

- W3의 긴 확인할 시간(처음 10분)과 알림 안내가 같은 일을 해요. 2차 묻기 화면은 만들지 않아요.
- W3가 뜨는 걸 알 수 있게 소리만 둬요: 뜰 때 짧은 알림음(알람 볼륨의 30%)과 진동 2번, 그 뒤 2분마다 짧은 알림음 한 번과 화면 켜기. 알람 소리(`USAGE_ALARM`)로 내요.
- W2에도 W3와 같은 짧은 알림음(알람 볼륨의 30%)과 진동 2번을 넣어요. W2는 지금 소리 없이 떠서(상태표 효과에 소리가 없음) 다른 방에 있으면 1분을 모르고 지날 수 있어서예요. W2 화면 모양은 바꾸지 않아요.

### 4. 알림 창 안내 (사용자 확정, 문구는 Leader 확정)

| 어디 | 문구 |
|---|---|

- 알림 성격: 소리, 진동 없는 조용한 알림, 계속 떠 있는 알림. 사용자가 밀어서 지워도 W3는 정한 시각에 떠요.
- 알림의 '깼어요' 같은 동작 버튼은 달지 않아요(사용자 확정: 버튼 한 번으로 끝나지 않음).
- 결정 59의 기다림 알림('미션을 마쳤어요 / 잠시 뒤 깨어 있는지 물어볼게요')은 W2 전까지 그대로예요. W2 '깼어요' 뒤에 이 안내 알림으로 바뀌어요.
- W2 '깼어요'를 누른 직후 화면 글: '확인했어요' 아래에 '3분 뒤 한 번 더 물어볼게요'를 한 줄 더해요(한 번 더 확인이 켜져 있을 때만).

알림 권한이 꺼져 있을 때:

- 안내 알림은 못 띄워요. 대신 W2 '깼어요' 직후 화면 글('3분 뒤 한 번 더 물어볼게요')이 안내를 맡아요.
- W3는 알림 권한과 상관없이 정한 시각에 떠야 해요. 울림 화면을 띄우는 방법과 같게 만들고, 알림 권한이 꺼진 폰에서도 뜨는지 개발이 확인해요(알림 권한이 없으면 전체 화면 알림도 막힐 수 있어서).
- 미리 끝내기는 앱을 열어서도 할 수 있게 해요: 한 번 더 확인을 기다리는 동안 홈(H0) 위쪽에 '한 번 더 확인이 남았어요' 띠를 두고 누르면 W3가 열려요.
- 알림 권한 꺼짐은 이미 있는 H2 권한 경고 배너가 알려요. 새로 더하지 않아요.

### 6. 다시 울리는 바퀴 상한 (Leader 확정)

- W2나 W3를 시간 안에 못 해서 처음부터 다시 울리는 것은 알람 하나에 **2번까지**예요. 고정값이고 설정 줄은 없어요.
- 2번 다시 울린 뒤(그날 세 번째 울림) 미션을 끝내면 W2, W3 없이 W1에서 끝나요.
- 각 바퀴 안에서 다시 울림 횟수가 처음 값으로 돌아가는 것은 결정 136 그대로예요. 상한은 바퀴 수에만 걸어요.
- 이유: 결정 136대로면 '미션 끝 → 다시 잠듦 → 다시 울림'이 끝없이 되풀이될 수 있어요. 상한이 있어도 매 바퀴는 진짜 알람과 미션을 거쳐요.
