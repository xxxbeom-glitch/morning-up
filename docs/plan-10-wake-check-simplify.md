# 다시 잠들기 방지 시트 단순화 안 (TSK-243, [기획 10], 11-26)

사용자 원문(11-26): "다시 잠들기방지는 선택사항이 너무 많아서 이거 구조단순화가필요해보여"

이 문서는 사용자 확인 전 안이에요. 결정 번호는 Leader가 매겨요. 관련 일: TSK-226(시트 시안), TSK-227(알람마다 옮기기).

## 결론

- 추천은 **A안(두 줄)**이에요. 시트에 '다시 물어보기'(3, 5, 10분 후)와 '한 번 더 확인'(안 함, 1번, 2번, 3번) **두 줄만** 남겨요.
- 고르는 곳이 **5개 → 2개**로 줄고, 토글을 켜면 줄이 늘어나는 일도 없어져요.
- W2 대답할 시간은 **1분**, W3까지 기다리는 시간은 **3분**으로 고정해요. 둘 다 지금 처음 값이라 처음 값을 그대로 쓰던 사람은 달라지는 게 없어요.
- 사용자가 결정 176에서 직접 원한 '횟수 고르기'는 남기고, '기다리는 시간 1, 3, 5분 고르기'는 빠져요. 이 점만 사용자에게 확인받으면 돼요.

## 4. A안을 추천하는 이유

- **사용자 요청을 가장 적게 버려요.** 결정 176에서 사용자가 원한 것은 '대답할 시간 1분 고정'(이미 고정), '기다리는 시간 1, 3, 5분', '횟수 고르기' 셋이에요. A안은 횟수를 남기고 기다리는 시간 하나만 고정해요. B안은 둘 다 버려요.
- **알라미 흐름과 같아요.** 알라미는 '언제 물을지' 하나만 고르게 해요. 우리는 확인이 두 단계라 단계마다 하나씩, 두 줄이에요.
- **토글 + 칩 묶음을 칩 한 줄로 합치면** 켜고 끌 때 시트 높이가 바뀌지 않아요. '안 함, 1번, 2번, 3번'은 지금 '묻는 횟수' 칩과 같은 부품이라 디자인 일이 적어요.
- **고정값이 지금 처음 값과 같아요.** 1분, 3분 모두 지금 처음 값이라 대부분의 사용자는 차이를 못 느껴요.
- C안은 '너무 많다'는 말에 비해 덜 줄였고, B안은 W3를 끌 수 없어 너무 세요(W3 10초 누르기가 싫은 사람은 다시 잠들기 방지 전체를 꺼야 해요).
