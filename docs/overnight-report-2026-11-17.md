## 리뷰 결과

처음 보는 리뷰 에이전트에게 가지 전체를 맡겼어요. 엔진(상태표, 다음 시각 계산, 다시 예약)에는 큰 논리 오류가 없었고,
폰에서 울림 화면이 안 뜰 수 있는 문제가 나왔어요. 10개 중 10개를 모두 고쳤어요(`d0457c1`).

| 중요도 | 지적 | 고친 방법 |
|---|---|---|
| 높음 | 알림을 '조용히'로 만들어서 잠금 화면 위 울림 화면(전체 화면 알림)이 막힘 | 조용히 설정을 빼요. 알림 통로가 이미 소리 없이 만들어져 있어요 |
| 높음 | 쉬고 다시 울릴 때, W2를 물을 때 알림이 '고친 알림'이라 화면이 안 뜸 | 쉬는 중 알림은 다른 번호로 두고, 깨어날 때는 첫 알림부터 화면 띄우기를 달아요 |
| 높음 | 알림 권한을 묻지 않아 안드로이드 13 이상 새 설치에서 화면이 안 뜸 | 앱을 열 때 묻고, 전체 화면 권한이 꺼져 있으면 기록해요. 울리는 중이면 앱을 열 때 울림 화면으로 보내요 |
| 중간 | 울리던 중 폰이 꺼졌다 한참 뒤 켜지면 밤에도 다시 울림 | 10분이 넘었으면 이어가지 않고 '놓친 알람'으로 끝내요 |
| 중간 | 정확한 알람 권한이 없을 때 서비스를 못 띄워 소리가 안 날 수 있음 | 서비스를 못 띄우면 알람 소리 채널의 비상 알림으로 깨워요 |

| 낮음 | 다시 예약이 여러 곳에서 동시에 돌면 놓친 알람이 두 번 울릴 수 있음 | 하나씩 처리하게 잠가요. 테스트로 먼저 실패를 확인하고 고쳤어요 |

리뷰가 짚은 빈틈: 알림과 울림 서비스 자체는 PC 테스트가 없어요. 폰 확인 목록 3~10번이 이 부분이에요.

## 폰 확인 목록

PC 테스트로는 확인할 수 없는 것들이에요. 갤럭시 S24+와 Z플립5에서 확인해 주세요.

### 설치 방법 (adb)

1. 폰에서 개발자 옵션의 'USB 디버깅'을 켜고 PC에 USB로 연결해요.
2. 작업 가지를 받아요.

```bash
git checkout dev/overnight-11-17
```

3. 디버그 앱을 만들어요.

```bash
./gradlew :app:assembleDebug
```

4. 폰에 설치해요. 앱 이름 옆에 `.debug`가 붙은 별도 앱으로 깔려요.

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### 확인할 것

시험 알람은 앱의 '설정' 탭(디버그 견본 화면) 맨 아래 '1분 뒤 울리기', '1분 뒤 미션 알람' 버튼으로 만들어요.
'1분 뒤 미션 알람'은 다시 울림 3분 간격 1번, W2는 1분 뒤 묻고 30초 안에 답하기로 만들어져요.

| 번호 | 확인할 것 | 기대 결과 |
|---|---|---|
| 1 | 빈 앱이 열리고 하단 메뉴 3탭이 바뀌는지 | 알람, 잠들기, 설정 탭이 바뀌어요 |
| 2 | 견본 화면의 색과 글자, 버튼, 토글이 피그마와 같은지 | 눈으로 비교해요 |
| 3 | 화면을 끄고 '1분 뒤 울리기' | 다음 분 정각에 잠금 화면 위로 울림 화면이 뜨고 소리와 진동이 나요 |
| 4 | 무음 모드, 미디어 볼륨 0에서 울리는지 | 알람 볼륨으로 울려요 |
| 5 | 아무것도 누르지 않기 | 1분 울리고 멈춘 뒤 3분 쉬고 다시 1분 울려요. 그 뒤 '놓친 알람' 알림이 떠요 |
| 6 | '1분 뒤 미션 알람'에서 '미션 시작' | 소리가 작아지고 진동이 멈춰요. 59초 동안 아무것도 안 누르면 다시 크게 울려요 |
| 7 | '미션 완료' 뒤 1분 기다리기 | '깨어 있나요?' 화면이 뜨고, 30초 안에 '깼어요'를 안 누르면 처음부터 다시 울려요 |
| 8 | 울리는 중 앱을 최근 앱 목록에서 밀어 지우기 | 소리가 계속 나거나 곧 다시 울려요 |
| 9 | 알람을 맞춰 두고 폰 재부팅(잠금 풀지 않기) | 잠금을 풀기 전에도 제시각에 울려요 |
| 10 | 알람 1~5분 전에 폰을 끄고 알람 시각 직후 켜기 | 10분 안이면 바로 울려요. 10분이 넘으면 '놓친 알람' 알림만 떠요 |
| 11 | 폰 설정에서 시간대를 바꾸기 | 알람이 새 시간대의 같은 시각으로 다시 잡혀요 |
| 12 | 화면 꺼진 채 30분 이상 두기(절전 모드) 뒤 알람 | 제시각에 울려요 |
| 13 | Z플립5를 접은 채 울리기 | 바깥 화면에서 어떻게 보이는지 확인해요(아직 맞춤 처리 없음) |
| 14 | 처음 앱을 열 때 알림 권한 창이 뜨는지 | 시스템 창으로 물어요. 허용해 주세요 |
| 15 | 알림 권한을 끈 상태에서 울리기 | 소리는 나는지 확인해요. 화면은 안 뜰 수 있고, 앱을 열면 울림 화면으로 가요(권한 안내 화면은 다음 단계) |
| 16 | 폰 설정에서 이 앱의 '전체 화면 알림' 허용 여부 | 안드로이드 14 이상은 꺼져 있을 수 있어요. 꺼져 있으면 잠금 화면 위로 화면이 안 떠요 |

문제가 있으면 앱 안 진단 기록(최근 500줄)에 남아요. 진단 기록을 보는 화면은 아직 없어서, 그때는 제가 adb로 꺼내 볼게요.
