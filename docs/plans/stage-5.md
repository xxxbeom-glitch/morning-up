# 5단계 작업표: 나머지 미션과 미션 고르기

> 자동 실행 기록: 보여 주고 기다리지 않고 바로 진행했어요. 질문 단계는 건너뛰고 기획서 추천안을 따랐어요.

**목표:** M1 Drop Words, M2 Pop Quiz, M4 Shake Shake를 만들고, 알람 편집에서 S1-2 미션 고르기(미션 있음, 없음)와 설정 시트 S1-3~S1-7로 미션을 최대 3개까지 고른 순서대로 골라요. 시트와 S0의 '미리보기'로 소리 없이 미리 해 보고, 울릴 때는 미션 사이에 '다음 미션 2 / 3'을 보여 주며 이어서 해요.

**구조:**
- `:core:model` `mission/PopQuiz`(문제 묶음, 4지선다 섞기, 연속 정답), `mission/DropWords`(속도표, 떨어지는 단어, 음절 입력, 앞부분 안 맞으면 비움, 바닥 닿으면 사라짐), `mission/Hangul`(음절 나누고 합치기, 자음이나 모음 하나만 바꾼 가짜 음절), `mission/SyllableKeypad`(19칸 채우기, 빠진 음절 끼워 넣기), `mission/ShakeShake`(흔들기 세기 기준 상수, 0.25초 묶기, 남은 횟수). 모두 난수 주입, TDD.
- `:core:alarm` `ShakeSupport`(가속도 센서가 있는지).
- `:core:designsystem` `MorningButtonStyle.Soft`, `MorningValueSwitchRow`(< >, − +, 꾹 누르면 빨라짐, 끝 값 비활성과 `REJECT`), `MorningMissionCheck`(24 원), `MorningModalSheet`(뒤 막, 아래에서 스프링, 끌어 내려 닫기).
- `:feature:mission` 문제와 단어 임시 데이터 `res/raw/mission_content.json`(단계마다 10개, 이 파일만 바꾸면 됨), 미션 플레이어(Quick Math, Pop Quiz, Drop Words, Shake Shake: 화면 상태와 조작을 가진 보통 클래스), 울림용 `RingMissionViewModel`(세션의 지금 미션을 고르고, 미션 사이 넘어가기), 미리보기용 `MissionPreviewViewModel`(울림 엔진을 쓰지 않음), 화면 M1, M2, M4, 넘어가기, '잘했어요'.
- `:feature:edit` S1-2 미션 고르기 페이지, 설정 시트, `EditViewModel`의 미션 고르기 동작. 4단계 디버그 Quick Math 길과 `buildConfig` 지움.
- `:feature:ring` 미션 자리를 미션 순서마다 새로 만들지 않게(넘어가기 움직임은 미션 화면 몫).
- `:app` 미션 자리에 `RingMissionRoute`, 미리보기 화면 길(`MissionPreviewRoute`), 견본 '1분 뒤 미션 알람'은 미션 3개 묶음으로.

## 작업

### 작업 1: 순수 규칙 (TDD)
- Pop Quiz: 연속 정답 N개면 끝, 틀리면 0부터 새 문제, 보기 4개 섞기, 같은 문제 연달아 안 나옴
- Drop Words: 속도표(10, 8, 6, 4초 / 1, 2, 2, 3개), 앞부분 맞으면 이어 치기, 다 맞으면 정답과 새 키패드, 안 맞으면 비움(정답 수 그대로), 바닥에 닿으면 사라지고 새 단어
- 가짜 음절: 자음이나 모음 하나만 바꿈, 진짜 음절과 겹치지 않음
- 키패드: 19칸, 화면 음절 먼저(먼저 떨어질 단어부터), 치는 중에는 그대로, 빈 입력일 때 빠진 음절만 제자리 끼워 넣기
- Shake Shake: 기준 넘으면 한 번, 0.25초 안 두 번은 한 번, 0이면 끝
- 엔진: 미션 3개 묶음이 순서대로, 중간에 시간이 끝나면 하던 미션부터

### 작업 2: 부품
- 버튼 Soft, 값 넘기기 줄, 체크 원, 바텀시트

### 작업 3: 미션 화면
- 플레이어 4개, 울림 VM(넘어가기 0.8초, 59초 새로 시작, `CONFIRM`), 미리보기 VM(시간 끝나면 닫기, 끝나면 '잘했어요', 진짜 알람이 오면 닫기)
- M1, M2, M4 화면과 미리보기 닫기 버튼

### 작업 4: 미션 고르기
- S1-2(고른 순서대로 위로, 3개면 나머지 비활성, 센서 없으면 Shake Shake 비활성), 시트(안 고른 미션 '선택 완료', 고른 미션 '선택 해제', 값은 바로 저장), S0 토글과 줄
- 디버그 임시 길 정리

### 작업 5: 테스트
- ViewModel: 3개 제한, 미션 없음 저장, 시트 값 범위와 끝 값, 미션마다 정답/오답, 넘어가기, 미리보기 끝과 닫기
- Compose UI: S1-2 카드와 체크, 시트 끝 값 비활성, M1 키 입력, M2 답 누르기, M4 남은 횟수

## 결과 기록
- 작업 1~5 모두 했어요. 구조 결정은 `docs/adr/0005-mission-player-and-preview.md`에 있어요.
- 혼자 정한 것: Pop Quiz는 틀리면 정답을 보여 주지 않고 바로 새 문제(dev-plan이 mission-levels보다 최신), 물러나는 이전 문제에서만 흔들림과 칠을 보여 주고 새 문제는 바로 누를 수 있게 함. S1-2 위 막대 제목은 S0 줄 이름과 같은 '미션 선택'. 시트 값 줄 이름은 '난이도', '속도', '단어 수', '문제 수', '흔드는 횟수'(design-system 미션 설정 항목 그대로).
- 미리보기는 편집 화면 위에 `:app` 길로 열고, 닫히면 편집 화면(열려 있던 시트 그대로)으로 돌아와요.
