## 정한 것 (5번만, 사용자 "그렇게 해")

- 사이트: 이 앱 하나만 소개하는 한 장 사이트(소개, 개인정보처리방침, 자주 묻는 질문). GitHub Pages에 올리고 도메인은 나중에. 사이트 이름은 앱 이름이 정해진 뒤.
- 첫 SNS는 인스타그램 하나.
- 아직 안 정함: 스토어 글에 '광고 없음'을 넣을지, 사이트에 사업자 정보를 넣을지(넣으면 항목은 사용자에게 먼저 물음).
