# 아이디어 8: 대규모 댓글 홍보 대신 안전하게 알리는 법 (피드백)

11-23 [마케팅 1] 작성. 피드백과 추천안이에요. 실제 댓글, 글, 계정 만들기는 하지 않았어요.
원문(`docs/ideas-11-22.md` 8번): "알람, 지각 등의 키워드들로 각 플랫폼별 포스팅들을 찾아서 대규모 댓글로 광고하거나 홍보하는 방식인데 이건 사실 정책 위반이 될 수도 있어서 안전한 방법으로는 뭐가 있는지 고민해 보기."

표시: **[웹]** = 11-23 웹에서 확인한 것, **[앎]** = 이미 아는 것으로 쓴 것(출시 전 다시 확인 권장).

## 결론

- **대규모 댓글 홍보는 하지 않는 게 맞아요.** 사용자 판단이 정확해요. 계정 정지, 브랜드 이미지 손상, 국내법 과태료 위험이 있고, 얻는 설치 수에 비해 잃을 게 커요.
- 목적("알람, 지각 고민을 가진 사람에게 닿기")은 **적게, 정체를 밝히고, 진짜 도움 되는 답을 다는 방식**으로 안전하게 이룰 수 있어요.
- **추천: '만든 사람이라고 밝히고 진짜 도움 되는 답 달기', 하루 2~3개까지.** 이유는 아래 3장에 있어요.

## 1. 대규모 댓글 홍보가 위험한 이유

| 위험 | 내용 | 근거 |
|---|---|---|
| 플랫폼 스팸 정책 | 같은 내용을 여러 곳에 반복해서 다는 댓글, 자동화 댓글은 대부분 플랫폼이 스팸으로 봐요. 댓글 삭제, 노출 제한, 계정 정지로 이어져요 | [웹] 유튜브 스팸 정책은 대량, 반복, 기만적 댓글을 금지. 스레드는 스팸 공격 뒤 활동 횟수 제한을 걸었음. [앎] 인스타그램, 네이버 카페, 커뮤니티도 같은 기준 |
| 국내법 (정보통신망법) | 게시판 운영자가 "광고 금지"라고 밝힌 곳에 영리 목적 광고를 올리면 과태료 대상이에요. 대부분의 커뮤니티와 카페가 광고 금지 규칙을 걸어 두었어요 | [웹] 정보통신망법 제50조의7, 제76조 (과태료 상한은 법령 원문 확인 필요) |
| 광고 표시 규정 (공정위) | 대가를 받았거나 자기 제품인데 그냥 사용자인 척 추천하면 '뒷광고'가 돼요. 만든 사람이 일반 사용자인 척 "이 앱 좋아요"라고 쓰는 것도 같아요 | [웹] 추천, 보증 심사지침(2026-06 개정 시행, AI 가상 인물 표시 의무도 추가). [앎] 경제적 이해관계는 글 첫 부분에 분명히 밝혀야 함 |
| 브랜드 이미지 | "알람 앱 광고 댓글 또 달렸네" 하고 캡처돼 퍼지면 첫인상이 '스팸 앱'이 돼요. 출시 초기 별점 테러로 이어질 수 있어요 | [앎] |
| 플레이 스토어 | 댓글에서 "별점 5점 주면 OO 드려요" 같은 보상은 플레이 정책 위반이에요. 앱이 순위에서 빠지거나 내려갈 수 있어요 | [웹] 구글 플레이 보상형 평점, 리뷰, 설치 조작 금지 (2017 공지, 현재 정책 원문 확인 권장) |

## 2. 같은 목적을 안전하게 이루는 방법

| 방법 | 하는 법 | 위험도 | 드는 시간 | 효과 |
|---|---|---|---|---|
| **정체 밝히고 진짜 도움 되는 답** | "알람 끄고 다시 자요" 같은 질문에 먼저 실제 도움 되는 방법(알람 위치, 잠들기 습관 등)을 쓰고, 마지막에 "참고로 저는 이런 앱을 만들고 있어요"라고 한 줄. 광고 금지 게시판은 피함 | 낮음 (규칙을 지키면) | 답 1개 10~15분 | 보통. 검색에 오래 남고 AI 답변 출처가 되기도 해요 |
| **메이커 커뮤니티에 직접 만든 앱 소개** | 직접 만든 제품 소개를 허용하는 곳(예: 디스콰이엇, GeekNews 'Show GN')에 만든 이야기와 함께 한 번 소개 | 매우 낮음 | 글 1개 1~2시간 | 낮음~보통. 잠 못 깨는 사람보다 만드는 사람이 많지만, 첫 피드백과 리뷰를 얻기 좋아요 [앎, 각 곳 규칙 확인 필요] |
| **일반 커뮤니티의 자기 홍보 게시판** | 커뮤니티에 '홍보 게시판', '앱 소개 게시판'이 따로 있으면 거기에만 한 번 | 낮음 | 30분 | 낮음~보통 |
| **체험단, 리뷰어** | 앱을 써 보고 솔직한 후기를 부탁. 대가(돈, 선물)를 주면 후기에 **'협찬' 표시 필수**, 플레이 스토어 별점과 리뷰는 대가와 묶으면 안 됨 | 보통 (표시를 빠뜨리면 높음) | 섭외와 관리에 시간 많이 듦 | 보통. 돈이 들 수 있어 지금 방향(무료, 가볍게)과 덜 맞아요 |
| **플레이 스토어 안 방법** | 스토어 글과 그림 다듬기(아이디어 5), 앱 안 리뷰 요청 창(미션 성공 직후처럼 기분 좋은 때, 보상 없이), 모든 리뷰에 답글 | 매우 낮음 | 주 30분 | 높음. 이미 설치한 사람과 스토어 검색에서 오는 사람에게 바로 효과 |
| **지인, 테스터 입소문** | 비공개 테스트 참여자와 지인에게 "써 보고 괜찮으면 알려 주세요"만. 별점 부탁은 하지 않음 | 매우 낮음 | 적음 | 낮음, 초기 리뷰에 도움 |
| **자기 채널에 글** | 브랜드 사이트 FAQ, 인스타그램 게시물로 "다시 잠드는 이유" 같은 글을 올리고 검색에 걸리게 | 매우 낮음 | 글 1개 1시간 | 느리지만 오래가요 (아이디어 5의 SEO, AEO) |

손님이 볼 답글 예시 (확정 아님, 앱 이름은 미정이라 비워 둠):
> 저도 알람 끄고 다시 자는 게 제일 큰 문제였어요. 효과 있었던 건 폰을 침대에서 손 안 닿는 곳에 두기, 알람을 여러 개 맞추지 않고 하나만 두기였어요. 참고로 저는 이 문제 때문에 '앱 이름'이라는 무료 알람 앱을 만들고 있어요. 알람을 끈 뒤 몇 분 지나 깨어 있는지 한 번 더 물어보는 앱이에요.

## 3. 1인 사업자에게 추천: 정체 밝히고 진짜 도움 되는 답 달기 (하루 2~3개까지)

| 이유 | 설명 |
|---|---|
| 원래 목적과 같음 | 사용자가 원한 "알람, 지각 고민 글을 찾아가서 닿기"를 그대로 하되, 양을 줄이고 정체를 밝혀서 안전하게 바꾼 것이에요 |
| 돈이 안 듦 | 체험단과 달리 비용이 없어요 |
| 오래 남음 | 질문 답변(지식iN, 커뮤니티 질문 글)은 검색과 AI 답변에 오래 남아요. 아이디어 5의 AEO, GEO와 이어져요 |
| 위험이 작음 | 광고 금지 게시판을 피하고, 만든 사람이라고 밝히고, 같은 글을 복사해 붙이지 않으면 스팸, 뒷광고, 과태료 문제를 대부분 피할 수 있어요 |
| 배우는 게 많음 | 사람들이 실제로 왜 못 깨는지 직접 보게 돼요. 아이디어 9("사용자는 왜 못 깰까")의 재료가 돼요 |

지키는 규칙:
- 하루 2~3개까지, 같은 문장 복사 금지, 질문마다 내용을 다르게.
- 답의 대부분은 도움 되는 내용, 앱 이야기는 마지막 한 줄.
- 커뮤니티 규칙을 먼저 읽고, 광고 금지라고 쓰여 있으면 앱 이야기는 빼거나 안 달아요.
- 개인 계정이 아니라 **만든 사람임을 알 수 있는 계정**으로 (계정을 만들거나 고르는 건 사용자가 직접).
- 시작 시기: 출시 뒤(출시 흐름 8단계 뒤). 설치 링크가 없을 때 홍보하면 효과가 사라져요.

## 4. 하지 말아야 할 것

| 하지 말 것 | 이유 |
|---|---|
| 같은 댓글을 여러 글에 복사해 붙이기 | 스팸 판정, 계정 정지 |
| 자동화 도구, 매크로로 댓글 달기 | 모든 플랫폼 금지, 계정 정지 |
| 부계정 여러 개로 일반 사용자인 척 추천 | 뒷광고, 기만 광고. 들키면 브랜드가 끝나요 |
| 광고 금지 게시판, 카페에 앱 링크 | 정보통신망법 과태료 대상, 강퇴 |
| 대행업체에 댓글, 바이럴 맡기기 | 위와 같은 위험을 우리가 그대로 져요 |
| 별점, 리뷰를 보상과 바꾸기 ("5점 주면 OO") | 플레이 정책 위반 |
| 대가를 주고 '협찬' 표시 없이 후기 받기 | 공정위 추천, 보증 심사지침 위반 |
| 경쟁 앱 글에 가서 "그거 말고 이거 쓰세요" | 비방, 스팸으로 보임 |
| AI로 만든 가짜 후기, 가상 인물 추천 | 2026-06 개정 지침상 가상 인물 표시 의무, 허위 경험담은 부당 광고 |
