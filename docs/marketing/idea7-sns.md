# 아이디어 7: SNS 브랜드 계정과 짤 포스팅 (피드백)

> **보류 (11-23)**: 사용자 "sns는 일단 좀 더 나중에 인사이트 찾아보자". 아래 추천안은 확정하지 않았어요. 나중에 인사이트(실제로 잘 되는 알람, 아침 계정 사례 등)를 더 찾아본 뒤 정해요.
> - 그대로인 것: 첫 SNS는 인스타그램 하나 (아이디어 5 확정).
> - 미정: 올리는 방식(짤 유형)과 횟수(아래 '주 2번'은 추천일 뿐이에요).

11-23 [마케팅 1] 작성. 고민에 대한 피드백만이에요. 게시물 계획표, 실제 짤, 계정 만들기는 하지 않았어요.
원문(`docs/ideas-11-22.md` 7번): "인스타그램, X, 스레드에 브랜드 계정을 만들고 MZ세대를 위한 맞춤형 포스팅을 올리는 거야. 짤 같은 거 올리는 정도? 일단 이건 추후 구체적인 방안을 생각."
이미 정한 것: 첫 SNS는 인스타그램 하나(아이디어 5 확정), 계정 여는 시기는 출시 흐름 7단계(비공개 테스트), 계정 이름은 앱 이름이 정해진 뒤.

## 결론

- **방향은 맞아요.** 알람, 아침, 지각은 누구나 겪는 주제라 공감 짤이 잘 먹히고, 돈이 안 들어요.
- **추천: 인스타그램에서 '직접 그린 공감 짤 + 앱 화면 짧은 영상'만, 주 2번으로 시작해요.** 이유는 사용자가 UI 디자이너라 그림과 화면 영상은 가장 빨리 만들 수 있고, 인스타그램이 2026년부터 **직접 만든 게시물은 더 추천하고, 남의 것을 퍼 온 계정은 추천에서 빼는** 쪽으로 바뀌었기 때문이에요.
- 세 곳(인스타그램, X, 스레드)을 처음부터 같이 하면 혼자서는 2~3주 안에 멈출 가능성이 커요. 하나를 3달 꾸준히 하는 게 셋을 한 달 하는 것보다 나아요.

## 1. 혼자 하기에 현실적인가

| 항목 | 현실적인 기준 |
|---|---|
| 올리는 빈도 | **주 2번** (예: 화, 금 아침). 익숙해지면 주 3번 |
| 1개 만드는 시간 | 짤 30분~1시간, 화면 영상 20~40분 (틀을 만들어 두면 더 줄어요) |
| 한 주 드는 시간 | 약 2~3시간 (댓글 답글 포함) |
| 쌓아 두기 | 계정 열기 전에 **6~8개를 미리 만들어 두면** 바쁜 주에도 끊기지 않아요 |
| 기대치 | 처음 3달은 팔로워보다 '설치 링크를 누른 수'를 봐요. SNS는 설치를 크게 늘리기보다 앱을 믿게 만드는 역할이에요 |

## 2. 짤의 큰 유형

| 유형 | 내용 | 만들기 | 설치로 이어지는 정도 |
|---|---|---|---|
| **공감 짤** | "알람 5개 맞췄는데 다 끄고 잔 나", "5분만이 1시간 된 순간" 같은 아침 상황 | 쉬움 (그림 한 장, 글 한 줄) | 낮음, 대신 공유가 잘 돼요 |
| **미션 화면 짧은 영상** | Quick Math, Drop Words 등을 실제로 푸는 7~15초 화면 녹화 | 쉬움 (폰 화면 녹화 + 글자) | **높음**, 앱이 무엇인지 바로 보여요 |
| **"깨어 있나요?" 장면** | 다시 잠들기 방지가 다시 물어보는 순간을 짧게 | 쉬움 | 높음, 우리 앱만의 장면이에요 |
| **유형 테스트, 고르기** | "당신의 기상 유형은?", "어떤 미션이면 깰까?" 고르기 카드 | 보통 (카드 여러 장) | 보통, 저장과 댓글이 늘어요 |
| **날씨와 아침 하늘** | 홈 화면 하늘 그림과 날씨로 만든 '오늘 아침' 카드 | 쉬움 (이미 있는 그림) | 낮음, 분위기를 보여줘요 |

### 하지 말아야 할 것

| 하지 말 것 | 이유 |
|---|---|
| 남의 그림, 사진, 웹툰 캡처 | 저작권 침해. 인스타그램도 퍼 온 게시물이 많은 계정은 추천에서 빼요 |
| 연예인, 유명인 얼굴과 이름 | 초상권, 퍼블리시티권 문제. 광고 목적이면 더 위험해요 |
| 유행 밈 원본 이미지 그대로 쓰기 | 밈 그림에도 저작권이 있어요. **말투와 구도만 빌리고 그림은 직접** 그려요 |
| 유명 노래, 드라마 소리 | 브랜드 계정은 인스타그램 상업용 음원만 안전해요 |
| 과장 광고 ("무조건 깨요", "100% 성공", "1위") | 거짓, 과장 광고 문제. 스토어 규칙과도 어긋나요 |
| 알라미 등 다른 앱 이름, 화면 비교 | 비방으로 보일 수 있어요. 다른 점은 우리 장면으로만 보여줘요 (아이디어 9 참고) |
| 수면, 건강 효과 주장 ("수면의 질이 좋아져요") | 근거 없는 건강 주장은 문제가 될 수 있어요 |

## 3. X와 스레드는 언제 늘릴까

| 조건 (하나라도) | 그때 할 일 |
|---|---|
| 인스타그램을 **3달 동안 주 2번 끊기지 않고** 올렸을 때 | 스레드 추가 (인스타그램 계정과 이어져 있어 같은 짤을 옮기기 쉬움) |
| 짤 재고가 늘 4개 이상 쌓여 있을 때 | 스레드 추가 |
| 인스타그램에 짧은 글 댓글, 공감 반응이 많이 붙을 때 | 스레드 추가 (글 중심이라 맞음) |
| 앱 소식, 업데이트 안내를 빨리 알려야 할 때 | X 추가 (짧은 공지용) |

- **이름 선점만은 미리**: 앱 이름이 정해지면 세 곳 모두 같은 아이디를 만들어 두기만 하고(글 없이), 실제 운영은 인스타그램만 해요. 남이 먼저 쓰는 걸 막아요.
- 늘릴 때도 새로 만들지 말고 인스타그램 짤을 크기만 바꿔 같이 올려요.

## 4. 사용자가 만들기 쉬운 형식과 Claude가 도울 일

| 형식 | 사용자 (UI 디자이너) | Claude가 도울 수 있는 일 |
|---|---|---|
| 짤 틀 (피그마) | 정사각형, 세로형 틀 2~3개를 한 번 만들어 두고 글만 바꿈 | 피그마에 틀 만들기, 글 넣기, 내보내기 |
| 앱 화면 영상 | 폰 화면 녹화 | adb로 화면 녹화, 자르기와 글자 넣기 초안 |
| 짤 문구 | 마음에 드는 것 고르기 | 공감 문구 후보 여러 개, 해시태그 후보, 가운뎃점과 긴 줄표 검사 |
| 고르기 카드 | 카드 디자인 | 질문과 답 문구, 카드 순서 |
| 기록 | 게시 버튼 누르기 (직접) | 매주 반응 숫자 정리표 |

- 계정 만들기, 로그인, 게시 버튼은 **사용자가 직접** 해요. Claude는 만들기와 정리만 도와요.

## 5. 첫 게시물까지 준비할 최소한의 것

| 준비물 | 내용 |
|---|---|
| 계정 아이디 | 앱 이름이 정해진 뒤. 스토어, 사이트와 같은 이름으로 |
| 프로필 사진 | 확정 앱 아이콘 (Clock Day Black) |
| 소개 문장 | 아이디어 5 규칙대로 **스토어 짧은 설명과 같은 문장**. 앱 소개 한 문장은 아이디어 9에서 정해요 |
| 프로필 링크 | 플레이 스토어 링크 (비공개 테스트 중이면 사이트 주소) |
| 짤 틀 | 피그마 틀 2~3개 |
| 미리 만든 게시물 | 6~8개 (공감 짤 절반, 화면 영상 절반) |
| 계정 종류 | 비즈니스 또는 크리에이터 계정 (무료 통계가 보여요) |
| 사업자 정보 | 프로필에 넣을지는 아직 안 정함. 넣게 되면 **Leader가 사용자에게 먼저 물음** |

소개 문장 예시 (손님이 보는 글, 확정 아님):
- `미션 하나로 가볍게 깨우는 무료 알람, 앱 이름`
- `알람 끄고 다시 자는 사람들을 위한 무료 알람`
