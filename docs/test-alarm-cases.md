# 시험 알람 A~G 계획과 결과

11-17 사용자 지시로 만들었어요. 알람 설정 조합은 약 1만 가지라서 다 시험할 수 없어요. 그래서 기능마다 한 번씩 확인되도록 7가지로 줄였어요.

## 시험하는 법

1. 개발용 빌드 설정 탭 맨 아래 '시험 알람'에서 버튼을 누르면, 다음 분 정각에 울리는 한 번 알람이 생겨요.
2. 아래 '할 일'대로 하고 '확인할 것'을 봐요.
3. 끝나면 Claude에게 "A 끝"처럼 알려요. Claude가 폰의 진단 기록을 꺼내 무슨 일이 있었는지 봐요(울림 단계, 소리 크기, 진동, 화면 꺼짐, 볼륨 버튼). 결정 69, 읽는 법은 `tools/read-diag.py` 맨 위에 있어요.
4. 결과 표에 날짜, 빌드, 결과를 적어요. 안 되는 것은 사용자 지적처럼 결정 기록으로 이어 가요.

공통: 알람음은 'Spring Season'이에요. 개발용 빌드는 앱이 내는 소리를 10% 크기로 내요(결정 63). 다시 잠들기 방지와 미션이 없는 경우는 따로 적지 않았으면 꺼짐이에요.

## 방치했을 때 울리는 시간

한 번 울리면 2분 울리고, 다시 울림 간격만큼 쉰 뒤 다시 울려요(11-16 결정은 1분, 11-19 사용자 결정: 2분으로 바뀜). 전체 시간은 2분 × (횟수 + 1) + 간격 × 횟수예요. 아래 표와 시험 경우는 2분 기준으로 고쳤어요.

| 다시 울림 | 3분 | 5분 | 10분 | 15분 |
|---|---|---|---|---|
| 꺼짐(새 알람 기본값) | 2분 | 2분 | 2분 | 2분 |
| 3번 | 17분 | 23분 | 38분 | 53분 |
| 5번 | 27분 | 37분 | 62분 | 87분 |
| 끌 때까지 | 안 멈춤 | 안 멈춤 | 안 멈춤 | 안 멈춤 |

- 미션 중 59초 동안 손을 놓으면 다시 2분 울려요. 다시 울림 횟수에서 빠지지 않아요.
- '깨어 있나요'(W2)에 답하지 않으면 다시 울림 횟수가 처음으로 돌아가 처음부터 다시 울려요.

## 시험 경우

| 경우 | 설정 | 할 일 | 확인할 것 | 걸리는 시간 |
|---|---|---|---|---|
| A | 전부 기본값(미션 없음, 다시 울림 꺼짐) | 그냥 둬요 | 2분 울리고 멈춰요. '놓친 알람' 알림이 남아요 | 3분 |
| B | 다시 울림 3분 간격 3번 | 그냥 둬요 | 2분 울림이 4번, 그 사이 3분 쉼이 3번이라 17분에 끝나요 | 18분 |
| C | 미션 Drop Words 3개, 전원 종료 방지 켬 | 울릴 때 화면 껐다 켜기, 볼륨 버튼 누르기, '미션 시작', 59초 손 놓기, 전원 버튼 길게 누르기, 미션 풀기 | 화면이 꺼져도 진동이 이어져요. 볼륨이 안 바뀌어요. 미션 중 소리와 진동이 꺼져요. 59초 뒤 다시 울려요. 전원 메뉴가 바로 닫혀요. 3개로 끝나요 | 4분 |
| D | 미션 Quick Math 1문제, 다시 잠들기 방지 1분 뒤 / 30초 | 화면 끈 채로 기다리기, 미션 풀기, W2에 답 안 하기 | 꺼진 화면이 켜져요. 1분 뒤 W2가 맨 앞에 떠요. 30초 뒤 처음부터 다시 울려요 | 4분 |
| E | 진동 끔, 부드럽게 깨우기 30초 | 들어요 | 진동이 없어요. 작은 소리로 시작해 30초 동안 커져요 | 2분 |
| F | 알람음 끔(진동만) | 그냥 둬요 | 소리 없이 진동만 와요 | 2분 |
| G | 다시 울림 3분 간격, 끌 때까지 | 두 번 울린 뒤 꺼요 | 횟수를 다 써도 멈추지 않아요 | 8분 |

- E의 부드럽게 깨우기는 10% 소리의 5%에서 시작해서, 처음 몇 초는 거의 안 들릴 수 있어요.
- C의 전원 종료 방지는 접근성 권한이 켜져 있어야 해요.
