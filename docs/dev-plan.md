# morning-up 개발 순서 기획 (2026-11-16)

> 이 문서는 '무엇을 어떤 순서로 만들고, 어디서 사용자가 확인하는지'를 정한 단계 기획이에요. 코드 단위의 자세한 작업표(파일, 함수, 테스트 이름)는 각 단계를 시작할 때 이 문서를 바탕으로 따로 써요. 개발은 사용자가 '시작'이라고 할 때 해요.

**목표:** 미션을 풀어야 꺼지는 안드로이드 알람 앱 첫 버전을, '알람이 확실히 울리는 것'부터 차례로 쌓아 출시까지 가져가요.

**구조:** 구글 공식 권장 앱 구조(Now in Android 견본 앱 방식)를 따라요. 기능별 모듈로 나누고, 화면은 ViewModel이 내보내는 상태만 그려요. 알람 엔진(저장, 예약, 울림, 복구)은 화면과 따로 된 모듈이라 화면 없이도 테스트해요. 자세한 규칙은 아래 '개발 방식'이에요.

**기술:** Kotlin, Jetpack Compose, Material 3, Room(폰 안 데이터베이스), DataStore(작은 설정 파일), AlarmManager `setAlarmClock()`, 포그라운드 서비스, 전체 화면 알림. 서버, 로그인, Firebase는 첫 버전에 없어요(F23).

**근거 문서:** `docs/dev-readiness.md`(4번 F1~F24 확정, 4-1 미션 없는 알람, 3번 흐름 표), `docs/design-system.md`(화면 규칙과 토큰), `docs/mission-levels.md`(미션 단계와 공통 규칙), `research/B-opensource-tech.md`(알람 안정성), `research/H-location-law.md`(날씨 위치). 피그마 `MazZLYfaQndMh9AxlRcz2v`의 `화면` 페이지(`30:2`)와 `디자인 시스템` 페이지(`137:704`). `06 핵심 흐름 (옛 기록, 11-15)` 페이지는 기준이 아니에요.

## 공통 규칙

- 지원 버전: 최소 안드로이드 8.0(API 26), 목표 API 36 (F19).
- 테스트 기기: 사용자 폰 갤럭시 S24+, 갤럭시 Z플립5. 그 밖에는 에뮬레이터. 샤오미 실기기는 없어요(출시 전 한계로 적어 둬요).
- 폰 작업 규칙: 화면 회전 설정은 건드리지 않아요. 시작할 때 `accelerometer_rotation`, `user_rotation` 값을 적고 끝나면 같은지 확인해요. 화면 깨우기는 설정을 바꾸지 않고 30초마다 `KEYCODE_WAKEUP`(최대 15분)으로 해요.
- 색, 글자, 간격, 라운드, 그림자는 모두 피그마 변수 이름을 따른 코드 토큰으로만 써요. 화면에 원색을 직접 쓰지 않아요(예외: 미션 플레이 화면 색 묶음 `mission/…`, 시트 뒤 막 `#14202E` 40%).
- 아이콘은 Lucide 하나로 통일해요. 직접 그리지 않아요.
- 손님이 보는 글(앱 문구, 스토어 글, 개인정보 처리방침)에는 가운뎃점과 긴 줄표를 쓰지 않아요. 문구 속 버튼 이름은 작은따옴표로 감싸요.
- 선택 표시는 칠로만 해요. 테두리, 글래스 효과, 구분선은 쓰지 않아요. 스누즈 버튼과 비상 탈출은 없어요.
- 오픈소스 코드는 Apache 2.0, MIT만 가져와요. GPL 코드는 보기만 해요. 가져온 것은 T5 오픈소스 라이선스 화면에 적어요.
- 작업 가지(branch) 안의 작은 커밋은 작업하면서 해요. `main`에 합치기와 GitHub에 올리기(push)는 사용자 확인 관문을 통과한 뒤에만 해요. 단계가 끝날 때마다 사용자가 폰에서 확인하는 '확인 관문'을 둬요.

## 개발 방식 (유지보수할 수 있는 실무 방식)

한 번에 아무렇게나 짜지 않고, 실제 앱 회사 엔지니어들이 쓰는 방식을 그대로 따라요. 나중에 기능을 고치거나 다른 개발자가 이어받아도 읽을 수 있게 하는 게 목표예요.

### 1. 구조

| 항목 | 정한 방식 | 왜 |
|---|---|---|
| 기준 | 구글 공식 앱 구조 가이드와 Now in Android 견본 앱 | 안드로이드 업계 표준이라 누가 봐도 익숙해요 |
| 모듈(코드 덩어리) | 1단계에서 `:app`, `:core:model`(알람, 미션 같은 데이터 모양), `:core:designsystem`(토큰, 공통 부품), `:core:data`(Room, DataStore, 저장소 창구), `:core:alarm`(예약, 울림 서비스, 복구), `:core:testing`으로 시작해요. 기능 모듈(`:feature:home`, `:feature:edit`, `:feature:ring`, `:feature:mission`, `:feature:settings`, `:feature:sleep`, `:feature:weather`)은 그 기능을 만드는 단계에서 하나씩 만들어요 | 기능끼리 서로 몰라서 하나를 고쳐도 다른 곳이 안 깨져요. 처음부터 빈 모듈을 잔뜩 만들지 않아 혼자 관리하기에도 무겁지 않아요 |
| 의존 방향 | `feature`는 `core`만 쓰고, `feature`끼리는 서로 직접 부르지 않아요. 화면 이동은 `:app`의 길 안내(Navigation)에서만 이어요 | 순환 의존(서로 물고 늘어짐)을 막아요 |
| 화면 구조 | 단일 액티비티(울림 화면만 잠금 화면 위용 액티비티 하나 더), Compose 화면 하나에 ViewModel 하나. 상태는 `StateFlow`로 한 방향 흐름(UDF: 데이터가 위에서 아래로만 흘러요) | 화면이 '상태만 그리는 그림'이 돼서 테스트하기 쉬워요 |
| 데이터 창구 | 저장소(Repository) 인터페이스 뒤에 Room, DataStore를 숨겨요. 화면은 Room을 직접 모르게 해요 | 저장 방식을 바꿔도 화면은 그대로예요 |
| 의존성 주입 | Hilt | 부품을 갈아 끼우기 쉽고, 테스트 때 가짜 부품을 넣을 수 있어요 |
| 시간 | 현재 시각은 `Clock`을 주입받아 써요. 코드 곳곳에서 시스템 시각을 직접 부르지 않아요 | 자정, 공휴일, 시간대 테스트를 시각을 고정해 돌릴 수 있어요 |
| 비동기 | 코루틴과 Flow. 작업 스레드(Dispatcher)도 주입받아요 | 테스트에서 시간을 빨리 감을 수 있어요 |
| 저장 위치 | Room과 DataStore를 통째로 '기기 보호 저장소'(잠금을 풀기 전에도 읽히는 칸)에 둬요. 같은 데이터를 두 곳에 나눠 두지 않아요. 앱 시작 코드는 잠금 전에도 안전하게(일반 저장소를 건드리지 않게) 만들어요 | 재부팅 뒤 잠금을 풀기 전에도 알람이 울려야 해서예요. 안드로이드 기본 시계도 이렇게 해요. 민감한 데이터가 없어 괜찮아요 |
| 울림 서비스 종류 | 포그라운드 서비스 종류는 `systemExempted`(정확한 알람 권한을 가진 알람 앱용). 울림은 늘 알람 신호에서 시작하고, 부팅 신호에서 직접 시작하지 않아요 | 안드로이드 14, 15의 시작 제한에 걸리지 않는 방법이에요 |
| 기기 안 진단 기록 | 알람 사건(예약, 울림 신호 받음, 서비스 시작, D0 표시, 꺼짐, 놓침)을 기기 보호 저장소에 짧게 남기고, 숨은 디버그 화면에서 보고 내보낼 수 있게 해요. 앱이 갑자기 죽으면 다시 예약하고, 울리던 중이었으면 다시 울려요 | 서버와 오류 보고 도구가 없어서, '안 울렸다'를 사용자 폰에서 원인까지 찾으려면 꼭 필요해요 |

### 2. 코드 규칙

- 빌드 설정은 버전 목록 파일(`gradle/libs.versions.toml`) 하나와 공통 빌드 설정(convention plugin)으로 모아요. 모듈마다 버전을 따로 적지 않아요.
- 화면 글자는 모두 `strings.xml`(한국어)에 둬요. 코드에 한글 문구를 직접 쓰지 않아요. 색, 크기도 토큰만 써요.
- 이름은 코틀린 공식 규칙을 따르고, 자동 검사(ktlint, detekt, Android Lint)를 통과해야 해요. 경고를 꺼서 넘기지 않아요.
- 하나의 파일은 한 가지 일만 해요. 너무 길어지면 나눠요.
- Room 데이터베이스는 구조를 파일로 내보내고(schema export), 구조를 바꿀 때마다 옮기는 코드(migration)와 그 테스트를 같이 써요. 사용자 알람이 업데이트 때 사라지면 안 돼요.
- 로그는 Timber로 남기고, 출시 빌드에선 개인정보가 담긴 로그를 남기지 않아요.
- 출시 빌드는 코드 줄이기와 난독화(R8)를 켜요. 버전 이름과 번호 규칙을 정해 둬요. 폰 확인 관문(2단계, 10단계)과 개발 후 체크리스트는 출시 빌드로도 해요. 디버그 빌드에서만 되고 출시 빌드에서 깨지는 일을 막아요.
- 목표 API 36 규칙을 지켜요: 뒤로가기는 `BackHandler`로 처리하고(예측 뒤로가기가 기본), 화면은 위아래 시스템 바 영역까지 쓰는 방식(edge-to-edge)이라 바 높이를 코드에서 비워요.
- 디버그 앱 ID에는 `.debug`를 붙여 출시판과 같이 깔 수 있게 해요. 둘 다 깔면 알람이 두 번 울리니 확인할 때는 하나만 켜 둬요.
- 오픈소스를 쓰기 전에 라이선스를 확인하고 T5 목록에 바로 적어요.

### 3. 테스트

| 종류 | 무엇을 | 도구 |
|---|---|---|
| 단위 테스트 | 다음 울릴 시각 계산, 1분 울림과 쉼 계산, 59초 규칙, 미션 문제 만들기와 채점, ViewModel 상태 | JUnit, Truth, Turbine(Flow 테스트), 가짜 `Clock` |
| 데이터베이스 테스트 | 저장, 불러오기, 구조 옮기기(migration) | Room 테스트 도구 |
| 화면 테스트 | 버튼을 누르면 상태가 바뀌는지 | Compose UI 테스트 |
| 예약 흐름 테스트 | 재부팅, 시간 변경, 백업 복원 때 다시 예약하는 길 | Robolectric(가짜 안드로이드 환경) |
| 화면 사진 비교 | 주요 화면을 라이트, 다크, 큰 글꼴로 찍어 이전과 달라졌는지. 7단계부터 붙여요 | Roborazzi(스크린샷 테스트) |
| 실기기 테스트 | 잠자기, 재부팅, 시간대, 방치 | 사용자 폰 2대와 adb (2단계, 10단계 확인 관문) |

- 엔진과 계산 로직은 테스트를 먼저 쓰고 코드를 써요(TDD). 버그를 고칠 때는 그 버그를 다시 막는 테스트부터 써요.
- 테스트가 하나라도 실패하면 다음 작업으로 넘어가지 않아요.

### 4. 작업 흐름

- 단계마다 가지(branch)를 따로 만들고, 작은 작업 단위로 커밋해요. 커밋 메시지는 무엇을 왜 바꿨는지 적어요.
- 단계가 끝나면 PR(바꾼 내용 묶음)을 만들고, 처음 보는 검토자(별도 리뷰 에이전트)가 코드를 검토한 뒤 사용자 확인 관문을 거쳐 `main`에 합쳐요.
- GitHub Actions(CI)가 PR마다 빌드, 자동 검사, 단위 테스트와 Robolectric 테스트를 돌려요. 에뮬레이터 테스트는 느리고 불안정해서 CI에선 돌리지 않고 PC에서 돌려요. 빨간불이면 합치지 않아요.
- 큰 기술 결정(예: 모듈 구조, 저장 위치, 울림 서비스 종류, 알람 예약 방식, 울림 상태표, 날씨 서비스 선택)은 `docs/adr/`에 '결정 기록'(ADR) 한 장씩 남겨요. 왜 그렇게 했는지 나중에 찾을 수 있어요.
- 단계마다 코드 단위 작업표(파일, 함수, 테스트 이름)를 먼저 쓰고 사용자에게 보여 준 뒤 시작해요.

## 모션과 인터랙션 (11-16 사용자 결정: 비어 있는 곳은 추천안으로, 요즘 방식으로)

장면 움직임(홈 하늘 궤도와 둥실, 울림 화면 해 뜨기와 달 뜨기, 비와 눈, 숨쉬는 빛, 59초 타이머 고리, Drop Words 떨어짐)은 `design-system.md`에 정한 값을 그대로 써요. 이 단락은 그 밖에 비어 있던 '조작했을 때의 반응'을 정해요.

### 기본 원칙

- **요즘 방식: 시간으로 정한 움직임보다 스프링(용수철처럼 튕기며 멈추는 물리 움직임).** 구글 머티리얼 3 Expressive(2025년부터 구글 앱에 쓰는 새 움직임 규칙)와 iOS가 모두 이 방식이에요. 손가락으로 끌다 놓아도 자연스럽게 이어지고, 중간에 다시 눌러도 끊기지 않아요.
- 움직임 값은 코드 한 곳(`:core:designsystem`의 `MorningMotion`)에만 두고 화면마다 숫자를 직접 쓰지 않아요. 나중에 느낌을 바꿀 때 한 곳만 고쳐요.
- 위치와 크기가 바뀌는 움직임은 살짝 튕기는 스프링, 투명도와 색이 바뀌는 움직임은 튕기지 않는 스프링을 써요.
- 알람 울림 화면(D0)은 단순하게 둬요. 정해진 장면 움직임 말고 장식 움직임을 더하지 않아요. 유리 질감, 물방울, 빗물 맺힘처럼 닿는 효과는 쓰지 않아요.

| 토큰 | 쓰는 곳 | 값 (Compose `spring`) |
|---|---|---|
| `spatialFast` | 누름 반응, 토글 손잡이, 작은 부품 | 감쇠 0.6, 강도 1400 |
| `spatialDefault` | 시트, 카드 펼침, 토스트, 목록 자리 바꿈 | 감쇠 0.8, 강도 700 |
| `spatialSlow` | 화면 넘김, 큰 장면 | 감쇠 0.85, 강도 300 |
| `effectsFast` | 색, 투명도의 짧은 변화 | 감쇠 1.0, 강도 1600 |
| `effectsDefault` | 페이드, 칠 바뀜 | 감쇠 1.0, 강도 700 |

### 지켜야 할 것

- **'애니메이션 줄이기'(기기 접근성 설정)가 켜져 있으면** 위치와 크기가 바뀌는 움직임은 모두 짧은 페이드로 바꾸고, 반복 장면(하늘 둥실, 해 뜨기 반복, 비와 눈, 숨쉬는 빛)은 멈춘 그림으로 둬요. 진동은 그대로예요.

- 모든 움직임은 화면 사진 비교 테스트(7단계부터)에 '움직임 없는 상태'로 찍혀요.

## 2단계. 알람 엔진 (가장 중요)

**만들 것:** 화면 없이도 '알람이 확실히 울리는' 부분 전체. 화면은 임시 D0(시각과 버튼 하나)만 써요.

2-0. 울림 상태표 먼저 정하기 (ADR)
- 상태: 예약됨, 울리는 중, 쉬는 중, 미션 중, W2 기다리는 중, 꺼짐, 놓침. 상태가 바뀌는 조건과 횟수 세는 규칙을 표 하나로 정하고 시작해요.
- 1분 울림은 '울리는 중'에서만 세요. 미션 중(소리를 끈 동안)에는 세지 않고 59초 규칙을 따라요(F4).
- 추천: 59초가 끝나 다시 울릴 때와 W2 시간 초과로 다시 울릴 때는 '다시 울림 횟수'를 깎지 않아요. 한 번 깬 사람이라 끝까지 깨워야 해서예요. 횟수는 아무도 손대지 않을 때만 써요.
- 다시 울릴 때마다 `setAlarmClock`으로 새로 예약해요. 서비스를 켜 둔 채 기다리지 않아요.

2-1. 저장과 다음 울릴 시각 계산
- 알람 한 개에 담는 값: 시각, 반복 요일, 공휴일 끄기, 켜짐, 미션 목록(없으면 그냥 알람), 다시 울림(간격 3, 5, 10, 15분과 횟수 3번, 5번, 끌 때까지), 다시 잠들기 방지(켜짐, 묻는 때 1~10분, 답할 시간 30초~2분), 전원 종료 방지, 알람음, 볼륨과 진동, 부드럽게 깨우기, 배경, '이번만 쉬기' 날짜.
- 새 알람은 미션 없음으로 시작해요(4-1).
- 다음 울릴 시각 계산은 순수 함수 하나로 만들고 자동 테스트를 촘촘히 해요: 요일 반복, 자정 넘김, 한 번 알람, 공휴일(2026~2027 한국 공휴일과 대체공휴일 목록을 앱에 넣음, F13), 이번만 쉬기, 시간대 변경, 서머타임으로 시각이 없어지거나 두 번 생기는 날(예: 뉴욕 3월 둘째 일요일 2:30).
- 공휴일 목록이 끝난 뒤(2028년)에는 공휴일 끄기 없이 요일대로 울리고, 설정에 '공휴일 목록을 업데이트해 주세요' 안내를 띄워요.

2-2. 예약과 복구
- `setAlarmClock()`과 `USE_EXACT_ALARM`. 거절되면 `SCHEDULE_EXACT_ALARM`(F6).
- 권한 선언: `USE_EXACT_ALARM`(안드로이드 13 이상)과, 안드로이드 12용 `SCHEDULE_EXACT_ALARM`(`maxSdkVersion` 32). `USE_EXACT_ALARM`이 Play 심사에서 거절되면 그때 `SCHEDULE_EXACT_ALARM` 흐름으로 바꿔요. 앱이 실행 중에 고르는 게 아니라 심사 결과로 정해지는 거예요.
- 재부팅(잠금 전 `LOCKED_BOOT_COMPLETED`와 잠금 뒤), 시간 변경, 시간대 변경, 앱 업데이트, 정확한 알람 권한 다시 허용 때 모두 '전체 다시 예약' 함수 하나로 처리해요(F7). 울림 화면, 울림 서비스, 신호 받는 곳은 모두 잠금 전에도 동작하게(`directBootAware`) 해요. 잠금 전에는 S8 내 사진을 못 읽을 수 있어서 기본 하늘 배경으로 대신해요.
- 폰이 꺼져 있는 동안 알람 시각이 지났으면: 추천, 켜진 뒤 10분 안이면 바로 울리고 그보다 늦으면 '놓친 알람' 알림만 남겨요.
- 자동 백업(F11): 백업 규칙에 기기 보호 저장소를 넣고, 내 사진 주소와 '이번만 쉬기' 날짜처럼 그 폰에만 맞는 값은 빼요. 새 폰에 복원되면 다시 예약하고, 다시 예약을 못 하면 '앱을 한 번 열어 주세요' 알림을 띄워요.

2-3. 울림
- 포그라운드 서비스(`systemExempted`)로 소리와 진동, 전체 화면 알림으로 임시 D0을 띄워요(F8). 알람 음량 채널로 울려서 무음 모드에서도 들려요.
- 화면이 켜져 있고 잠금이 풀린 채 다른 앱을 쓰는 중이면 안드로이드 규칙상 D0이 바로 뜨지 않고 위에서 내려오는 알람 알림으로 떠요. 누르면 D0으로 가요. `setAlarmClock`에 화면을 여는 신호를 넘기는 방법으로 바로 뜨게 할 수 있는지도 S24+에서 시험해요.
- 고른 알람음을 못 읽으면(잠금 전, 파일 삭제, 복원 뒤) 앱 안에 넣어 둔 기본 알람음으로 바로 바꿔 울려요. 소리 없이 지나가는 일은 없어야 해요.
- 울리는 중의 진행(지금 미션 순서, 끝낸 미션, 59초 마감 시각)은 기기 보호 저장소에 계속 저장해요. 앱이 죽었다 살아나도 하던 곳부터 이어요.
- 울리는 동안 상단 알림을 띄워요. 끄기 버튼은 없고 누르면 D0(또는 하던 미션)으로 가요. 모양은 안드로이드 기본 알림에 앱 아이콘과 시각만 둬요(2-2의 1번 빈 화면, 개발하면서 정함).
- 아무도 안 끌 때: 1분 울리고 멈춘 뒤 다시 울림 간격만큼 쉬고 다시 울려요. 횟수가 끝나면 멈추고 '놓친 알람' 알림을 남겨요(F4).
- 한 번 알람(반복 없음)은 울리고 끄면 토글이 꺼져요(3번 흐름 표 13).
- 미션 중 다른 알람 시각이 되면 뒤 알람은 울리지 않고 '지나감'으로 처리해요. 전화 통화 중이면 진동과 작은 소리만 내고 통화가 끝나면 원래대로 울려요(3번 흐름 표 9, 10). 통화는 전화 권한 없이 `AudioManager`의 통화 상태와 오디오 포커스로 알아채요.
- 알람 사건은 위 '기기 안 진단 기록'에 남겨요.
- 임시 알람음은 폰 기본 알람음 하나예요(F22).

- 넘겨줄 것: 알람 상태를 하나의 흐름으로 내보내요(예약됨, 울리는 중, 쉬는 중, 미션 중, 꺼짐, 놓침). 3~6단계 화면은 이 상태만 보고 그려요.
- 자동 테스트: 다음 시각 계산, 1분 울림과 쉼과 횟수 계산, 전체 다시 예약.
- 준비: 알림 권한 묻는 화면은 6단계에 나오니, 이 단계에선 `adb shell pm grant <앱 ID> android.permission.POST_NOTIFICATIONS`로 미리 켜 두고 시험해요.
- 확인 관문 (폰 2대, 디버그와 출시 빌드 둘 다): 잠자기 모드 강제(화면 끄고 `adb shell dumpsys battery unplug` 뒤 `adb shell dumpsys deviceidle force-idle`), 앱 대기 상태(`am set-inactive <앱 ID> true`, `am set-standby-bucket <앱 ID> restricted`), 재부팅 뒤 잠금 안 풀고 대기, 시간대 서울과 뉴욕 바꾸기, 앱 밀어서 종료 뒤 다음 실행 복구, 10분 이상 방치, 통화 중 알람, 고른 알람음 파일을 지웠을 때, 플립5를 접은 채 울릴 때(바깥 화면). 끝나면 `dumpsys deviceidle unforce`, `dumpsys battery reset`, `am set-inactive <앱 ID> false`로 폰을 원래대로 돌려요. 정확한 알람 권한을 껐다 켜는 시험은 사용자 폰(안드로이드 14 이상)에선 끌 수 없어서 안드로이드 12 에뮬레이터에서 해요. 모두 통과해야 3단계로 가요.

## 3단계. 홈과 알람 편집

**만들 것:** H0 홈(하늘 없이 단색 자리), H1 빈 홈, H5 삭제 확인, H6 저장 토스트, H7 삭제 스낵바, S0 알람 편집(미션 있음, 미션 없음 두 상태), S0-1 저장 안 하고 나가기.

- S0 미션 줄: 미션이 없으면 토글 꺼짐과 값 '없음', '미리 해보기' 숨김, '전원 종료 방지' 줄은 비활성(4-1).
- 설정 줄 값 글자에는 파란색을 쓰지 않아요(`text/secondary`, 꺼지면 `text/disabled`).
- 미션 고르기 S1-2는 이 단계에선 자리만 두고 5단계에서 만들어요.
- 상태 표시줄 알람 아이콘을 누르면 그 알람의 편집 화면(S0)으로 열려요(3번 흐름 표 1).
- 확인 관문: 알람을 만들고, 고치고, 지우고, 켜고 끄면 예약이 따라와요. 저장 직후 상태 표시줄 알람 아이콘과 '몇 시간 몇 분 후' 문구가 맞고, 아이콘을 누르면 S0이 열려요.

## 4단계. 울림에서 해제까지 한 바퀴 (Quick Math 하나로)

**만들 것:** D0 알람 울림(아침, 밤), M3 Quick Math, W1 해제 완료(날씨 없이 짧은 인사), W2 깨어 있나요 확인, S4 다시 잠들기 방지.

- 미션 없는 알람은 D0 버튼 글만 '알람 끄기'예요. 누르면 바로 꺼지고 W1이 떠요(4-1).
- 미션을 시작하면 소리와 진동을 꺼요(F14, 11-17 사용자 지시로 20%에서 끄기로 바꿈. 사용자가 손을 쓰는 중이라서). 59초는 '손을 놓은 시간'이에요. 어떤 동작이든 59초로 돌아가고, 0이 되면 원래 크기로 다시 울리고 D0으로 가요. 다시 시작하면 그 미션은 처음부터예요.
- 미션 중 뒤로가기는 아무 일도 안 해요. 홈 버튼으로 나가도 59초는 이어지고, 상단 알림을 누르면 하던 미션으로 돌아와요(3번 흐름 표 2, 3).
- Quick Math 키패드는 무작위 배열이고 정답마다 다시 섞여요. 틀리면 새 문제로 처음부터, 알람은 다시 울리지 않아요.
- W1 '확인' 뒤: 잠긴 채 껐으면 잠금 화면, 잠금이 풀려 있었으면 홈(H0). W2 '깼어요' 뒤: 화면을 닫고 원래 있던 곳으로. W2를 시간 안에 안 누르면 D0부터 고른 미션을 모두 처음부터 해요(3번 흐름 표 5~7).
- 처음 값: 다시 잠들기 방지 '1분 후', 답할 시간 1분(F9). W2를 묻는 때와 답할 시간 끝은 잠자기 모드에서도 정확해야 해서 정확한 알람(`setExactAndAllowWhileIdle`)으로 예약하고 상태를 저장해요. W2 시간 초과는 울림과 똑같이 다뤄요.
- 미션 고르기(S1-2)는 5단계에 나오니, 이 단계에선 디버그 빌드에만 보이는 임시 줄로 Quick Math를 붙여 시험해요.
- **먼저 그려야 할 것: W2를 부르는 알림**(화면이 꺼져 있을 때 W2를 전체 화면으로 띄우는지 포함). 추천: 울림과 같은 전체 화면 알림으로 띄워요.
- 확인 관문: 진짜 알람으로 울림, Quick Math, W1, W2까지 한 바퀴. 미션 중 손을 놓아 59초가 끝나는 경우, W2를 안 누르는 경우도 해 봐요.

## 5단계. 나머지 미션과 미션 고르기

**만들 것:** M1 Drop Words, M2 Pop Quiz, M4 Shake Shake, S1-2 미션 고르기(미션 있음, 미션 없음), 설정 시트 S1-3~S1-7, '미리 해보기', 미션 사이 넘어가기.

  (11-20 사용자 결정 '추천안대로': 사용성 테스트용으로 먼저 Pop Quiz 단계마다 50문제, Drop Words 단계마다 60단어로 늘렸어요. F15, F16 목표는 그대로예요.)
- 미리보기: 소리 없음, 59초가 0이 돼도 알람 대신 시트로 돌아가요, 왼쪽 위 닫기, 끝나면 '잘했어요'. 미리보기 중 진짜 알람이 오면 미리보기를 닫고 진짜 울림으로 바꿔요(3번 흐름 표 11).

- 확인 관문: 미션 3개 묶음이 순서대로 돌고, 중간에 59초가 끝나면 하던 미션부터 다시 해요.

## 6단계. 설정과 권한, 전원 종료 방지

**만들 것:** T1 설정, T2 '권한' 한 화면(카드 셋 '필수 권한', '선택 권한', '기타', 11-18 결정 130 보충), P5, P6 바텀시트(P1~P4는 보관, 11-18 결정 125. P7은 11-19 결정 134로 안 씀), H2 권한 경고 배너 4종, 온보딩 화면(스플래시, O2-1~O2-4, O3, 11-19 결정 131), 나중용 목록 시트 PL2(두 단계), 하단 메뉴 설정 탭 '확인 필요' 말풍선, T5 오픈소스 라이선스, 전원 종료 방지(접근성 권한).

- 권한 목록: 알림, 정확한 알람, 전체 화면 알림, 배터리 제한 없음, 방해 금지 모드 접근, 다른 앱 위에 표시(필수, 11-18 결정 105), 부팅 뒤 다시 등록, 진동, 위치(9단계), 접근성(전원 종료 방지) (F20). 11-18 결정 130으로 다섯 단계로 나눠 묻는 자리와 강도를 정했어요: 1 꼭 필요(알림, 전체 화면 알림, 다른 앱 위, 온보딩 한 장씩, 배너, PL 1단계), 2 있으면 좋음(배터리, 위치, 온보딩 건너뛰기 가능, 배터리만 배너와 푸시, PL 2단계), 3 기능 켤 때만(접근성), 4 설정에만 조용히(방해 금지, 알람 음량, 절전 예외), 5 묻지 않음(진동, 부팅, 화면 켜기, 정확한 알람. 정확한 알람은 설정 '권한' 화면에도 줄이 없어요, 11-19 결정 133). 표는 `decisions-11-18.md` '결정 130 권한 분류표'.
- 권한은 두 가지 디자인으로 받아요(11-18 결정 129). 온보딩: O2 새안 시리즈(한 화면에 권한 하나, 큰 그림과 움직임, O2-1 알림, O2-2 전체 화면 알림, O2-3 배터리, O2-4 다른 앱 위에 표시, 버튼 '{권한} 허용하기'와 '나중에 하기'. O2-4 다른 앱 위에 표시(결정 129 보충 3, 스플래시 → O2-1~O2-4 → O3, 진행 점 5개(11-19 결정 131, O1은 스플래시, O4는 없앰), 이미 켜진 권한 화면은 건너뜀)). 나중용: 홈 H2 배너나 배터리 푸시를 누르면 홈 위에 바텀 모달 목록 시트 PL2(**확정, 개발 대상**, 11-19 결정 132: 헤드 A안, 뒤로 가기로만 닫힘, X 없음)(두 단계, 결정 129 보충 5: 1단계 필수 3줄 알림, 다른 앱 위, 전체 화면 알림과 '다음'(필수 셋이 켜져야 활성), 2단계 선택 2줄 배터리, 위치와 '완료', '다음에 하기'. 필수가 다 켜진 채 열리거나 배터리 배너, 푸시로 열면 2단계부터. 받는 권한은 온보딩과 같음, 보충 4), 줄마다 토글은 폰 설정으로 가는 버튼이고 실제 허용 때만 켜짐, 그 밖엔 토스트 3초, 폰 뒤로 가기로 닫힘, 결정 127 보충 1~4). 첫 알람 저장 때는 아무것도 띄우지 않아요(정확한 알람은 묻지 않음, 결정 119). 알림이 꺼져도 저장은 돼요. 나머지는 H2 배너(한 번에 하나, 급한 순서), 설정, 배터리 전날 밤 푸시(하루 한 번)로 안내해요(F21, 11-18 결정 110, 112, 113, 129). 앱을 열 때마다 팝업은 띄우지 않아요.
- 정확한 알람: 알람 앱은 `USE_EXACT_ALARM`으로 설치 때 자동 허용돼요. 설정에도 줄을 두지 않아요(11-19 결정 133). 혹시 꺼져 있으면(안드로이드 12) 앱이 조용히 처리할 방법은 개발 방이 확인해요.
- 설정 T2의 모든 줄(알림, 전체 화면 알림, 다른 앱 위, 배터리, 절전 예외, 방해 금지, 알람 음량)은 누르면 시트나 창 없이 바로 폰 설정으로 가고(결정 125, 126, 줄별 화면은 `decisions-11-18.md` '결정 126 줄별 이동 표'), 돌아오면 토글을 실제 상태로 바꿔요. 목록 화면으로 열리는 다른 앱 위에 표시와 방해 금지 모드 예외는 떠날 때 스낵바로 '목록에서 morning-up을 찾아 켜 주세요'(11-18 결정 125, 126).
- 울림 중 홈 키나 최근 앱으로 나가면, 다른 앱 위에 표시가 허용돼 있을 때 울림 화면을 바로 다시 띄워요(11-18 결정 114).
  - 전체 화면 알림은 안드로이드 14 이상 알람 앱에 기본으로 켜져 있어요. 확인해서 꺼져 있을 때만 바로 기기 설정 화면으로 보내요(P4는 보관, 11-18 결정 125).
  - 배터리는 직접 예외 요청 팝업을 쓰지 않고 기기 배터리 설정 화면으로 보내요(Play 정책 위험 때문).
  - 방해 금지 모드 접근은 알람 채널로 울리면 보통 필요 없어요. 줄은 '권한' 화면 '기타' 카드에 두어요(11-18 결정 130 보충).
- 전체 화면 알림 권한이 꺼졌을 때 울림은 위에서 내려오는 알람 알림으로 떠요(dev-readiness 2-2의 2번 화면).
- 권한 줄을 눌러 기기 설정에 갔다가 돌아오면 바로 다시 확인해서 토글, 배너, 말풍선을 고쳐요(3번 흐름 표 14).
- 삼성 '절전 예외 앱에 추가' 줄은 기기 배터리 설정으로 바로 보내요(T3 화면은 없앴어요).
- 전원 종료 방지: 설정에서 토글을 켜면 설정 첫 화면 위에 바텀시트 한 장(P6 자리, 동의와 켜는 곳 안내를 합침, 애니메이션 없음)이 떠요. '동의하고 설정 열기'는 바로 폰 접근성 설정으로, '나중에'는 닫기(11-19 결정 134). P7 안내 페이지는 쓰지 않아요. 미션 중 전원 메뉴가 뜨면 닫아요. 미션 없는 알람에선 쓰지 않아요. 출시 때 넣을지는 사용자가 써 보고 정해요(F1).
- **먼저 그려야 할 것:** 온보딩 O2 4장, PL2 목록 시트, '권한' 한 화면은 이미 그려져 있어요(피그마 741 구역 등, 11-19 흐름 정리). 남은 것: (11-18 결정 126으로 다른 앱 위에 표시, 방해 금지 모드 예외, 알람 음량 요청 창은 필요 없어짐. 대신 목록 화면 스낵바와 알람 음량 화살표 줄) / 권한을 두 번 거절한 뒤 '설정에서 켜 주세요' 안내 / 온보딩 O2 새안 4장(O2-4가 다른 앱 위)과 나중용 목록 시트(결정 129).
- 확인 관문: 권한을 하나씩 끄면 배너, 말풍선, 줄 상태가 맞게 바뀌어요. 알림 채널을 꺼 두거나 알림 권한을 거절했을 때도 경고가 떠요. 미션 중 전원 버튼을 길게 눌러도 메뉴가 닫혀요.

## 7단계. 홈 하늘과 알람 편집 나머지

**만들 것:** H0 홈 하늘 장면(시간대 궤도와 둥실, 날씨 없이), H3 더보기와 선택 모드, H8 이번만 쉬기(한꺼번에 끄기 포함), S3 다시 울림, S5 알람음, S6 볼륨과 진동, S7 부드럽게 깨우기, S8 알람 화면 배경.

- 이번만 쉬기: 반복 알람을 끄면 카드에 '이번만 쉬기'가 나오고, 누르면 다음 한 번만 쉬어요.
- S5 알람음 목록은 피그마 시안대로 이름과 묶음을 채운 목업 목록으로 만들어요(11-16 사용자 결정). 실제 소리는 나중에 붙여요. 지금은 어떤 항목을 골라도 앱 기본 알람음으로 울리고, 목록 데이터는 나중에 파일만 바꿔 끼우면 되게 한곳(목록 정의 파일)에 모아요. S6 볼륨 슬라이더는 머티리얼 기본 슬라이더에 토큰 색만 입혀요.
- S8 '내 사진'은 시스템 사진 선택기만 쓰고 가운데 맞춤이에요.
- '애니메이션 줄이기'가 켜져 있으면 하늘 움직임을 멈춰요.
- 확인 관문: 피그마 홈 계열 화면이 모두 나와요. 이번만 쉬기 뒤 다음 울릴 시각이 맞아요.

## 8단계. 잠들기 탭

**만들 것:** Z1 잠들기, Z2 재생(빗소리), Z2-1 종료 타이머, Z2-2와 Z2-3 숨 쉬기 장면.

- 잠들기 콘텐츠는 피그마 시안대로 제목, 분류, 썸네일을 채운 목업 목록으로 만들어요(11-16 사용자 결정). 실제 소리는 나중에 붙여요. 지금은 재생 화면, 타이머, 서서히 줄이기가 소리 없이 동작하고, 소리 파일은 나중에 목록 정의 파일에 넣기만 하면 되게 해요.
- 잠들기 재생은 알람과 다른 포그라운드 서비스 종류(`mediaPlayback`)와 미디어 세션(잠금 화면 재생 조절)을 써요.
- 확인 관문: 재생, 종료 타이머, 서서히 줄이기가 동작해요. 잠들기 소리가 켜진 채 알람이 울려도 알람이 이겨요.

## 9단계. 날씨 (F2, 출시 때 넣을지 사용자 결정)

**만들 것:** P5 위치 권한(시스템 위치 창. O3, PL2 2단계 위치 토글, '권한' 화면 '선택 권한' 카드 위치 줄을 누를 때 띄우고, 두 번 거절하면 앱 정보 화면으로 보내요. 11-18 결정 129 보충 4), 날씨 불러오기, 홈 하늘 날씨 장면, W1 날씨 한마디, T1 '날씨 애니메이션' 켜고 끄기.

- 날씨 서비스 고르기(기상청 또는 Open-Meteo). 좌표는 폰에서 격자로 바꿔 보내요. 위치정보사업 신고가 필요한지는 `research/H-location-law.md` 기준으로 출시 전에 확인해요.
- 날씨를 못 불러오거나 위치가 꺼져 있으면 홈은 시간대만 따르는 맑은 하늘, W1은 짧은 인사만 보여요.
- 확인 관문: 비, 눈, 맑음이 홈과 W1에 맞게 나와요. 위치를 끄면 맑은 하늘로 돌아가요.

## 10단계. 출시 준비

- 실기기 2~3일 방치 테스트(주말을 넘겨도 월요일 알람이 울리는지), 다크 모드 화면 검수, 큰 글꼴(시각과 키패드는 고정, 나머지 1.3배까지) 확인.
- 실제 문제와 단어 목록(F15, F16) 넣기와 검수. Pop Quiz 출처는 공식 사전 기준이고, 문제를 어떻게 만들고 검수할지는 이 단계 전에 정해요.
- 알람음, 잠들기 소리 오디오 파일 넣기.
- 전원 종료 방지와 날씨를 출시에 넣을지 사용자 결정.
- Play Console 신고(정확한 알람, 전체 화면 알림, 포그라운드 서비스 종류, 접근성을 넣으면 접근성 신고와 동작 영상), 개인정보 처리방침(위치를 넣으면 위치 항목 포함), 오류 보고(Crashlytics)를 쓸지 결정(F23).
- 울림 화면이 빨리 뜨도록 시작 성능 프로필(baseline profile)을 넣어요.
- 리뷰 요청은 첫 버전에 넣지 않아요(F12). 온보딩은 11-18부터 디자인 중이고, 권한은 온보딩 O2 새안 시리즈(권한 하나씩)로 받고, 나중에 꺼지면 배너와 푸시에서 바텀 모달 목록 시트로 받아요(11-18 결정 129, 첫 저장 때는 아무것도 안 뜸).

### A. 알람이 확실히 울리는지 (가장 중요)

- [ ] 무음 모드, 진동 모드, 방해 금지 모드에서도 소리가 나요

- [ ] 고른 알람음 파일을 지웠거나 읽을 수 없으면 앱 기본 알람음으로 울려요

- [ ] 절전 모드를 켜도 울려요
- [ ] 미션 중 앱이 죽어도(디버그 화면에서 강제로 죽이기) 다시 울리고 하던 미션부터 이어져요
- [ ] 폰이 꺼져 있는 동안 알람 시각이 지나면, 켠 뒤 정한 규칙(10분 안이면 울림, 넘으면 놓친 알람 알림)대로 해요
- [ ] 진단 기록에 예약, 울림, 꺼짐 사건이 남고 내보낼 수 있어요
- [ ] 아무도 안 끄면 1분 울림, 간격만큼 쉼, 정한 횟수 뒤 멈춤과 '놓친 알람' 알림이 나와요. '끌 때까지'는 계속 반복해요
- [ ] 10분 넘게 방치해도 소리가 끊기거나 앱이 죽지 않아요
- [ ] 통화 중 알람은 진동과 작은 소리만, 통화가 끝나면 원래대로 울려요

### C. 미션과 해제 흐름

- [ ] 네 미션 모두 59초 규칙(손을 놓은 시간, 동작하면 59초로 복귀, 0이면 다시 울리고 D0)이 같아요
- [ ] 미션 중 소리가 설정 볼륨의 20%로 줄고, 59초가 끝나면 원래 크기로 돌아와요
- [ ] 미션 중 뒤로가기는 아무 일도 안 하고, 홈 버튼으로 나가도 상단 알림을 누르면 하던 미션으로 돌아와요
- [ ] 미션 3개 묶음이 고른 순서대로 이어지고, 시간이 끝나 돌아오면 끝낸 미션은 다시 하지 않아요
- [ ] 틀렸을 때 규칙(Pop Quiz, Quick Math 처음부터 / Drop Words 입력칸만 비움 / 바닥 닿은 단어는 벌 없음)이 문서와 같아요
- [ ] Quick Math 키패드는 무작위이고 정답마다 다시 섞여요
- [ ] Shake Shake는 누워서 손목만 까딱해서는 안 줄어요. 센서가 없는 기기에선 카드가 비활성이에요
- [ ] 미션 없는 알람은 D0 버튼이 '알람 끄기'이고 누르면 바로 꺼진 뒤 W1이 떠요
- [ ] W1 뒤 잠금 화면 또는 홈으로, W2 '깼어요' 뒤 원래 있던 곳으로 가요. W2를 안 누르면 D0부터 미션을 모두 다시 해요
- [ ] 미리보기는 소리 없이 돌고, 0초가 돼도 알람이 울리지 않으며, 미리보기 중 진짜 알람이 오면 진짜 울림으로 바뀌어요
- [ ] 전원 종료 방지를 넣었다면, 미션 중 전원 메뉴가 닫혀요

### D. 권한

- [ ] 권한을 하나씩 끌 때마다 '권한' 화면 줄 상태와 설정 탭 '확인 필요' 말풍선이 맞게 바뀌어요. H2 배너는 필수 셋(알림, 전체 화면 알림, 다른 앱 위)과 배터리가 꺼졌을 때만 떠요(11-18 결정 113, 119, 130). 위치만 꺼졌을 때는 배너가 뜨지 않아요
- [ ] 기기 설정에서 돌아오면 바로 다시 확인해서 화면이 고쳐져요
- [ ] 첫 알람 저장 때는 아무것도 뜨지 않고, 온보딩 O2에서 권한을 하나씩 받으며, 배너나 푸시를 누르면 PL2 목록 시트가 두 단계로 떠요. 1단계 '다음'은 필수 셋이 켜져야 눌리고, 2단계 '완료'는 언제나 눌려요(결정 129 보충 5). 앱을 열 때마다 팝업이 뜨지 않아요(결정 129)
- [ ] 다른 앱 위에 표시가 켜져 있으면 울림 중 홈 키를 눌러도 울림 화면이 바로 다시 떠요
- [ ] 알림 권한을 두 번 거절한 뒤에는 '설정에서 켜 주세요' 안내로 가요
- [ ] 정확한 알람 권한이 꺼졌다 다시 켜지면 모든 알람이 다시 예약돼요(안드로이드 12 에뮬레이터에서 확인)
- [ ] 알림 권한을 거절했거나 알람 알림 채널을 꺼 두면 홈 배너와 설정 경고가 떠요

### E. 화면과 디자인

- [ ] 모든 화면을 피그마 `화면` 페이지와 나란히 놓고 비교해요(사용자 확인)
- [ ] 라이트와 다크 모두 글자가 잘 읽히고 원색이 섞이지 않았어요
- [ ] 폰 글자 크기를 키워도 시각과 키패드는 그대로, 나머지는 1.3배까지만 커지고 잘리지 않아요
- [ ] '애니메이션 줄이기'를 켜면 하늘과 장면 움직임이 멈춰요
- [ ] Z플립5 접은 바깥 화면처럼 작은 화면, 큰 화면에서도 안 깨져요
- [ ] 설정 줄 값 글자에 파란색이 없고, 선택 표시에 테두리가 없어요
- [ ] 아이콘은 모두 Lucide예요
- [ ] 화면 읽기(TalkBack)로 주요 버튼('미션 시작', '알람 끄기', 권한 '허용', 체크 원 '허용됨')을 읽을 수 있어요

### F. 문구

- [ ] 앱 안 모든 문구에 가운뎃점과 긴 줄표가 없어요
- [ ] 문구 속 버튼과 메뉴 이름은 작은따옴표로 감쌌어요
- [ ] 미션 이름은 영어판(Drop Words, Pop Quiz, Quick Math, Shake Shake)으로 통일돼 있어요
- [ ] 삼성 설정 메뉴 이름(절전 예외, 접근성 경로)이 실제 폰과 같아요

### G. 데이터와 콘텐츠

- [ ] Pop Quiz 단계마다 60문제, Drop Words 단계마다 200단어가 들어갔고 검수를 마쳤어요
- [ ] 임시 문제, 임시 소리, 샘플 소리가 하나도 남지 않았어요
- [ ] 폰을 바꿨을 때(구글 백업 복원) 알람이 따라오고, 복원 뒤 다시 예약돼요. 내 사진과 '이번만 쉬기'는 따라오지 않아요
- [ ] 공휴일 목록이 끝난 날짜(기기 날짜를 2028년으로) 뒤에도 요일대로 울리고 업데이트 안내가 떠요
- [ ] 앱을 업데이트해도 저장된 알람이 하나도 사라지지 않아요(데이터베이스 구조 옮기기 확인)
- [ ] 앱 데이터를 지우고 처음 열었을 때 빈 홈(H1)이 나와요

### H. 출시 서류와 정책

- [ ] 앱 ID가 정한 값이고, 업로드 키를 안전한 곳 두 군데에 백업했어요
- [ ] 개발자 계정 조건을 채웠어요(조직 계정 D-U-N-S 확인, 개인 계정이면 테스터 12명 14일 비공개 테스트)
- [ ] 디버그판(`.debug`)을 지우고 출시판 하나만 깔린 상태로 마지막 확인을 했어요
- [ ] Play Console 신고: 정확한 알람(`USE_EXACT_ALARM`), 전체 화면 알림, 포그라운드 서비스 종류
- [ ] 접근성(전원 종료 방지)을 넣었다면: 접근성 사용 신고, 앱 안 동의 화면, 동작 영상
- [ ] 날씨를 넣었다면: 위치 권한 신고, 위치정보 관련 확인(`research/H-location-law.md`), 개인정보 처리방침의 위치 항목
- [ ] 개인정보 처리방침 주소가 앱(T1)과 스토어에 같게 들어가 있어요
- [ ] T5 오픈소스 라이선스 화면에 가져온 코드와 글꼴(Pretendard)이 모두 적혀 있어요
- [ ] 쓰지 않는 권한이 앱에 남아 있지 않아요(카메라, 마이크, 광고 ID, 전화 상태 없음)
- [ ] 스토어 글에 가운뎃점과 긴 줄표가 없고, 사업자 정보는 사용자가 고른 항목만 넣었어요
