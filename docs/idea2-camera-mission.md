# 아이디어 2: 카메라, 바코드 촬영 미션 (보류, 11-23)

11-23 [기획 2] 작성. 원문은 `docs/ideas-11-22.md` 2번.

> **보류 (11-23 사용자 "미션은 후에 다시 생각해 보자")**: MVP에 넣지 않고 첫 버전 뒤에 다시 생각해요. 결정 138 (`decisions-11-23.md`). 아래 추천과 질문은 그때 참고용이에요.

## 결론

- 알라미 말고도 사진, 바코드, QR 미션이 있는 알람 앱이 많아요. 국내 '슈퍼알람', 해외 'Sleep as Android', 'Barcode Alarm Clock' 등이 있어요. **검증된 방식이라 해 볼 만해요.**
- 다만 **MVP에는 넣지 않고, 출시 뒤 첫 업데이트에 '바코드, QR 스캔'만 넣는 것을 추천해요.** '정해 둔 물건 사진 맞추기'는 실패 불만이 많아서 빼요.

## 1. 레퍼런스 (11-23 웹 검색)

| 앱 | 방식 | 무료/유료 | 사용자 반응 |
|---|---|---|---|
| 알라미 (기준) | 등록해 둔 장소를 똑같이 다시 찍기(사진 미션), 바코드 스캔, 매일 다른 집안 물건 찾기(AI) | 기본 무료, 여러 미션 묶기 등은 유료 구독 | 좋음: 침대 밖으로 나가게 됨. 불만: 사진을 계속 인식 못 해 알람을 못 끄고 앱을 지운 사례, 빛이 바뀌면 인식이 안 됨. 바코드로 바꾸니 낫다는 후기도 있음 |
| 슈퍼알람 (국내) | 바코드 스캔, 사물 인식, 수학, 기억력, 걷기 등 | 무료, 앱 안 결제 | 디자인과 편의성 칭찬이 많음. 카메라 권한은 바코드, 사물 미션에만 쓴다고 밝힘 |
| Sleep as Android | 욕실에 붙인 QR 코드 스캔, NFC 태그 대기, 수학, 흔들기 | 무료 체험, 유료 | 불만: QR을 집에 두고 나가서 앱을 지웠다 다시 깔아야 알람을 끌 수 있었던 사례 |
| Barcode Alarm Clock (iOS) | 치약 같은 정해 둔 바코드 스캔 | 유료(Pro) | 평점 약 4.3~4.4. 좋음: 매번 침대에서 나오게 함. 불만: 스캔이 늦게 잡혀 알람이 계속 울림, 가끔 안 울림 |
| ScanStop, Alarm Scan, BarLock 등 (iOS 새 앱) | 바코드, QR 스캔. 일부는 못 찾을 때 대신할 다른 미션 | 대부분 무료 | 평가 수가 적어 반응을 판단하기 어려움 |
| SnapWake, ActiWake, Daymax (iOS) | 정해 둔 물건, 하늘, 파란 물건 등을 찍으면 AI가 확인 | 구독 위주 | 평가 적음. 비슷한 앱 KiWake는 "아무거나 찍어도 꺼진다"는 불만 |

공통으로 나온 교훈

| 교훈 | 내용 |
|---|---|
| 사진 맞추기는 잘 실패함 | 빛, 각도가 바뀌면 인식이 안 돼 알람을 못 끄는 일이 가장 큰 불만 |
| 바코드, QR이 더 안정적 | 정답이 딱 하나라 판단이 분명하고 빨라요 |
| 대신할 길이 필요함 | 코드를 잃어버리거나 집 밖에 있으면 끌 수 없어요. 대체 미션이나 비상 해제가 있어야 해요 |
| 늘 있는 물건에 붙이기 | 버릴 물건의 바코드를 쓰면 다음 날 못 꺼요 |

## 2. 우리 앱에 넣는다면

| 항목 | 내용 |
|---|---|
| 권한 | 카메라 하나. 결정 130의 '3 그 기능 켤 때만' 단계예요. 온보딩에서는 묻지 않고, 미션을 고를 때(S1-2) 처음 한 번 시스템 창으로 물어요 |
| 온보딩 권한 흐름 영향 | 없음. O2 장 수(결정 129)는 그대로예요 |
| 사용성 테스트 영향 | 새 권한과 새 미션이라 폰 설치와 권한 시험이 필요해요. 밤 10시~아침 9시 규칙 때문에 낮에만 시험할 수 있어요 |
| 59초 무동작 타이머 | 그대로는 안 맞아요. 욕실까지 걸어가는 동안 화면을 안 만지면 59초가 끝나 다시 크게 울려요. 카메라 화면이 열려 있는 동안은 '동작 중'으로 보거나, 이 미션만 시간을 늘려야 해요(추천: 카메라가 켜져 있으면 동작 중으로 봄) |
| 실패하기 쉬운 상황 | 어두운 방(손전등 켜기 버튼 필요), 코드가 가까워 초점이 안 맞음, 코드를 잃어버리거나 떼어 버림, 집 밖에서 잔 날, 카메라 고장이나 권한 거절 |
| 안전장치 | 등록한 코드를 못 찍을 때 다른 미션(예: 수학)으로 바꾸는 길. 피그마 '06 핵심 흐름'에 남아 있는 '15분 뒤 비상 해제', '대체 미션'과 함께 정해야 해요 |
| 개인정보 | 사진은 저장, 전송하지 않고 폰 안에서 코드만 읽는다고 안내해요. 바코드 값만 알람에 저장 |
| 만들기 크기 | 중간. 코드 읽기는 구글의 폰 안 바코드 인식(ML Kit)을 쓰면 무료이고 바로 돼요. 필요한 것: 코드 등록 화면, 스캔 화면, 손전등, 대체 미션, 권한 거절 처리, 59초 규칙 예외. 사진 맞추기(AI 비교)는 훨씬 커서 빼요 |
| 디자인 | 새 화면 2개(등록, 스캔)와 미션 고르기 타일 1개 |

## 3. 아이디어 3(MVP는 잠 깨는 데만 집중)과 맞춰 보기

- 카메라 미션은 "침대에서 나오게 하기"라 잠 깨기 목적에는 딱 맞아요.
- 하지만 MVP는 지금 있는 미션(M1~M4)으로 "알람이 확실히 울리고 꺼진다"를 먼저 굳히는 것이 더 중요해요. 새 권한, 새 실패 상황(코드 분실), 59초 규칙 예외가 한꺼번에 들어오면 출시가 늦어지고 시험할 것이 늘어요.
- 수면 라운지를 빼서 생긴 여유는 '알람 확실히 울리기'(아이디어 6 조사)와 다시 잠들기 방지(결정 136)에 먼저 쓰는 것을 추천해요.

## 4. 추천

- **넣어요. 다만 MVP 다음, 첫 업데이트에 '바코드, QR 스캔 미션'만 넣어요.**
- 이유 1: 여러 앱이 쓰는 검증된 방식이고, 바코드는 사진 맞추기보다 실패 불만이 적어요.
- 이유 2: 알라미는 미션 묶기를 유료로 막아요. 우리가 바코드 미션을 무료로 주면 아이디어 9의 "무료로 써 볼 만한 앱"에 힘이 돼요.
- 이유 3: MVP 범위(잠 깨기, 확실히 울리기)를 지키고 시험 부담을 늘리지 않아요.
- 넣을 때 꼭 같이: 손전등 버튼, 코드를 못 찍을 때 다른 미션으로 바꾸는 길, 카메라가 켜진 동안 59초 멈춤.

## 5. 사용자에게 물을 것

1. 카메라 미션은 MVP 다음 첫 업데이트에, 바코드와 QR 스캔만 넣는 것으로 할까요? (사진 맞추기는 뺌)
2. 코드를 못 찍을 때 다른 미션으로 바꾸는 길을 둘까요? 두면 확실히 일어나게 하는 힘은 조금 약해지지만, 알람을 못 꺼서 앱을 지우는 일은 막아요.
