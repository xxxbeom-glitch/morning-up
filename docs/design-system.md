# morning-up 디자인 시스템

피그마 morning-up 파일(`MazZLYfaQndMh9AxlRcz2v`)에 있는 디자인 규칙을 정리한 문서예요.
페이지 구성(2026-11-16 정리): `표지`, `디자인 시스템`(색, 글자, 크기 견본), `컴포넌트`(부품 원본), `화면`(`30:2`), 조사 페이지 `01`~`08`, `09 컬러 팔레트 조사`(옛 `10`), `보관 (이전안)`.
- 11-16 `화면 / 메인`과 `화면 / 나머지`(`137:483`)를 한 페이지 `화면`으로 합치고 `화면 / 나머지` 페이지는 지웠어요. 이 문서에서 `화면 / 메인`, `화면 / 나머지`라고 적힌 곳은 모두 `화면` 페이지로 읽어요.
- `화면` 페이지 배치(11-16 재정렬): 왼쪽(x 0부터)은 확정 화면을 흐름 순서대로 묶은 7개 줄이에요. 1 홈(A 홈, H1~H8-5, y 200), 2 홈 하늘 장면(낮밤 궤도 5장, 둥실 4장, 날씨 8장, y 1472), 3 알람 편집(B, S1~S5-2, S6~S8, D1, y 3706), 4 알람 울림(D, D 밤, y 5612), 5 알람이 울린 뒤(W1 6장, W2 2장, y 6812), 6 잠들기 탭(Z1, Z2, 썸네일, y 8012), 7 설정과 권한(T1, T2, P1~P4, T3~T5, y 9421). 오른쪽 x 7000은 '결정이 필요한 화면' 구역인데 11-16 기준 비어 있어요(알람 화면 배경 S8과 기획 16번은 나중에 정해요). 반영이 끝난 12시간제 시안과 쓰지 않기로 한 버튼 떠다니기 시안은 `보관 (이전안)` 페이지로 옮겼어요. 결정이 끝난 화면은 왼쪽 해당 줄로 옮겨요.
홈(A), 알람 편집(B), 알람 울림(D) 화면 기준이에요.
2026-11-16 기준이에요.

## 방향

- 캐시워크식 밝은 라이트: 밝은 회색 바탕, 흰 카드, 옅은 그림자. 2026-11-16부터 p8 색을 써요. 같은 날 강조색을 맑은 파랑 A(#0B6CF0) 한 색의 단계로 바꿨어요(라이트 기본 500 #0B6CF0, 다크 기본 300 #8AB8FB). 하늘 그라데이션 `sky/1`(#0A78C2)은 그대로예요. 초록은 성공 색으로 옮겼어요.
- 글래스 효과, 테두리 선, 구분선은 쓰지 않아요.
- 선택 표시는 칠로만 해요. 선택 버튼에 테두리를 두르지 않아요.
- 아이콘은 Lucide 하나로 통일해요 (선 두께 2, 크기 24).
- 화면에 쓰는 색, 글자, 간격, 라운드, 그림자는 모두 아래 변수와 스타일에 묶어요.
